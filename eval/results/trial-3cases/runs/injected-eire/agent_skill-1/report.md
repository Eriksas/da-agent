**问题：** 2011-W31 的 GMV 环比下降了，主要是哪个国家拖累的？

**分析周：2011-W31（2011-08-01 ~ 08-07），基期 2011-W30（环比 wow）**

## 1. 结论

GMV 从 178,721.26 降到 161,986.06，减少 16,735.20（-9.36%）。**看国家维度，降幅最大的是 EIRE（爱尔兰），单周从 21,615.74 归零（-21,615.74，占总变化的 129.16%）**——但该组基期只有 9 单，被工具标记为样本不足，不能单独下结论。剔除口径噪音后，更稳的判断是：下降主要发生在老客身上，且集中在英国以外的小市场；英国实际是增长的（+6,347.38）。

## 2. 主要驱动（按贡献大小）

**金额维度（decompose_gmv，Shapley 值，与拆解顺序无关）：**

| 因子 | Shapley 贡献 | 占总变化 |
|---|---|---|
| 人均订单数 1.1625 → 1.0993 | -8,690.40 | 51.93% |
| 活跃客户数 277 → 272 | -2,833.02 | 16.93% |
| 缺客户 ID 的 GMV 16,063.58 → 13,427.81 | -2,635.77 | 15.75% |
| 可识别客户客单价 505.15 → 496.85 | -2,576.01 | 15.39% |

- 数据事实（metric_summary）：订单数 343 → 312（-9.04%），但客单价几乎没动（521.05 → 519.19，-0.36%），活跃客户数只掉 1.81%。
- 推断：这是"买的人少了 + 每人少买一单"的下滑，不是价格问题；人均订单数是最大单一因子。

**国家维度（drilldown，GMV 环比）：**

- EIRE：-21,615.74（占总变化 129.16%），9 单 → 0 单，**样本不足**。
- Japan：-3,680.40（21.99%），1 单 → 0 单，**样本不足**。
- Sweden：-3,254.99（19.45%），2 单 → 1 单，**样本不足**。
- 对冲项：United Kingdom **+6,347.38**（+4.54%，285 单，样本充足）、Germany +2,747.40、Switzerland +1,713.65、France +1,575.70；others（其余 11 国合计）+594.66。
- 陷阱提示：各组正负抵消后总变化才 -16,735.20，所以单个分组占比会超过 100% 或为负，不能读成"爱尔兰一个市场就搞砸了整周"。

**新老客维度（drilldown，与国家维度是同一笔 GMV 的两种切法，不能相加）：**

- 老客 -19,485.39（116.43%，294 → 268 单）；新客 +5,385.96（-32.18%）；未知 -2,635.77（15.75%）。
- 数据事实：新客数 27 → 30（+11.11%），新客 GMV 增长主要由 3 个新客客均较高带来。

**商品维度：**变化分散在长尾——others（2200 个单品）合计 -14,381.43，占总变化 85.94%，没有单一商品是主因。

## 3. 需要注意

- **可比性没问题**：交易天数 6 vs 6，metric_summary 和各 drilldown 均无 warnings；但这是 8 月旺季周，仍需业务确认是否有活动节奏变化。
- **EIRE / Japan / Sweden 都是小样本**（9、1、2 单），drilldown 明确警告"变化可能是偶然波动，不宜单独下结论"，本回答不对其单独归因。
- **反向抵消**：英国增长 6,347.38（相当于总降幅的 37.93%）被爱尔兰的归零掩盖了，只看单国容易误判。
- **GMV 与净销售额同时看**：净销售额 -16,922.98（-9.56%），取消率 0.91% → 1.12%（+0.21 个百分点），取消金额 1,808.12。下降不是取消单造成的，取消反而略微变多。
- **极端大额订单**：data_quality_overview 列出的 6 条人工复核行中，没有落在 2011-W30/W31 的，所以本周的下滑无法用已标记的极端单解释。
- 缺客户 ID 部分占当周 GMV 的比例不低（13,427.81），这部分不进入客户数/人均订单口径。

## 4. 建议下一步

1. 拉 EIRE 9 单的明细发票和客户 ID，确认是不是 1~2 笔大单（比如批发/礼品采购），以及这些客户是流失还是转到其他国家下单。
2. 查英国 +4.54% 的同时活跃客户仅降 1.81% 意味着什么——是否存在"小市场客户迁移到英国站"或合并下单的行为（待业务确认）。
3. 看老客人均订单数下降 5.44% 的原因：是促销周期结束、还是某类复购品（如 REGENCY TEAPOT、CHILLI LIGHTS）断货，需与商品/库存数据对齐。
4. 若要判断"是否某个市场运营动作导致"，需要对照实验或分批上线数据，现有数据只能给相关关系。
