## 需要注意

1. **可比性**：两周交易天数都是 6 天，metric_summary 未返回警告；2011-W49 是残缺周（数据只到 12-09 12:50），未参与对比。
2. **取消**：取消金额 7,158.91 → 3,266.67，取消率 2.37% → 1.06%，因此净销售额增速（+3.69%）高于 GMV 增速（+2.31%）。注意取消金额口径为"当周 C 开头发票"，可能对应更早下的订单，分子分母不是同一批订单。
3. **缺客户 ID 的 GMV = 62,564.34**，不计入活跃客户/新老客，结构拆解中作为独立因子（+4,005.19）；GMV 与订单数是全覆盖口径，而客单价 466.64 混合了可识别与不可识别部分（可识别客单价为 391.15）。
4. **小样本**：除英国外，国家和商品维度所有大幅波动的分组订单数都少于 30，不能单独下结论；`others` 是前 N 名以外分组的合计，不等于剔除某一项后的结果。
5. **极端值**：人工复核清单中的 581483（168,469.60，2011-12-09）落在 2011-W49，不在本次对比区间；但本周/上周区间内没有该量级的极端行。
6. **相关不等于因果**：以上均为同比/环比的同期变化，没有对照实验，"新客变少""周三回落"都只能作为待验证的可能原因。
