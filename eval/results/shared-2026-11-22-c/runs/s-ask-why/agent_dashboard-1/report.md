**问题：** 上周 GMV 为什么变化？

## 分析对象

**2011-W48（2021-11-28 至 12-04，即“上周”）**，基期为 **2011-W47（11-21 至 11-27）**，环比（wow）对比。

## 1. 结论

上周 GMV **309,381.73 英镑**，较上一周 **302,392.22** 上涨 **6,989.51（+2.31%）**（`metric_summary`）。两周交易天数均为 6 天，`metric_summary` 未返回任何不可比警告，**可直接比较**。

这次微涨是**“人多了、买得勤了”与“每单买得小了”相互抵消**的结果：净销售额 306,115.06，环比 +10,881.75（+3.69%），涨幅高于 GMV，主要因为取消金额从 7,158.91 降到 3,266.67（取消率 2.37% → 1.06%）。**GMV 增长基本由英国本土老客和活跃客户数撑起来，客单价是最大拖累项。**

## 2. 主要驱动（按 `decompose_gmv` 的 Shapley 贡献排序）

| 因子 | Shapley 贡献 | 占总变化 | 依据 |
|---|---|---|---|
| 可识别客户客单价 | **-13,088.20** | -187.25% | `decompose_gmv` |
| 活跃客户数 | **+10,735.71** | +153.6% | `decompose_gmv` |
| 人均订单数 | **+5,336.81** | +76.35% | `decompose_gmv` |
| 缺客户 ID 的 GMV | **+4,005.19** | +57.3% | `decompose_gmv` |

四项之和 = +6,989.51，与总变化一致（工具校验 `contributions_sum_to_total: true`）。

**① 客单价下滑是最大拖累（数据事实 + 推断）**
- 可识别客单价 412.58 → 391.15；全口径客单价 490.90 → 466.64（-24.26，-4.94%，`metric_summary`）。
- 按订单金额分档（`query_data` 取数）：**≥1000 英镑档 GMV 从 79,976.37 降到 67,638.88（-12,337.49）**，订单数反而从 33 增到 37，但平均每单从 2,423.53 降到 1,828.08；同期 300–1000 英镑两档合计 **+17,862.07**（300–600：74,696.56 → 82,944.46，订单 185 → 211；600–1000：35,113.36 → 44,727.53，订单 46 → 59）。可识别客户 GMV 总变化仅 **+2,984.32**（`calculate`）。
- **推断**：客单价下降主要不是“大家都买便宜了”，而是**周内最大额的那几单没有复现**——属于订单结构波动，具体原因（是否为大额团购/批发单）**待业务确认**。

**② 活跃客户数增加是最大正贡献（数据事实）**
- 492 → 514（+4.47%）；其中**老客 455 → 483（+6.15%）**，新客 37 → 31（-16.22%）（`metric_summary`）。
- 国家维度：英国 GMV **+14,297.73（+5.38%）**，订单 560 → 607，是客户数增长的主要来源（`drilldown`）。

**③ 人均订单数提升（数据事实）**
- 1.2012 → 1.2276（+2.2%）；订单总数 616 → 663（+7.63%）（`metric_summary`）。

**④ 必须并列说明的抵消项（不能只谈最大项）**
- **荷兰 -10,694.24（-99.04%）**：W47 有 5 张发票、W48 只剩 1 张 104.00 的小单（`query_data`）。明细显示，W47 的绝大部分金额来自老客 14646 的 4 张发票（7,952.68 + 1,835.96 + 513.24 + 290 = **10,591.88**，`calculate`），其中 578140 一单 42 条明细。**推断**：荷兰的“归零”实质是一个大额老客断档，非市场问题；该组订单数 <30，工具已标记样本不足，不单独下结论。
- **新客 GMV -9,396.04（-48.32%，19,446.50 → 10,050.46）**，新客订单 43 → 36（`drilldown`）。订单数只少 7 单，金额却少近一半，**差额来自头部新客订单消失**：客户 18139 在 W47 一人下过 6 单新客订单（2,786.40、2,675.28、1,090.92、734.82、689.52、461.40），其中前两单各自都大于 W48 最大的新客订单（1,162.65）；W48 的新客订单列表中未出现该客户（`query_data`）。**老客 +12,380.36（+5.52%）部分抵消了这一项。**
- **缺客户 ID 的 GMV +4,005.19（+6.84%，58,559.15 → 62,564.34）**，订单 25 → 32（`drilldown`），该组样本不足，需谨慎解读。

## 3. 需要注意（口径与警告）

- **可比性**：两周交易天数均 6 天、无不完整周、无节假日停业（`metric_summary` warnings 为空；`data_quality_overview` 显示部分周只有 2009-W49 和 2011-W49，最后一条记录为 2011-12-09 12:50，均不在本次比较内）。
- **取消率口径**：分子是当周 C 开头发票金额、分母是当周 GMV，不一定是同一批订单；净销售额涨幅高于 GMV 是因为取消金额减少，不能直接读成“需求变好”。
- **拆解口径**：GMV = 活跃客户数 × 人均订单数 × 可识别客单价 + 缺客户 ID 的 GMV；Shapley 与默认顺序的连环替代差异很小（10,735.71 vs 10,903.10；5,336.81 vs 5,599.98；-13,088.20 vs -13,518.76），**结论对拆解顺序不敏感**。
- **小样本**：荷兰、日本、法国、西班牙、意大利、德国、芬兰订单数均 <30；商品维度 21166、82600、79321 等同样样本不足，工具已标记，勿单独下结论。
- **缺客户 ID 占比不低**：W48 缺客户 ID 的 GMV 62,564.34，订单 32 单；全站缺客户 ID 金额占 GMV 的 13.11%（`data_quality_overview`），这部分销售额不进客单价拆解，会放大结构波动。
- **无对照实验**：上述均为“同时发生”的相关关系，未做因果判断。

## 4. 建议下一步

1. **查两个关键客户**：14646（荷兰，W47 下单 10,591.88）与 18139（W47 6 单新客订单）是否为批发/团购型大客户（如 578140 一单 42 条明细、18139 的 577783 有 35 条明细），确认其断档是偶发还是流失——这决定“总变化被少数大单放大”这一判断是否成立。
2. **验证客单价波动是否常态**：拉 2011 年前 8 周的 identified_aov 与 ≥1000 英镑档订单分布，确认“每周 1–2 笔大单”的结构性规律，从而判断本周客单价下滑是否只是常规波动。
3. **补齐流量侧数据**：新客数 37 → 31 是首单客户变少，本数据只有交易表，需结合渠道/流量/落地页数据判断获客是否走弱。
4. **核对 guest 结账流程**：缺客户 ID 订单 32 单、GMV 62,564.34，若网站未登记结账流程发生变化，会同时影响 GMV 与拆解口径。
5. **若要验证因果**（例如“缺客户 ID 订单变化影响了 GMV”），需要 CRM 触达数据或 A/B 实验，当前数据只能给相关关系。
