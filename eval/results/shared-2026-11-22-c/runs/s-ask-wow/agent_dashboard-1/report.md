## 需要注意

- **可比性**：两周交易天数均为 6 天（metric_summary），2011-W48 是完整周，数据只到 2011-12-09 12:50，不完整周是 2011-W49 和 2009-W49（data_quality_overview），本周不受影响。
- **极端大额行**：清单中需人工复核的发票（581483、C581484、C541433、541431、556444、530715）都不在 W47/W48，本结论未受其影响（data_quality_overview）。
- **样本不足**：荷兰、日本、法国、西班牙、"未知"客群、部分商品的订单数均少于 30（drilldown warnings），这些分组的涨跌可能是单笔订单造成，不单独下结论。
- **抵消项**：总变化小、分组互相抵消，因此单项贡献占比超过 100% 或为负（drilldown warnings）；不能只看英国或只看老客。
- **口径**：客单价 = GMV ÷ 订单数；取消率 = 取消金额 ÷ GMV，分子分母不一定是同一批订单；缺客户 ID 的订单计入 GMV 和订单数但不计入活跃客户（metric_summary / data_quality_overview 定义），这也是"活跃客户 +22 而订单 +47"的部分原因。
- **左删失**：新客数靠近数据起点时可能把老客算成新客；本周距起点较远，但新客样本仅 31/37 人，结论从严。
- **无因果证据**：以上都是同时发生的事实性拆解，"客单价下降""新客萎缩"背后的业务原因需业务确认或实验验证，不能写成"因为"。
