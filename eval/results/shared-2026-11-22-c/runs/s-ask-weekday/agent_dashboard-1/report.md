## 需要注意

1. **天数不等会误导总额排名**：周二、周三各 5 天有交易，其余各 4 天。周三总额第一是因为多了一天；单日效率上周一反超。周四日均订单数最高（119.25）但日均 GMV 排第三，说明周四客单偏低。
2. **单日榜首疑似被大额订单拉动**：2011-11-14 的 GMV 明显高于其余日期，但订单数（106）与相邻日期接近，属大单集中而非客流高峰；按订单数看，周二 2011-11-29（135 单）、周三 2011-11-23（130 单）才是订单最密集的日子。GMV 口径为**下单口径，含之后被取消的订单**，单日 GMV 不等于当天最终实现的净销售额。
3. **周六为结构性缺失**：取数说明认为该商家基本不周六营业（全量数据中周六仅 1 天有交易），因此 0 值属"不营业"而非数据丢失；该说明程序未核对。
4. **数据质量口径**（data_quality_overview）：缺客户 ID 的行仍计入 GMV 和订单数（约四分之一行），但不影响本结论的两个指标；极端大额行仅标记待人工复核（共 38 行），清单中列出的日期（2011-12-09、2011-01-18、2011-06-10、2010-11-04）均不在 11 月内。2011 年 11 月是完整月，数据范围覆盖至 2011-12-09。
