# 2011-W31 GMV 环比下降分析

**分析周期：2011-W31（2011-08-01 ~ 08-07），对比基期 2011-W30（上一周）**

## 1. 结论

2011-W31 GMV 为 **161,986.06**，较 W30 的 **178,721.26** 下降 **-16,735.20（-9.36%）**（来源：metric_summary，wow）。

**最大拖累来自 EIRE（爱尔兰）**：W30 有 21,615.74，W31 直接为 **0**，单周减少 **-21,615.74**，占总降幅的 **129.16%**（来源：drilldown，按国家）。也就是说，除掉 EIRE 这一项，其余国家合计其实是**增长 +4,880.54** 的（来源：calculate：-16,735.20 + 21,615.74）。因此这次环比下滑几乎完全由爱尔兰订单“集体消失”造成，主力市场英国实际是增长的。

## 3. 需要注意（口径与警告）

- **EIRE 样本不足**：drilldown 明确标注 base_orders=9（<30）标记 small_sample，其贡献占比 129.16% 大于 100%，是因为英国、德国、瑞士、法国等正向增长相互抵消了总降幅所致；单看 EIRE 的绝对值（-21,615.74）是可靠的，但“占比 129%”不应按字面理解为“降幅的 129%”。
- 其余拖累项（Japan 1 单、Sweden 2 单）同样是 small_sample，可能只是偶然波动，不宜单独下结论。
- 本周 W31 与 W30 交易天数均为 6 天，无停业或不完整周（2011-04-21~04-26 的停业在 W17，与本周无关）；数据范围 2009-12-01 ~ 2011-12-09，W31 属完整周。
- GMV 为下单口径、含之后被取消的订单；净销售额同步下降 -16,922.98（-9.56%），说明取消并非主因。
- 无实验/对照，以上只能表述为“与……同时发生”“可能原因”，不能断言因果。

## 4. 建议下一步

1. **核查 EIRE 这 9 单（合计 21,615.74）**：确认是真实流失（大客户流失/合同到期/内部停售），还是清洗口径问题（如国家字段异常、R07 重复行删除、R10 国家不明确未合并）。data_quality_overview 显示存在需人工复核的极端大额行（R09，38 行）及“缺少客户 ID 占 GMV 13.11%”的情况，建议逐单复核。
2. **确认该国是否整体停售**：若 EIRE 是单一批发/企业客户渠道，其订单消失会直接造成这种“少数大单决定周度 GMV”的波动，需要在预测口径上单独标注。
3. **看更长的周序列**：用 metric_summary 对 2011-W28~W31 做 4 周趋势，确认 EIRE 是回归常态（一次性）还是持续下滑（需干预）。
4. **同步跟进英国**：英国订单数从 312 降到 285 但 GMV 仍增长（客单价上升），可进一步用 drilldown 按新老客拆英国，判断是量缩价升还是结构变化。
5. **数据治理**：本周约 15.75% 的降幅来自缺客户 ID 的 GMV（-2,635.77），建议提升客户 ID 覆盖率，否则国家/客户维度的归因会持续失真。
