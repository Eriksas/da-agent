**问题：** 我们做了一个满减实验，按 50/50 分流：对照组 5000 人中 400 人下单，实验组 5600 人中 480 人下单。实验组赢了吗？

## 结论

**不能算赢。** 实验组转化率 0.085714 vs 对照组 0.08，差异不显著（p = 0.287131，95% 置信区间 [-0.004788, 0.016217]）；更关键的是，本次分流的**样本比例失衡（SRM）检验不通过**，按设计不应该解读效果。

## 主要原因（数字均来自 ab_proportion_test / ab_sample_size / calculate）

1. **SRM 失败，实验结论无效**
   - 设计分流 50/50，总样本 10600 人 → 预期对照组 5300 人。
   - 实际对照组 5000 人（占比 0.471698），实验组 5600 人（占比 0.528302），对照组比预期少 300 人。
   - 卡方拟合优度检验：chi2 = 33.9623，p_value = 0.0，sample_ratio_mismatch = true。工具建议："先排查分流和埋点，暂不解读实验效果"。
   - 常见原因：分流哈希/桶位不均、机器人与重复用户被剔除的比例在两组不同、埋点丢失偏向某一组。

2. **即使抛开 SRM，效果也不显著**
   - 对照组转化率 0.08，实验组 0.085714，difference = 0.005714，relative_lift = 0.071429。
   - z = 1.0644，p = 0.287131，significant = false；置信区间 [-0.004788, 0.016217] 跨过 0。

3. **样本量本来就不足以检出这个幅度的提升**
   - 以基线率 0.08、目标率 0.085714（即当前观察到的绝对差 0.005714）、alpha 0.05、power 0.8 计算，每组需 36536 人，合计 73072 人；当前每组仅 5000 / 5600 人。
   - 换句话说，即使流程完全没问题，这次也只有机会检出比 0.071429 大得多的效果。

## 需要注意

- 上述 p 值和置信区间是"假设分流正确"条件下的统计结果；在 SRM 未修复前，它们不能作为"满减无效/有效"的证据。
- 转化率与差异数字照抄你提供的数据（400/5000、480/5600）与工具计算结果，未做其他假设。
- 未做多重比较或异常值剔除说明；如实验组存在异常高转化人群，需要单独排查。

## 建议下一步

1. **先查分流与埋点**：确认哈希分流是否 50/50、是否有实验组机器人/内部号、埋点是否在某一组丢失；SRM 的 p_value = 0.0 对应的偏离量级（对照组少 300 人）不像随机波动。
2. **修复后重跑并延长实验**：若目标是把基线 0.08 提升到 target_rate 0.1，按 alpha 0.05、power 0.8 计算，每组需 3213 人、合计 6426 人；当前样本量不足，需按实际流量延长实验周期。
3. **关注 GMV/客单价而非仅下单率**：满减可能提升下单率却压低客单价，实验组下单人数比对照组多 80 人（480 - 400 = 80，来自 calculate）但人均金额若下降，整体 GMV 可能不涨；建议后续同时埋 AOV 与净销售额指标（GMV 口径需扣除满减成本）。
4. 结论措辞：对内对外都应写"本次实验因分流样本比例失衡、且转化率差异不显著，暂无法判断满减效果"，不要写"满减带来了明确提升"。
