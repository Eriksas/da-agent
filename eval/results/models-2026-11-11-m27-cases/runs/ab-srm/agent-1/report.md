**问题：** 我们做了一个满减实验，按 50/50 分流：对照组 5000 人中 400 人下单，实验组 5600 人中 480 人下单。实验组赢了吗？

**结论**：实验组并没有“赢”。既不能说有提升，也不能说没提升——实验数据本身存在分流失衡（SRM），结果不可信，建议先排查。

**主要原因**

1. **分流比例失衡（致命问题，先于效果讨论）**：`ab_proportion_test` 的 SRM 检查显示，总样本 10600 人，预期对照/实验各 5300 人，实际对照组 5000 人（比预期少 300），实验组 5600 人（比对照多 600），实测对照组占比 0.4717、实验组 0.5283；卡方 = 33.9623，p 值 = 0.0，判定 `sample_ratio_mismatch: true`。工具给出的建议是：先排查分流和埋点，暂不解读实验效果。

2. **效果本身也不显著**：对照组转化率 0.08（400/5000），实验组转化率 0.085714（480/5600），绝对差 0.005714，相对提升 0.071429；z = 1.0644，p 值 = 0.287131，95% 置信区间 [-0.004788, 0.016217]，`significant: false`。即差异方向为正，但完全落在噪声范围内。

**需要注意**

- 50/50 设计下实验组人数比对照组多 600，且两组差异在 p=0.0 水平上显著偏离 1:1，这不是随机波动能解释的。可能原因包括：分流哈希/随机种子有偏、埋点丢失集中在某一组、实验开启期间有用户被重复或遗漏分配。
- 即使忽略 SRM，以当前样本量也无法检出 0.57 个百分点的真实提升；p 值 0.287 说明"未显著"不等于"无效果"，样本量可能不足。
- 上述所有数字均来自 `ab_proportion_test` 与 `calculate`（对照组转化率 400/5000 = 0.08）。

**建议下一步**

1. **先查 SRM**：核对分流服务日志，统计每组的曝光/去重 UV、是否有人同时进两组、是否有设备或用户 ID 重复计数；确认埋点是否只在某组丢失。
2. **修好后再跑**：用干净数据重跑比例检验。
3. **顺便算够样本量**：若预期真实提升就是 0.57 个百分点（8% → 8.57%），可用 `ab_sample_size` 计算所需样本量，再决定是否延长实验。
4. **双指标校验**：GMV 之外看客单价/净销售额（取消单会稀释转化收益），避免"转化微涨但单均下滑"被漏掉。
