**问题：** 我们做了一个满减实验，按 50/50 分流：对照组 5000 人中 400 人下单，实验组 5000 人中 460 人下单。效果显著吗？

## 结论

**效果显著。** 实验组转化率 9.2% vs 对照组 8.0%，绝对提升 1.2 个百分点，相对提升 15%，双侧 p = 0.0323（< 0.05），95% 置信区间 [0.10pp, 2.30pp] 不包含 0，判定为显著。

（数据来自 ab_proportion_test）

## 主要原因 / 关键数字

| 指标 | 数值 |
|---|---|
| 对照组转化率 | 400/5000 = 8.0% |
| 实验组转化率 | 460/5000 = 9.2% |
| 绝对差 | 1.2 个百分点 |
| 相对提升 | 15% |
| z 值 | 2.1401 |
| p 值 | 0.0323 |
| 95% 置信区间 | [0.001012, 0.022988] |

**分流质量（SRM）**：对照组实测占比 0.5，期望 0.5，chi2 = 0.0，p = 1.0，无样本比例失衡问题（ab_proportion_test 的 srm 段）。这也提示：两组各 5000 人的规模是准确的，不是数字记错。

## 需要注意

1. **样本量偏紧。** 按基线 8%、想检测 1.2pp 提升、alpha=0.05、power=0.8 计算，每组需要 8568 人（合计 17136），而实际每组只有 5000 人（ab_sample_size）。也就是说本次实验的实际统计功效低于 80%，点估计 15% 的相对提升存在被高估的可能，CI 下限只有 0.10pp。结论是"显著"，但"至少提升 1.2pp"这个精度并没有被充分保障。
2. **统计显著 ≠ 业务显著。** 1.2pp 的绝对提升是否值得做满减，需要结合满减成本（券费用）对 9.2% 的增量转化做单客利润测算，这部分数据本次工具未提供。
3. **只测了下单转化。** 满减实验更该看的是下单后的 GMV/净销售额、客单价、是否出现"凑单多买"或"低质订单"，本次没有相应数据。

## 建议下一步

1. **补功效再跑一轮**：把每组流量扩到 8568 人以上（或在现有流量上多跑 1–2 周），确认提升幅度稳定在 1.2pp 以上再全量。
2. **算 ROI**：拉取实验组/对照组的净销售额与满减成本，用「增量净销售额 − 券成本」判断是否正向；本工具不覆盖，需要业务数据源。
3. **看护栏指标**：检查客单价是否被满额门槛拉低、取消率是否上升（可用 metric_summary / drilldown 按新老客拆解），避免用低质量订单换转化。
4. **延长观察期**：若近期有节假日或大促，转化率基线会漂移，建议在稳定期复测一次，避免只在当前流量结构下成立。
