**结论：显著。** 满减实验组转化率 9.2% vs 对照组 8.0%，绝对提升 1.2 个百分点，相对提升 15%，双侧 p = 0.0323 < 0.05，95% 置信区间 [0.10pp, 2.30pp] 不包含 0。

**具体数字（来自 ab_proportion_test）**
- 对照组转化率：0.08（400/5000）
- 实验组转化率：0.092（460/5000）
- 差异：0.012，相对提升：0.15
- z = 2.1401，p = 0.032349，置信区间 [0.001012, 0.022988]
- SRM 检查：观测分流 50/50，与设计一致，chi2 = 0.0，p = 1.0，无样本比例失衡
- 无 warnings

**需要注意**
1. p = 0.0323 接近 0.05 阈值，属于"刚刚显著"，结论对样本波动较敏感；本次未做多重比较校正，若同时测多个满减档位/多个指标，需做 Bonferroni 或 BH 校正后再看显著性。
2. 置信区间下界仅 0.10pp，实际效果区间较宽，不能据此断言效果就是 1.2pp。
3. 按 ab_sample_size，基线 8%、想稳定检出 1.2pp 的绝对提升（alpha 0.05、power 0.8），每组需 8568 人、总计 17136 人；本次每组仅 5000 人，实际把握度低于 80%，存在检出"运气成分"的风险。
4. 转化率是二值指标，本次结论只覆盖"是否下单"，未涉及客单价、GMV 和长期留存，需确认满减带来的下单增加能否覆盖补贴成本、且不是把本来会下单的人提前转化。
