# 新版商品详情页实验结论

**分析的是本次 50/50 分流的实验（对照组 8000 人 / 480 人下单，实验组 8000 人 / 520 人下单）。**

## 1. 结论

**目前不能判定新版更好。** 实验组转化率略高于对照组，但差异没有达到统计显著，属于"方向正面、证据不足"。

- 对照组转化率：0.06（480/8000）
- 实验组转化率：0.065（520/8000）
- 绝对差异：0.005（+0.5 个百分点），相对提升 0.083333（约 +8.3%）
- z = 1.3064，p 值 = 0.191418，95% 置信区间 [-0.002501, 0.012501]
- significant = false（alpha = 0.05）

置信区间跨 0，意味着真实差异既可能是新版更好，也可能是新版更差（区间下限 -0.25 个百分点），无法排除"新版反而降低转化"的可能。

## 2. 数据可信度检查

- 分流比例正常：实际对照组占比 0.5，与设计的 0.5 一致，卡方 = 0.0，p = 1.0，`sample_ratio_mismatch = false`（样本比例失衡检查通过）。
- 工具返回的 warnings 为空：未发现 SRM 异常或其他数据问题。

## 3. 需要注意

- **不能下因果结论**：本次只是"实验组转化率同时高于对照组"，样本量不足以证明新版详情页带来提升；也未排除其他同期因素（如流量结构、时段、品类分布）在两组间不均。
- 指标口径：这里用的是**下单转化率**（下单人数/总人数），不等于 GMV 或支付转化率。新版详情页可能影响加购、客单价或支付环节，本实验未覆盖这些指标。
- p 值 0.191418 属于"数据不足"区间，请勿按"接近显著"来做上线决策。

## 4. 建议下一步

1. **不要基于当前结果直接全量上线或下线新版**，继续跑量到可判定为止。
2. **样本量测算**：若要检出 0.5 个百分点的绝对提升（基线 6% → 6.5%），alpha = 0.05、power = 0.8 时，**每组需要 36791 人、总计 73582 人**（ab_sample_size）。当前每组仅 8000 人，远低于所需量，这就是不显著的直接原因。
3. 延长实验期间并核查**分组间的人群/流量结构一致性**（新老客、渠道、设备、品类），确认 0.5 个百分点的差异不是结构偏移造成的。
4. **补充更贴近业务的指标**：除下单率外，同时看加购率、支付转化率、客单价与人均 GMV，并用相同流量跑第二阶段实验，避免只优化单一漏斗环节。
5. 若最终仍无法在 73582 人规模下检出差异，可考虑把 MDE 放宽到实际业务上有意义的水平（如 1 个百分点），或直接接受"新版无显著负面影响"这一结论后再全量。
