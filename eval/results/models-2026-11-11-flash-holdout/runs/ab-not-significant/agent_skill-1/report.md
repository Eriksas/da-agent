# AB 实验结论：新版商品详情页**暂不能判定更好**（未达统计显著）

> 说明：本次分析完全基于你提供的实验数据（对照组 8000/480，实验组 8000/520），未使用店铺经营数据。

## 1. 结论

实验组下单率 **6.5%**，对照组 **6.0%**，绝对差 **0.5 个百分点**，相对提升 **8.33%**；但 **p = 0.191418 > 0.05**，95% 置信区间为 **[-0.002501, 0.012501]**（即 -0.25pp ~ +1.25pp），**不显著**。当前数据不足以证明新版更好，也不足以证明新版更差。

## 2. 主要原因（逐项拆解）

| 项目 | 数值 | 来源 |
|---|---|---|
| 对照组转化率 | 0.06（480/8000） | ab_proportion_test |
| 实验组转化率 | 0.065（520/8000） | ab_proportion_test |
| 绝对差 | 0.005 | ab_proportion_test |
| 相对提升 | 0.083333（+8.33%） | ab_proportion_test |
| z 值 | 1.3064 | ab_proportion_test |
| p 值 | 0.191418 | ab_proportion_test |
| 95% 置信区间 | [-0.002501, 0.012501] | ab_proportion_test |
| 是否显著 | false | ab_proportion_test |

- **分流是干净的**：SRM 检查显示实际对照组占比 0.5，与设计占比 0.5 一致，chi2 = 0.0，p = 1.0，`sample_ratio_mismatch = false`，说明样本比例与设计相符，结论不是分流偏差造成的。
- **差异幅度落在噪声范围内**：0.5pp 的差小于置信区间允许范围，区间横跨 0，说明 +8.33% 的相对提升完全可能是随机波动。

## 3. 需要注意

- **不显著 ≠ 没效果**：区间上界到 +1.25pp，真实效果可能为 0，也可能是一个有商业价值的小幅提升；现在下"新版无效"的结论同样会犯方向性错误。
- **样本量对当前效应量不够**：按 alpha=0.05、power=0.8、基线 6% 计算，检测 **2pp** 提升每组只需 2554 人（合计 5108），检测 **1pp** 需每组 9540 人（合计 19080），检测本次实际观测到的 **0.5pp** 需每组 36791 人（合计 73582）。当前每组 8000 人足以识别 2pp 级别的效果，但不足以可靠识别 0.5pp 的效果——即"没测出来"不等于"没有"。
- 工具本身未返回 warnings；以上判断基于显著性检验与样本量测算，未做多重指标校正（若同时看了多个指标，需额外校正）。

## 4. 建议下一步

1. **先定业务最小可接受效应（MDE）**：如果业务上 0.5pp 根本不值得上线，那按当前结论**不应全量**，把资源留给下一次更明确的改版；如果 0.5pp 值得要，就继续跑到每组 9540 人（可检测 1pp）或 36791 人（可检测 0.5pp）再判断。
2. **看下游指标而不只看下单率**：同时跟踪下单率之外的 GMV / 客单价 / 取消率，避免出现"下单率微涨但客单价下滑"的净负面效应。
3. **看分人群效应**：按新老客、渠道、商品类目切分实验结果，确认是否存在局部显著提升（例如某类目内 +2pp 以上），再决定是否做定向放量。
4. **继续保留实验组流量**，避免因提前下结论关闭分流导致后续无法补齐样本。
