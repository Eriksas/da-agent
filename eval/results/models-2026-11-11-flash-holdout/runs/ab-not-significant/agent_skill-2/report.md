**问题：** 我们测试了新版商品详情页，按 50/50 分流：对照组 8000 人中 480 人下单，实验组 8000 人中 520 人下单。新版本更好吗？

# 结论

**目前的数据还不能说明新版本更好。** 实验组转化率 6.5%（520/8000），对照组 6.0%（480/8000），绝对差 +0.5 个百分点、相对提升 8.33%，但 **p = 0.1914 > 0.05，差异不显著**（`ab_proportion_test`）。当前观察到的差异与随机波动无法区分，不能作为全量上线的依据。

# 需要注意

1. **不显著 ≠ 没效果，也 ≠ 有效果**：置信区间同时包含负值和正值，说明这个实验还无法排除“新版本更差（最多 -0.25pp）”或“更好（最多 +1.25pp）”的可能。
2. **样本量本身不足以检出这个量级的差异**：以基线转化率 0.06、最小可检测提升 0.005 计算，每组需要 **36,791** 人、总计 **73,582** 人才能在 80% 把握度下稳定检出（`ab_sample_size`）。目前每组只有 8,000 人，缺口为每组 28,791 人、合计 57,582 人（`calculate`）。这说明本次“未显著”很可能是**功效不足**，而不是新版本无效。
3. **分流本身是干净的**：SRM 检验显示对照组/实验组实际占比 0.5/0.5，与设计一致（`ab_proportion_test`），说明差异不是分流偏斜造成的。
4. 本次仅检验了转化率这一项指标；商品详情页通常还会影响客单价、GMV、页面跳出等，**当前数据没有覆盖这些指标**。
5. 用户提供的数字为每组 8,000 人、转化 480 / 520 人，工具未提供更细的分群或时间维度数据。

# 建议下一步

1. **继续跑量**：把实验延长到每组约 3.7 万人，再看显著性；或者反向思考——如果业务上认为 +0.5pp 带来的收益太小不值得跑这么多量，就直接判负，不必继续投入。
2. **明确可接受的最小效应（MDE）**：先和业务对齐“新版本至少要提升多少转化率才值得上线”，再据此判断需要多少样本量，避免用 p 值反复解读。
3. **补充护栏指标**：客单价、GMV、取消率、页面停留与跳出率，防止转化率上升但整体价值下降。
4. **做分群检验**：按新客/老客、设备、地区拆分效果，可能存在总体被稀释的分群差异（注意分群样本会进一步变小，需控制多重比较）。
5. 在拿到显著结论前，建议先做**小流量灰度 + 监控业务护栏指标**，而不是直接全量替换。
