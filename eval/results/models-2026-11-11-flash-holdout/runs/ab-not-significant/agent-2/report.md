# AB 实验结论：新版详情页转化率更高，但**统计上不显著**，暂时不能判定新版更好

## 1. 结论

数据方向上新版详情页更好：实验组转化率 0.065，对照组 0.06，绝对提升 0.005（+0.5pp），相对提升 8.333%。但两比例 z 检验 p = 0.191418，95% 置信区间 [-0.002501, 0.012501] 跨过 0，`significant = false`——**当前证据不足以说新版更好**，也排除不了一定幅度的轻微下降。

## 2. 关键数字（全部来自 `ab_proportion_test` / `ab_sample_size`）

| 指标 | 对照组 | 实验组 |
|---|---|---|
| 分母（访客） | 8000 | 8000 |
| 转化人数 | 480 | 520 |
| 转化率 | 0.06 | 0.065 |

- 差值 0.005，相对提升 0.083333，z = 1.3064，p = 0.191418
- 95% 置信区间 [-0.002501, 0.012501]（即 -0.25pp ~ +1.25pp）

**SRM 检查（样本比例失衡）通过**：观测分流 0.5 / 0.5，期望对照组 8000.0、实验组 8000.0，control_minus_expected = 0.0，treatment_minus_control = 0，chi2 = 0.0，p = 1.0，`sample_ratio_mismatch = false`。分流实现没有明显问题。

## 3. 主要原因：不显著主要是**样本量不够**，不是效果为负

- 要在 α=0.05、power=0.8 下检出 1pp 的提升（6% → 7%），每组需要 9540 人（合计 19080）；当前每组 8000 人，**还差 1540 人/组**（`ab_sample_size` + `calculate`）。
- 若目标就是本次观测到的 0.5pp 效果，每组需要 36791 人（合计 73582），**还差 28791 人/组**（`ab_sample_size` + `calculate`）。
- 也就是说：本次实验对"小幅转化提升"的检验力不足，**"p 不显著"不等于"新版没效果"**；同时置信区间上界 +1.25pp 也说明真实效果有可能是不错的提升。

## 4. 需要注意

- `ab_proportion_test` 返回的 `warnings` 为空，无数据质量告警。
- 本次结论完全基于你提供的 16000 人分流量化数据，与仓库内 2009-W49 至 2011-W49 的销售数据无关；"下单"口径按你给的分母（每组 8000 人）计算，**未去重口径请自行确认**（人均多次下单会低估转化差异）。
- 只测了"下单转化率"这一个指标，没看 GMV / 客单价，新版也可能只是把低价值订单转化得更多。

## 5. 建议下一步

1. **先定 MDE 再续跑**：如果业务上认为 1pp 以上的提升才值得上线，再补 1540 人/组即可达到结论；否则要确认是否有足够流量支撑到 73582 人的规模，否则该实验只能作为方向性参考。
2. **补充 GMV 类指标**：以订单金额为结果指标重跑，避免"转化率升、GMV 不升"或反向。
3. **预设停止规则与切分维度**（新老客、流量来源、端），避免跑到显著为止的 p-hacking。
4. 如果要在当前样本上做决策，建议按"效果未达显著 + 置信区间包含轻微负向"处理，即**暂不全量上线新版**，先继续跑量验证。
