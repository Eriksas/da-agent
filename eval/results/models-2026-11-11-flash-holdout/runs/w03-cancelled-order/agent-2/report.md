**问题：** 2011-W03 的 GMV 环比涨了一成多，是不是卖得更好了？

## 结论

**不是卖得更好，2011-W03 的 GMV 环比 +11.77% 是一笔"假涨"。** 这一周的生意其实在下滑：订单数、活跃客户数都在两位数下滑，净销售额环比 **-29.44%**。GMV 的增长几乎全部来自**一笔单笔 77,183.60 的极端大额订单（发票 541431，MEDIUM CERAMIC TOP STORAGE JAR，只有 1 单）**，而这笔订单在 24 小时内被等量取消（C541433，-77,183.60）——也就是说，这单根本没成交。

> 分析对象：**2011-W03 对比 2011-W02（环比）**，两周交易天数均为 6 天，非营业天数差异造成的。

## 主要原因

**1）单一极端大额订单撑起了全部 GMV 增幅（主因）**
- 当周 GMV 209,331.26 vs 上周 187,291.30，+22,039.96 / **+11.77%**（`metric_summary`）。
- 商品维度拆解中，商品 `23166` MEDIUM CERAMIC TOP STORAGE JAR 从 **0 → 77,183.60**，占总变化的 **350.2%**（`drilldown`·商品）；前 5 名以外的 2,304 个分组合计反而是 **-32,466.78**。
- 剔除这一单后，GMV 环比变为 **-29.44%**，日均 GMV 环比同样为 **-29.44%**（`calculate`）。
- 该单被等量取消：取消金额 2,344.03 → **78,840.60**，取消率 1.25% → **37.66%（+36.41 个百分点）**，净销售额 184,947.27 → **130,490.66，-29.44%**（`metric_summary`·取消口径）。

**2）客户和订单量本身在收缩（真实趋势）**
- 订单数 258 → **229，-29 单 / -11.24%**；活跃客户 212 → **185，-27 / -12.74%**（`metric_summary`）。同比看更清楚：订单 -12.6%、活跃客户 -15.53%（`metric_summary`·yoy）。
- 人均订单数 1.0991 → **1.1027**，仅 +0.33%（`metric_summary`），说明不是"老客买得更多了"。

**3）客单价上升是数学假象，不是提价或结构改善**
- GMV 口径客单价 725.94 → **914.11，+25.92%**；但把这笔 77,183.60 剔掉后，客单价只有 **577.06**，反而低于上周；按净销售额口径算客单价环比 **-20.51%**（`calculate`）。GMV 拆解中"可识别客户客单价"贡献 +43,104.93（Shapley）、活跃客户数贡献 -22,442.14（`decompose_gmv`），也都指向同一笔订单。

**4）新客明显塌了**
- 新客 GMV 28,660.87 → **5,188.87，-23,472.00 / -81.90%**；老客 +44,679.58（`drilldown`·新老客）。同期 GMV 下降的商品集中在 `21108` FAIRY CAKE FLANNEL ASSORTED COLOUR（-6,585.30）和 `48185` DOORMAT FAIRY CAKE（-4,451.21）这类常见新客引流品（`drilldown`·商品）——两者与新客下滑在时间上同时发生，可能是同一件事，但订单样本仅 4 单 / 6 单，不足以下因果结论。

## 需要注意

- **口径提醒**：GMV 是"下单口径"，含之后被取消的订单；净销售额 = GMV − 取消金额；取消率的分子分母不一定对应同一批订单（`metric_summary`·指标定义）。GMV 涨而净销售额跌，本身就是"下单口径"与"成交口径"的差别。
- **极端大额行已进入人工复核清单**（清洗规则 R09），涉及发票 541431 / C541433、556444、581483 / C581484 等共 38 行。结论对"是否把 541431 计入 GMV"高度敏感：计入则 +11.77%，剔除则 -29.44%。
- **样本不足提示**：`drilldown` 中多个商品分组订单数少于 30（23166 仅 1 单、21108 为 4→1 单、48185 为 6→8 单、22470 为 18→17 单），单项涨跌可能是偶然波动，不宜单独下结论。
- `drilldown` 的 "others" 是前 5 名以外 **2,304 个分组的合计**，不等于只剔除某一个分组。
- 缺客户 ID 的 GMV 为 35,196.78，占当周 GMV 的 **16.81%**（`calculate`）；全量数据该比例为 **13.11%**（`data_quality_overview`）。这部分不计入活跃客户/复购分析，未识别订单会稀释客单价的可比性。
- 数据范围 2009-W49 至 2011-W49；2011-W03 不在节假日停业名单内。

## 建议下一步

1. **人工复核发票 541431 / C541433**：确认这 77,183.60 是真实客户下单后取消，还是误录/测试单。如果是误录，应从 GMV 统计口径中剔除，运营看板本周应按 -29.44% 解读。
2. **把看板主指标从 GMV 切到净销售额**（或同时展示取消率），避免今后再被这类单笔订单误导。
3. **查新客塌陷的原因**：新客 GMV -81.9%、新客数 14 vs 16，重点核对 21108 / 48185 等引流品的库存与曝光，以及 W03 的投放、渠道、落地页是否中断；同时复核同期是否有重复行（R07 清洗会删重复行，删错会让 GMV 偏低）。
4. **看更长周期**：该周同比净销售额 -8.92%、订单 -12.6%、活跃客户 -15.53%，趋势性走弱的迹象比单周更值得关注，建议拉 4-8 周的净销售额/订单/活跃客户曲线确认是否为持续下滑而非单周波动。
