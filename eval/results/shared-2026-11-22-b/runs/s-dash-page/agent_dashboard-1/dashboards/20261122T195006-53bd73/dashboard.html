数据说明

  • 口径：GMV 为下单口径（含之后被取消的订单）；净销售额 = GMV − 取消金额；取消单按取消发生的时间入账，不回溯原订单所在月份。
  • 不完整月份：2011-12 只到 12-09（数据截止），不能和完整月份比；2010-12-23 至 2011-01-03 停业，2010-12 与 2011-01 天数不足，2010-12 订单数比 2010-11 少 43%。
  • 极端大额订单：发票 541431、581483 等下单后很快全额取消，会抬高当月 GMV、客单价和商品排名，净销售额不受影响；2011-12 当月取消 174,091.36，占该月 GMV 的 28.3%。
  • 客户口径：全表约 22.24% 的行缺客户 ID，这部分金额计入 GMV，但不计入活跃客户数，在新老客拆分中归入「未知」；老客占全期 GMV 73.73%，客群结构以老客为主。
  • 新老客按周判定（客户首次购买的周）；2009-12 是数据起点，该月新客金额 462,001.42 高于老客 215,914.65，起点附近月份的新客占比偏高。
  • 单位为英镑（£）；客单价 = GMV ÷ 订单数，订单数只数销售订单（取消行没有订单号），两者可能不是同一批订单。
