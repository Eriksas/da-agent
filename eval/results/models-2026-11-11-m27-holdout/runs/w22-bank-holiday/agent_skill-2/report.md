# 2011-W22 GMV 环比下降诊断

## 1. 结论

**“降了近三成”主要是天数差异造成的放大：实际 GMV 115,065.00，环比 -44,398.82（-27.84%，`metric_summary`），但当期只有 5 个交易日、基期 2011-W21 有 6 个交易日，按日均口径日均 GMV 从 26,577.30 降到 23,013.00，实际降幅为 -13.41%（`metric_summary` warnings）。**

去掉天数因素后仍是真实下滑，性质是**老客侧的普遍性收缩**（英国市场 + 老客 + 全品类，而非单个商品问题），而非数据异常或爆款断货。

## 2. 主要驱动（按贡献排序）

**驱动一：少一个交易日（数据事实）**
- 交易天数 6 → 5（`metric_summary`）。这是总量 -27.84% 中最大的一块。
- 旁证：2010-W22 同样是 5 个交易日，同比口径下 GMV 反而是 **+7.94%**（106,601.91 → 115,065.00，`metric_summary` 同比）。两年同周都是 5 天，说明这一周的结构性少一天是常态节假日模式（**待业务确认**：2011-05-30 为英国五月最后一个周一，疑为 Spring Bank Holiday 停业）。

**驱动二：活跃客户数下降（Shapley -24,548.60，占总变化 55.29%，`decompose_gmv`）**
- 活跃客户 260 → 212（-48，-18.46%）；订单数 350 → 259（-91，-26%）。
- 老客数 243 → 191（-52，-21.4%）；新客数 17 → 21（+4，+23.53%）。
- 老客 GMV 137,421.07 → 93,603.39（-43,817.68，占总变化 98.69%，`drilldown` 按新老客）；日均后仍为 -18.26%（22,903.51 → 18,720.68，calculate）。

**驱动三：人均订单数下降（Shapley -12,590.53，占 28.36%，`decompose_gmv`）**
- 人均订单数 1.2462 → 1.1226（-9.91%），即来了一次但没复购。

**驱动四：可识别客户客单价小幅下降（Shapley -4,502.08，占 10.14%，`decompose_gmv`）**
- 客单价 455.61 → 444.27（-2.49%），量级远小于前两项，不是主因。

**驱动五：缺客户 ID 部分减少（-2,757.61，占 6.21%）**
- 16,999.49 → 14,241.88（`drilldown` “未知”客群，订单 26/21，小样本，不单独下结论）。

**抵消项（不可忽略）**
- 新客 GMV 反而 +2,176.47（5,043.26 → 7,219.73，+43.16%，`drilldown`），拉回约 4.9% 的跌幅。

**下钻结论**
- 国家：United Kingdom 137,820.66 → 96,176.99（-41,643.67，占总变化 93.79%，315→232 单，`drilldown`）；日均后 -16.26%（22,970.11 → 19,235.40，calculate）。其余国家多为 1–5 单的小样本（Netherlands 2→5 单、EIRE 4→0 单等），不单独下结论；前 8 名以外 8 个分组合计 +1,767.84。
- 商品：前 8 名商品合计解释 41.54% 的总变化（各商品占比 0.0709、0.0655、0.0545、0.0524、0.048、0.0434、0.0404、0.0403，合计由 calculate 计算），且其中多数订单数少于 30；前 8 名以外 2019 个商品合计 -25,956.71（占 58.46%，`drilldown`），说明是**面上的普跌，不是单一爆款断货**。

## 3. 需要注意（口径与警告）

- **不可直接比较**：两周交易天数不同（5 vs 6），总量对比必须带保留，日均口径更公平（`metric_summary` warnings、`decompose_gmv` warnings、`drilldown` warnings 均提示同一件事）。
- **取消不是原因**：净销售额 -28.1%（157,659.72 → 113,356.54），与 GMV 降幅基本同步；取消率 1.13% → 1.48%（+0.35 个百分点），且取消金额分子分母不一定是同一批订单（`metric_summary` 定义），不足以解释跌幅。
- **极端大额行不在本周**：`data_quality_overview` 的极端行清单中，2011 年 6 月的两笔 PICNIC BASKET（38,970.00，发票 556444，2011-06-10）落在 W23 而非 W22，W22 内部无极端值扭曲；但 2011-W49 的 168,469.60 大额单说明该店铺存在需人工复核的大额订单。
- **小样本分组**：国家维度除英国外各组订单 < 30；新老客维度“新客/未知”组订单 22/21，均标注样本不足，结论从严。
- **缺客户 ID 占整体 13.11%**（`data_quality_overview`），该部分不计入活跃客户与人均订单，会低估客户数口径的波动。

## 4. 建议下一步

1. **确认停业日**：向业务/运营确认 2011-05-30（周一）是否全天停业（英国 Spring Bank Holiday）；确认后可把 W22 与 W21 改为按 5 天口径对齐复盘。
2. **查老客流失名单**：拉取 2011-W21 活跃但 W22 未下单的老客名单（243→191，-52 人），看是否集中于特定国家、客群或首购月份，判断是自然淡季还是触达/物流问题。
3. **查复购链路**：人均订单数 1.2462→1.1226 是一致性下滑，核对 W22 是否有发货延迟、库存缺货、邮件/短信触达中断。
4. **查流量与渠道**：老客订单与新客订单同时受影响，需确认是否与投放、站内改版或支付/物流故障同期发生。
5. **如需验证因果**：用 A/B 或分地区/分渠道对照实验（如对流失老客做召回优惠 vs 不触达），不要仅凭时间相关下结论。

## 5. 可信度自评

**说明局限后分享。** 天数差异与老客/人均订单下滑这两点有工具数据支撑、可信；但“少的那一天是节假日停业”“是老客召回失效”属于待业务确认的假设，且除英国外各国家、各具体商品分组样本不足，无法据此单独定责。
