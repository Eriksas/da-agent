**问题：** 2011-W01 的 GMV 环比变化怎么看？

## 结论

**2011-W01 的"环比"算不出来，不是因为业务涨跌，而是基期不可比**：环比基期 2010-W52 整周停业、GMV 为 0，工具返回的变化率是空值（`metric_summary` 2011-W01 vs 2010-W52：基期 GMV 0.0、change_pct null，warning："基期 2010-W52 整周没有交易（停业）"）。在分母为 0 的情况下报任何涨跌幅都是无意义的。

| 口径 | 基期 | 基期 GMV | 变化 | 日均 GMV 变化 |
|---|---|---|---|---|

## 主要驱动

### A. 对 2010-W51（环比替代口径）：是"人多了"，不是"单变大了"

- **活跃客户数 86 → 207（+140.70%）**、**订单数 158 → 242（+53.16%）**，而**客单价 539.26 → 538.33（−0.17%，基本持平）**（`metric_summary` + `calculate`）。GMV 增长几乎全部来自客户数与订单数，客单价没贡献。
- **老客是主力**：GMV 41,543.49 → 107,339.33，订单 100 → 210，客户 79 → 193（`query_data` 按新老客分组）。
- **抵消项必须一起看**：**缺客户 ID 的"未知"组 GMV 39,917.13 → 16,801.60，订单 51 → 18**（`query_data`）。这一组在 2010-W51 占了近一半 GMV、到 2011-W01 大幅回落，是"增长"里被抵消掉的部分。所以**不能只说"增长全靠老客"**：老客的高增长里，有多少是真实复购、有多少是未识别交易（游客/缺客户 ID）的重新分布，无法从现有数据区分。
- **交易天数差异必须剥离**：2011-W01 实际销售日为 1/4、1/5、1/6、1/7、1/9 共 5 天（1/3、1/8 无销售），2010-W51 只有 12/20–12/23 共 4 天（`query_data` 按日明细）。所以总量 +52.90% 里天然含"多一天"，日均口径只有 +22.32%。
- **国家下钻**：英国 70,173.02 → 113,862.46（订单 142 → 224），是唯一有量级的贡献来源；其余国家单周订单仅 1–4 单（如 Netherlands 8,576.88 → 0、Australia 0 → 7,154.38、Germany 1,789.51 → 3,652.13），**样本远不足 30 单，不单独下结论**，差异基本由单笔订单驱动（`query_data`）。

### B. 对 2010-W01（同比口径）：GMV 降 21.53%，但主因是客单价，不是订单

`decompose_gmv`（2011-W01 vs 2010-W01，总变化 −35,736.14，Shapley 值）：

- **可识别客户客单价：884.59 → 506.58，Shapley 贡献 −77,797.41**（占比 2.177，因子反向变化故超过 100%）——最大单一因素。
- **人均订单数：1.1265 → 1.0821，Shapley −5,700.00**。
- **活跃客户数：166 → 207，Shapley +31,551.30**（占比 −0.8829）是唯一的正向贡献。
- **缺客户 ID 的 GMV：591.63 → 16,801.60，Shapley +16,209.97**。
- 汇总看：订单 200 → 242（+21%）、活跃客户 166 → 207（+24.7%）、客单价 830.05 → 538.33（−35.15%）、**新客 67 → 14（−79.1%）、老客 99 → 193（+94.95%）**、**取消率 0.78% → 3.66%（+2.88 个百分点）**（`metric_summary` 同比）。
- 新老客结构整体翻转、老客占比上升，同时**取消率上升 2.88 个百分点**与 GMV 下滑**同时发生**——取消是原因还是结果，现有数据无法判断。

## 需要注意

1. **环比不可比是第一结论**：2010-W52 停业，任何"环比涨幅"都不成立，汇报时必须标注"复业首周"。
2. **两周都不完整**：2011-W01 5 个销售日（1/3、1/8 无销售），2010-W51 4 个销售日（12/24–12/26 无销售）。总量对比必须同时给日均。
3. **同比的两条口径警告**：基期 2010-W01 距数据起点（2009-12-01）不足 52 周，起点前的购买看不到，**部分老客被算成新客**，因此"新客 −79.1%"这一条要从严解读；同比两周交易天数 6 → 5，总量差 −21.53% 中含天数因素，日均只有 −5.83%。
4. **缺客户 ID 的行占全站 GMV 的 13.11%**（`data_quality_overview`：gmv_missing_customer_share 0.1311），跨周横向比较总量时，这部分结构变化会直接改变结果。
5. **GMV 是下单口径**，含之后被取消的订单；取消率的分子（当周取消）与分母（当周 GMV）不一定是同一批订单。
6. **极端大额行不落在 W01**：人工复核清单里的 77,183.60（发票 541431，2011-01-18，1 天内全额取消）属于 2011-W03，W01 内部没有极端大额行干扰。
7. 全部结论均为"同时发生"的关系，**未做因果判断**——上述新老客结构翻转、取消率上升、游客占比变化都缺少对照实验，属于待验证假设。

## 建议下一步

1. **周报口径**：给 2011-W01 加"假期停业后复业首周"标注，环比一律改用日均，并把 2010-W51 标注为"停业前最后一个交易周（仅 4 天）"。
2. **查 2011-W01 的取消明细**（按发票号回溯原下单周），确认 +2.88pp 的取消率上升是真实恶化，还是取消单按发生时间跨周入账造成的记账位移。
3. **查 2010-12 起是否改变了收银/会员录入方式**（缺客户 ID 订单从 51 单降到 18 单），这能直接判定"老客高增长"里有多少是游客交易重新归属。
4. **给 2011-W01 补一次商品维度下钻**（本次未展开），确认客单价 −35.15% 是否集中在某几个 SKU 上，为后续定价/选品讨论提供依据。
