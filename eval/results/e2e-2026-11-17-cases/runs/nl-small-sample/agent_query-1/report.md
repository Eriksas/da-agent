**问题：** 2011-W48 荷兰的 GMV 为什么跌了这么多？

## 结论（分析的是 2011-W48，即 2011-11-28 ~ 12-04，与上一周 2011-W47 环比）

**荷兰 GMV 的“暴跌”是小样本 + 单笔批发大单造成的统计现象，不是可解读的业务下滑。** 荷兰 W48 只有 **1 张订单、104.00 英镑**（drilldown：base_orders=5 / current_orders=1，已标记 small_sample）；而 W47 的 10,798.24 英镑里有 **7,952.68 英镑（占 73.65%）来自单张批发发票 578140**（42 个商品行，客户 14646，11-23 下单）。把这张单剔除后，荷兰环比仍是 **-96.35%**，说明“跌”的主体是**上一周被一张大单垫高了基期**，不是荷兰在 W48 出现了需求崩塌。

同时要注意：**这次荷兰的下跌没有拖累大盘**——全站 GMV 从 302,392.22 升到 309,381.73（+6,989.51，+2.31%，metric_summary），英国的 +14,297.73 完全盖过了荷兰的 -10,694.24；drilldown 里荷兰占总变化的比重是 **-1.53（即 -153%）**，属于“分项反向变动、相互抵消”的典型情形。

## 主要驱动（按贡献大小）

1. **基期被一张批发大单抬高**（数据事实，来自 query_data 荷兰发票级汇总 + calculate）
   - W47 荷兰 5 张发票：7,952.68 / 1,835.96 / 513.24 / 290.00 / 206.36；W48 只有 1 张：104.00（客户 12787，11-30，3 个 JUMBO BAG 商品行）。
   - 其中 4 张 W47 发票属于客户 **14646**，W48 该客户在荷兰没有任何订单；W48 唯一的单来自另一客户 12787。
   - 剔除 578140 这张 7,952.68 的单后：荷兰环比 -96.35%（calculate），全站环比由 +2.31% 变为 **+5.07%**（calculate）。
2. **荷兰是典型的“大单驱动、极度波动”的微型市场**（数据事实，来自 query_data 荷兰周度表）
   - W40–W48 每周荷兰 GMV：925.33 / 0 / 29,458.10 / 9,995.22 / 4,486.91 / 9,793.12 / 457.74 / 10,798.24 / **104.00**；订单数 4 / 0 / 7 / 3 / 3 / 3 / 3 / 5 / **1**；客单价在 152.58 ~ 4,208.30 之间跳动，单周最大一笔在 W42 高达 20,277.92。
   - 结论：**单周百分比对荷兰没有解释力**，应该看 4 周/13 周滚动值。
3. **与取消、退货无关**（数据事实，来自 query_data）
   - 荷兰 W40–W48 每周取消金额均为 0，W47/W48 两周没有任何取消行（74 行全为销售行），所以这次下降不是取消单口径或退货造成的。
4. **全站层面的“客单价下滑”同期也存在**（数据事实，来自 decompose_gmv，Shapley 值）
   - W48 环比：活跃客户数 **+10,735.71**、人均订单数 **+5,336.81**、可识别客户客单价 **-13,088.20**、缺客户 ID 的 GMV **+4,005.19**，合计 +6,989.51。
   - 推断（非因果）：W47 荷兰这几张大单都来自**可识别**客户 14646，正好落在“可识别客户客单价”这一项上；该客户在 W48 没有荷兰订单，与可识别客单价下滑在时间上同时发生。是否为主因需要验证，不宜下因果结论。

## 需要注意

- **样本不足**：drilldown 已对荷兰标记 small_sample（基期 5 单、当期 1 单）；按流程不对单周百分比下强结论，本回答的“跌得多”只描述现象。
- **W48 是完整周**：data_quality_overview 列出的不完整周只有 2009-W49 和 2011-W49，metric_summary 显示 W47/W48 交易天数都是 6 天且无警告；query_data 返回的备注称“2011-W48 因数据截止 2011-12-09 不完整”与上述口径冲突，**未采信**。
- **数据范围**：2009-12-01 ~ 2011-12-09；2011-W49 为不完整周，不可与 W48 直接比较。
- **口径**：GMV 为下单口径（含之后被取消的订单）；荷兰这两周无取消单，所以 GMV 与净销售额一致（drilldown 用 GMV 口径）。
- 同比（2010-W48）GMV 为 -2.46%、新客数 -42.59%，但基期距数据起点不足 52 周存在左删失（metric_summary warning），新客类同比结论从严。

## 建议下一步

1. **改用滚动口径看荷兰**：用 4 周或 13 周滚动 GMV/订单数（W40–W48 已有明细），判断荷兰是否真的在缩量。

3. **按客户看荷兰大客户名单与采购节奏**（如 14646 在 W42/W45/W47 反复下单，W41/W46 缺单），确认是批发客户的采购周期而非零售需求下滑。
4. **口径建议**：B2B 批发大单与零售订单在周报里分开统计，否则单周国家数据会被 1 张单主导。
