## 需要注意

1. **不完整周**：2011-W49 数据截止 2011-12-09 12:50（周五），交易天数 5 天，基期 6 天。总量对比天然吃亏/占便宜，必须同时看日均：日均 GMV 51,563.62 → 96,745.03（+87.62%），日均订单 110.5 → 101.8（-7.87%），日均净销售额 +21.89%（calculate，净销售额口径已扣除那笔取消）。即：剔除虚高后**日均真实成交额确实上升约 21.89%，但订单量是下降的**——增长来自单笔金额而非订单数量，这是与"大涨"相反的信号。
2. **极端大额行需人工复核**（data_quality_overview 列在复核清单，R09 仅标记不删除）：若这单是真实大额采购且后续未取消，是真需求；若为误录/测试单，应从 GMV 口径剔除并修正。
3. **口径提示**：GMV 是下单口径含之后被取消的订单；取消额按当周 C 开头发票统计，分子分母不一定是同一批订单；缺客户 ID 部分（占全量 GMV 13.11%）不计入活跃客户和人均订单。
4. 左删失不适用于本周（2011-W49 位于数据末端，新客 17 人为真实新客口径），但新客数基数小，解读从严。
