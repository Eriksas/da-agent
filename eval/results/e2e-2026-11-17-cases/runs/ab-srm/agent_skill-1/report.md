## 结论

**实验组目前不能算"赢"**：转化率差异在统计上不显著（p = 0.287131，95% 置信区间 [-0.004788, 0.016217] 跨过 0），而且更关键的是**分流比例失衡（SRM）告警触发**，按工具建议应先排查分流与埋点，暂不解读实验效果。

## 主要原因（数字均来自 ab_proportion_test）

**1. 效果本身不显著（ab_proportion_test.test）**

| 指标 | 数值 |

| 对照组转化率 | 400 / 5000 = 0.08 |

| 相对提升 | +0.071429（+7.14%） |
| z 值 | 1.0644 |
| p 值 | 0.287131 |
| 95% 置信区间 | [-0.004788, 0.016217] |
| 是否显著 | false（significant = false） |

即：实验组点估计更高，但 p 值远大于显著性水平 0.05，置信区间同时覆盖"实验组更差"和"实验组更好"两种可能，目前无法排除是随机波动。

**2. 分流比例与设计不符（ab_proportion_test.srm，SRM 检查）**

- 实际对照组占比 0.471698，实验组占比 0.528302；设计为 50/50（期望各 5300 人）。

- 工具建议："样本比例与设计不符，先排查分流和埋点，暂不解读实验效果。"

**3. 样本量不足以支撑当前观测到的效应量（ab_sample_size）**

若基线转化率 8%、希望检测到 0.5714pp 的绝对提升，在 alpha = 0.05、power = 0.8 下，每组需要 36536 人、合计 73072 人。当前每组仅 5000 / 5600 人，远未达到所需规模。
