# 2011-W48 GMV 环比变化诊断（对比 2011-W47）

## 1. 结论

上周（**2011-W48**，数据中最近的完整周）GMV 为 **309,381.73**，环比上周（2011-W47）**+6,989.51（+2.31%）**——总量小幅上升。两周交易天数同为 6 天、无不可比警告，**可直接比较**。

变化是"**量增价减**"：客户数、人均订单数、缺客户 ID 订单三项共推高 GMV，但被**可识别客户客单价下降 5.19%**（412.58→391.15）几乎抵消；结构上表现为**老客增长、新客腰斩**。剔除样本不足的荷兰后，环比其实有 +6.10%。

## 3. 需要注意（口径与警告）

- **不可比风险低**：两周 trading_days 均为 6，`metric_summary` 返回 warnings 为空，2011-W49 才是不完整周。

- **`others` 口径**：是前 N 名以外所有分组合计，不等于"剔除某一项后"的结果。
- **因果**：以上均为同期同向变动的数据事实，"新客减少""客单价下滑"是描述性表述，具体业务原因（流量、活动、品类结构）需业务侧确认。
