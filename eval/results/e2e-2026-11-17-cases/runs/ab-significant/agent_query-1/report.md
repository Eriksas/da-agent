# 满减实验结果分析

**分析对象**：对照/实验组各 5000 人，转化定义为“下单”，数据来自你提供的实验数据（ab_proportion_test、ab_sample_size）。

## 1. 结论

**效果在统计上显著，但边际很薄，属于"刚好过线"**。实验组转化率 9.2% vs 对照组 8.0%，绝对提升 1.2 个百分点、相对提升 15%，双侧 p 值 0.0323 < 0.05，95% 置信区间 [0.101%, 2.299%] 不含 0，因此判定显著；但置信区间下界非常接近 0，且实际样本量低于保证同等效果在 80% 把握度下所需的样本量，结论稳健性偏弱。

## 2. 主要依据

| 指标 | 对照组 | 实验组 | 差值 |
|---|---|---|---|
| 下单人数 / 总人数 | 400 / 5000 | 460 / 5000 | +60 人 |
| 转化率 | 8.0% | 9.2% | +1.2pp |
| 相对提升 | — | — | +15% |

- **样本比例失衡（SRM）检查**：实测对照组占比 0.5、实验组 0.5，与设计的 0.5/0.5 一致，chi2 = 0.0、p = 1.0，**未发现分流异常**（ab_proportion_test 的 srm 段）。这是结果可信的前提，该项通过。
- **显著性检验**：两比例 z 检验，z = 2.1401，p = 0.032349，置信区间 [0.001012, 0.022988]，significant = true，工具未给出额外 warnings。
- **样本量充足性**：按基线转化率 0.08、要检测 0.012 的绝对提升，alpha = 0.05、power = 0.8 计算，**每组需要 8568 人（合计 17136 人）**，实际每组 5000 人，缺口 3568 人/组（ab_sample_size + calculate）。也就是说当前实验的把握度并未达到常规的 80% 标准线，是"p 值擦线通过"。
- 每 5000 名流量下，实验组比对照组多产生 **60 个订单**（calculate）。

## 3. 需要注意

- **p = 0.0323 距离 0.05 只有一点余量**，属于临界显著。若换成双侧/单侧口径、或再分群看，结论可能翻转为不显著。
- **置信区间下界 0.101% 极接近 0**，意味着"真实效果为零"的可能性不能被完全排除。
- **样本量未达标准**：每组 5000 人低于所需的 8568 人，因此本次结果的实际统计把握度低于 80%，存在 II 类错误风险（可能低估了满减的真实效果）。
- **只看到了转化率，没有看到成本侧数据**：满减是让利型活动，转化率提升 1.2pp 是否划算，取决于客单价、毛利与补贴成本，这些数字工具未提供，无法判断 ROI。
- **本次结论仅限于"下单转化"这一指标**：满减是否影响了客单价、复购、退款率，工具未提供数据，不能推断。

## 4. 建议下一步

1. **延长实验或扩流量至每组 8568 人以上**（缺口 3568 人/组），把 p 值推离临界区，再做一次决策；或者延长当前实验到两周汇总。
2. **补齐商业口径**：拉取两组客单价、毛利、补贴实际发放额与退款率，计算"每多 1 元 GMV 的补贴成本"，判断 +1.2pp 转化是否带来净收益。
3. **做多重比较校正**：如果后续要看分群（新老客、国家、客单价段）的效果，需要预先定义检验或做 Bonferroni/BH 校正，避免假阳性。
4. **检查是否存在效应被稀释**：满减通常对新客或低客单价人群效果更强，建议按客单价分层再跑一次 AB（此处需用 query_data 或重新设计实验分层）。
