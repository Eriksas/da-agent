# 2011-W48 荷兰 GMV 异动分析

**分析周期：2011-W48（最近一个完整周），基期 2011-W47（环比）**

## 一、结论

荷兰 GMV 从 **10,798.24 跌到 104.00**（-10,694.24，**-99.04%**），但同期**全站 GMV 实际是上涨的**：302,392.22 → 309,381.73（+6,989.51，+2.31%，`metric_summary`）。

跌幅的全部原因是**订单量**：荷兰订单从 5 单变成 1 单（`drilldown` 国家维度）。荷兰本身是"极少订单、单笔金额极大"的市场——近四周 GMV 在 **457.74 ~ 10,798.24** 之间来回摆动（`drilldown` 2011-W46 / W47），W48 只是那个撑起金额的大单没来，**不是**取消、停业或数据异常造成的。

## 二、主要驱动（按贡献排序）

**1. 订单数：5 单 → 1 单（最直接原因）**
来自 `drilldown`（country / gmv / wow）：Netherlands base 10,798.24（5 单）→ current 104.00（1 单），change -10,694.24，change_pct -99.04%。

**2. 单笔金额结构极不均衡，"基数"由 1~2 笔大单撑起**
- W47 荷兰单均订单金额 = **2,159.648**（`calculate`：10798.24/5）
- W48 唯一剩下的一单只有 **104.00**
- 推断：W45 荷兰 9,793.12（仅 3 单，`drilldown` 2011-W46），W47 荷兰 10,798.24（5 单），W46 荷兰仅 457.74（3 单）——单笔金额量级差异巨大，说明荷兰 GMV 是"少数大单 + 零星小额单"结构。

**3. 与取消无关（排除重要干扰项）**
`drilldown`（country / **net_sales** / wow）：荷兰净销售额 10,798.24 → 104.00，与 GMV **完全一致**，即两周荷兰都没有取消单，不是"下单后被退款"导致的账面回落。

**4. 大盘其他市场把这一跌完全抵消**
`drilldown`（country / gmv / wow）：英国 +14,297.73（订单 560→607）、日本 +3,651.60、法国 +3,318.47（10→18 单）、芬兰 +1,439.05、挪威 +1,146.51；反向的有西班牙 -3,313.22、意大利 -2,453.80、德国 -1,571.19。荷兰 `share_of_total_change` = **-1.53**（负值，因正负互相抵消）。剔除荷兰后全站 GMV 环比为 **0.060645（+6.06%）**（`calculate`：剔除荷兰后的两周 GMV 之比减 1）。

**5. 同比同样如此，是常态而非突发**
`drilldown`（country / gmv / yoy）：2010-W48 荷兰 10,687.45（7 单）→ 104.00（1 单），-99.03%。说明"某些周近 1 万、某些周接近 0"是荷兰的固有节奏。

## 三、需要注意

- **样本不足，不可单独下业务结论**：荷兰 W48 仅 1 单、W47 仅 5 单，`drilldown` 明确标记 `small_sample: true`；国家维度返回的警告也提示"订单数少于 30 的分组，变化可能是偶然波动"。
- **百分比幅度 ≫ 绝对金额**：荷兰占 W47 全站 GMV 的 **3.570938%**，占 W48 仅 **0.033615%**（`calculate`）。
- **本周可正常对比**：两周交易天数均为 6 天（`metric_summary`）；数据止于 2011-12-09 12:50，不完整周是 2009-W49 和 2011-W49，W48 完整；`data_quality_overview` 的停业记录（如 2011-04-21 至 2011-04-26）不在本周。
- **不是极端大额行导致**：`data_quality_overview` 的人工复核清单中，581483（168,469.60，2011-12-09，属 2011-W49）、541431（77,183.60，2011-01-18，属 2011-W03）均不在 2011-W48，且不属于荷兰。
- **另一个更值得关注的事**：全站新客 GMV 19,446.50 → 10,050.46（**-9,396.04，-48.32%**，订单 43→36），老客 +12,380.36（`drilldown` customer_type）；`decompose_gmv` 的 Shapley 值显示可识别客单价贡献 -13,088.20，为最大负项。该量级与荷兰跌幅接近，但工具**没有"国家 × 新老客"交叉表**，不能直接归因给荷兰，只能作为待验证假设。

## 四、建议下一步

1. **拉荷兰订单级明细**（发票号、客户 ID、金额）：确认 W45 / W47 是不是同 1~2 个客户的周期性大单。若是，荷兰应改看"订单数 / 活跃客户数"，而不是 GMV 绝对值和百分比。
2. **向业务确认**：W47 那几笔荷兰大单的客户是否延期、流失或改由其他渠道下单；W48 唯一那笔 104.00 的订单属于新客还是老客（待业务确认）。
3. **监控口径调整**：国家维度对 <30 单分组不看 GMV 百分比，改看订单数 + 大额订单清单。
4. **单独立项跟进全站新客 GMV -48.32%**：它对大盘的影响远大于荷兰，需要商品 / 渠道 / 流量数据支撑。

## 五、可信度自评

**说明局限后分享。** 能确定的是：荷兰跌幅 = 订单从 5 单降到 1 单，且与取消无关，环比/同比呈现同一形态；不能确定的是具体是哪个客户、为什么没来——荷兰 1/5 单属于极小样本，现有工具数据无法确认。
