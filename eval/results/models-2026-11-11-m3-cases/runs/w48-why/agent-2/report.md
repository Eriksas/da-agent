## 需要注意

- **口径**：GMV 为下单口径（数量×单价，含之后被取消的订单）；净销售额 = GMV − 取消金额。取消金额统计的是"当周 C 开头发票"的金额，**可能对应更早下的订单**，因此取消率下降与本周下单质量并非严格对应。
- **抵消效应**：本周多个分组方向相反且幅度大，单个分组贡献占比超过 100% 或为负是正常的（`drilldown` 已标注警告）。不要只看英国 +14,297.73 就下结论。
- **样本不足**：荷兰、日本、法国、西班牙，以及 CHILLI LIGHTS、COOK WITH WINE METAL SIGN、HEART OF WICKER LARGE、缺客户 ID 分组均被标记 small_sample，其变化可能是偶然波动。
- **数据质量**（`data_quality_overview`）：本数据集清洗后共 1,003,357 行销售、39,516 个订单、5,852 个客户；R08 规则下缺客户 ID 的行有 243,007 行，W48 单周缺客户 ID 的 GMV 占比达 20.22%，这部分订单**不计入活跃客户、复购和人均订单**，会低估或扭曲客群结构分析。
- **极端大额订单复核清单**：581483（168,469.60）、541431（77,183.60）、556444（38,970.00）、530715（15,818.40）等。**经核对这些发票的日期均不在 2011-W48（581483 落在 2011-12-09，属不完整的 2011-W49），故不影响本周结论**；但它们会显著影响跨周对比，做同比或月报时需单独剔除。
- **2011-W49 为不完整周**（最后一条记录 2011-12-09 12:50），若看到"W49 数据暴跌"，属数据截断，不是业务下滑。
- **同比基数可比性**：2010-W48 距数据起点不足 52 周，起点前的购买不可见，部分老客会被误算为新客——**新客同比 -42.59% 这个数字存在低估可能**。
- 以上均为**同期对比的关联性描述**，数据中没有实验或对照设计，不能据此断言因果。

## 建议下一步

1. **优先查拉新**：新客数 WoW -16.22%、YoY -42.59%，且新客 GMV -48.32%。需要拉渠道/流量来源（自然搜索、邮件营销、联盟、付费）分渠道的曝光与转化数据，看是流量减少还是转化下滑。
2. **查荷兰大单是否为一次性事件**：核实 W47 荷兰 GMV 从 W46 的 457.74 元（3 单）跳升到 10,798.24 元（5 单）、单均从 152.58 元跳到 2,159.65 元的原因（是否为大额/批发/礼品型订单），以及 W48 回落至 104.0 元（1 单）后是否还会重现。如果属偶发，建议在看板里给大额订单加"剔除后 GMV"口径，避免每周环比都被这类订单干扰。
3. **盯住客单价**：可识别客户客单价 -5.19%，可能是订单结构向低价品（如 COOK WITH WINE METAL SIGN，39 单仅 2,417.11）迁移，也可能是促销折扣加深。建议拆到"品类/价格带"维度看 AOV 构成。
4. **核查缺失客户 ID**：本周 20.22% 的 GMV 无法归因，占比不低。建议排查下单流程中客户 ID 写入失败的场景——这既是数据问题，也可能是移动端/游客下单体验问题。
5. **盯住 W49 全周数据**：等 2011-W49 补齐后重跑一次环比，确认 +2.31% 的回升是趋势还是单周噪声；同时注意圣诞季大促节奏，2010-W52/W53 有停业记录，节前后的周度对比需按交易天数做日均校正。
