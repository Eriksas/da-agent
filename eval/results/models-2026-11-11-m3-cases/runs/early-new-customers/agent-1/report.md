# 2010-W10 新客情况分析（对比上周 2010-W09）

## 1. 结论
2010-W10（对比基期 2010-W09，环比）新客**不算多，且比上周明显减少**：新客数 83 人，较上周的 116 人减少 33 人（-28.45%），降幅大于活跃客户整体降幅（-18.18%）；新客占活跃客户的比例从 39.06% 降到 34.16%，下降 4.90 个百分点。同时新客 GMV 减少 22,918.14，是本周整体 GMV 下滑的主要来源。

## 3. 需要注意（数据口径与警告）
- **⚠️ 起点效应（新客数被高估）**：2010-W10 和 2010-W09 距离数据起点（2009-12-01）都不足 52 周，起点之前的购买记录看不到，**部分老客会被误判为新客**。因此 83 和 116 这两个新客数都偏高，且"新客数绝对值"和"新客占比"在早期周次并不可靠（此警告由 metric_summary 和 drilldown 同时给出）。
- **"未知"分组样本不足**：drilldown 中"未知"组基期 36 单、当期 19 单，低于 30 单阈值，工具已标记 small_sample，其 +8,406.77 的反向贡献可能是偶然波动，不宜单独下结论。
- **无对照实验**：以上都是环比同期对比，属于"同时发生/可能的原因"，不能断定下降的具体成因。
- 其他口径：GMV 为下单口径（含后续被取消订单）；新客=首次购买落在当周的客户；老客=活跃客户数−新客数；活跃客户不含缺失客户 ID 的订单（全局缺客户 ID 的 GMV 占比 13.11%）。

4. **排查缺客户 ID 订单上升**：当期"未知"组 GMV 上升 8,406.77，建议核对这几单是否本可归属到可识别客户（可检查是否属于缺 ID 的极端大额或线下订单）。
