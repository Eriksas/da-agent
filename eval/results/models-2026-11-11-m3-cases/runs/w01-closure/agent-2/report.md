## 结论

**2011-W01（2011-01-03～01-09）的标准环比算不出来**：它的上一周 2010-W52（2010-12-27～2011-01-02）整周停业（0 个交易天、GMV = 0、订单 = 0），系统返回基期为 0、变化率为 null（metric_summary 2011-W01 wow；data_quality_overview 停业记录 2010-12-23 关门、2011-01-04 重开、间隔 12 天）。所以"GMV 从 0 涨到 130,274.65"没有业务含义，`decompose_gmv` 的环比拆解也直接报错（基期无可识别客户订单）。

换成可比基准（停业前最后一个交易周 **2010-W51**）：GMV 85,203.04 → 130,274.65，**+52.90%**（calculate 0.528991）；按日均看 21,300.76 → 26,054.93，**+22.32%**（calculate 0.223193）——**增长是真实的，但主要靠人（活跃客户 86 → 207，+140.70%），客单价基本持平**。

## 主要原因

**1）拉不动环比的第一位因素：基期停业，而非业务波动**（metric_summary 2010-W52 wow）
- 2010-W52 当期全部指标为 0：GMV 0（基期 2010-W51 为 85,203.04）、订单 0、活跃客户 0、交易天数 0（基期 4 天），工具提示"整周没有交易（停业）"。

**2）vs 2010-W51：增长由活跃客户数驱动，客单价没帮忙**（metric_summary + calculate）
- 活跃客户数 86 → 207，+140.70%（calculate 1.406977）；订单数 158 → 242，+53.16%（calculate 0.531646）。
- 客单价 539.26 → 538.33（两者基本持平）；人均订单数 1.2442 → 1.0821（2011-W01 metric_summary / 2010-W51 metric_summary）。
- 缺客户 ID 的 GMV 从 39,917.13 降到 16,801.60（占当周 GMV 12.90%，calculate 0.128971）；扣掉这部分后的"可识别客户 GMV"从 45,285.91（calculate 85203.04 − 39917.13）涨到 113,473.05（calculate 130274.65 − 16801.6），**+150.57%**（calculate 1.505703）。

**3）同比看反而是下降的，症结在客单价和新客**（metric_summary 2011-W01 yoy）

## 需要注意

- **口径警告**：任何"2011-W01 环比 GMV +100%"的说法都不可用，基期停业导致变化率无定义；本回答用 2010-W51 替代仅供参考，非官方环比。
- **交易天数不可比**：2011-W01 为 5 天（Jan 3 停业、Jan 4 重开），2010-W51 为 4 天、2010-W01 为 6 天；总量差异有一部分来自天数，比较应优先看日均 GMV。
- **缺客户 ID 的影响很大**：全库缺客户 GMV 占比 13.11%（data_quality_overview，2,575,278.90）；2011-W01 为 12.90%，但 2010-W51 高达 39,917.13/85,203.04 量级、2010-W01 仅 591.63。这使"环比 +52.90%"和"同比 -21.53%"都含有数据完整性变化的成分。
- **同比基期样本瑕疵**：2010-W01 距数据起点不足 52 周，部分老客会被算成新客，因此"新客 -79.1%（67 → 14）"可能被高估，但 79.72% 的降幅占比在方向上仍值得警惕。
- **小样本标记**：drilldown 中 79321、20679、22423、15056BL、21843、47502、22720 等分组被标记订单数少于 30（变化可能是偶然波动，不宜单独下结论）；85123A（订单 47 → 46，未标小样本）单品 -2,047.44。
- **取消率上升**：3.66%（2011-W01）vs 0.78%（2010-W01），上升 2.88 个百分点，当周取消金额 4,764.03。
- **极端大额订单不落在本周**：被标记的 541431 / C541433（77,183.60，2011-01-18）属 2011-W03，未进入 2011-W01 的 GMV。
- 本回答中的因果表述均为"同时出现/可能原因"，无对照实验支撑。
