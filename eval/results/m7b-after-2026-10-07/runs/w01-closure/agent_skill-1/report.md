# 2011-W01 GMV 环比分析

## 结论

**2011-W01 的环比无法直接计算**——它的环比基期 2010-W52 整周停业（0 个交易天，各项指标为 0，`metric_summary` 的 warnings 明确指出；`data_quality_overview` 显示 2010-12-24 至 2011-01-03 停业 12 天，最后营业日 2010-12-23、重新开业 2011-01-04），工具返回的 change_pct 为 null。从 0 算起的"增长"没有业务含义。

**若要一个可用的参照**，用停业前最后一个交易周 2010-W51 作基期：GMV 从 85,203.04 升到 130,274.65，增加 45,071.61（+52.90%，`calculate`）。但 2010-W51 本身也只有 4 个交易天（2011-W01 为 5 天），属于不完整周，**总量口径仍不可直接比较**；按日均看，日均 GMV 21,300.76 → 26,054.93（+22.32%），日均订单数 39.5 → 48.4（+22.53%），客单价 538.33 vs 539.26（几乎持平，差 -0.93，`calculate`）。**跨停业周的首尾比较受圣诞/新年假期分布影响，属于待验证假设，需业务确认假期与投放节奏。**

**同期同比（更可靠的口径）**：2011-W01 GMV 130,274.65 vs 2010-W01 的 166,010.79，**下降 35,736.14（-21.53%）**；但两天数不同（5 天 vs 6 天），日均 GMV 27,668.47 → 26,054.93，仅 -5.83%。**总量的同比降幅中有相当一部分来自少了一个交易日。**

## 主要驱动（以下为同比口径，decompose_gmv / drilldown 只支持 wow 与 yoy；wow 因基期停业无法拆解）

按 Shapley 值排序（`decompose_gmv`，总变化 -35,736.14）：

1. **可识别客户客单价：-77,797.41（占比 217.7%）** — 884.59 → 506.58。这是最大的负向因子（数据事实）。
2. **活跃客户数：+31,551.3（占比 -88.3%）** — 166 → 207 人。正向抵消项（数据事实）。
3. **缺客户 ID 的 GMV：+16,209.97（占比 -45.4%）** — 591.63 → 16,801.6，占当周 GMV 的 12.90%，而去年同期仅 0.36%（`calculate`）。这是不可忽略的抵消项：**本周 GMV 里有约 1.7 万来自无法识别客户的订单**，既不计入活跃客户数，也不能做复购分析（数据事实 + 口径提示）。
4. **人均订单数：-5,700.0（占比 15.95%）** — 1.1265 → 1.0821。

新老客拆分（`drilldown`，GMV 同比）：

- **新客：-28,487.25（-82.28%，占总变化 79.72%）**，订单 68 → 14（base_orders 68 / current 14，当期订单少于 30，标记为小样本，结论从严）
- **老客：-23,458.86（-17.94%，占总变化 65.64%）**，订单 119 → 210，样本充足
- **未知（缺客户 ID）：+16,209.97（+2739.88%）**，小样本

国家拆分（`drilldown`）：**EIRE -47,422.88（-99.56%，占总变化 132.7%）**，但基期仅 3 单、当期 1 单，小样本，不宜单独下结论；**United Kingdom +1,292.26（+1.15%）**，224 单，是唯一有足够样本且基本持平的市场；Germany +3,447.38、Australia +7,154.38（基期 0 单）均为小样本。

净销售额同比 164,721.85 → 125,510.62（-23.80%），取消率由 0.78% 升至 3.66%（+2.88 个百分点，`metric_summary`）。

## 需要注意

- **2011-W01 的"环比"没有基期**：不要在任何周报里写"环比 +130,274.65"或"环比增长 100%"。
- **2010-W51 与 2011-W01 都不完整**（4 天 / 5 天），跨停业比较只能看日均，且要写明保留。
- **同比比较天数不同**（5 vs 6 天），总量 -21.53% 与日均 -5.83% 差距很大，对外沟通应以后者为主。
- **基期 2010-W01 距数据起点不足 52 周**（数据起点 2009-12-01），起点前的购买看不到，部分老客会被算成新客——"新客 -82%"这一条要打折看，可能被左删失放大。
- **缺客户 ID 占比 12.90%**（`data_quality_overview` 全量口径 13.11%），本周该比例异常高，新老客结论受影响。
- **取消率 3.66%** 的分子（当周取消）与分母（当周 GMV）不一定是同一批订单。
- **相关系非因果**：以上都是"与……同时发生"，没有对照实验，不写"因为"。
