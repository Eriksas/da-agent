## 需要注意（数据口径与警告）

- **两个不完整周**：2009-W49（数据从 12-01 开始）和 2011-W49（数据到 12-09 12:50）不能与完整周直接比较。图 5 里 2011-W49 客单价 £950.34 就是被一笔大额单抬起来的。
- **低交易周与停业**：2009-W52 只有 3 个交易日；2009-W53、2010-W52 为 0 个交易日；三次停业分别是 2010-12-23 停业、2011-01-04 重新开张（间隔 12 天），2010-04-01 停业、2010-04-06 重新开张（间隔 5 天），2011-04-21 停业、2011-04-26 重新开张（间隔 5 天）。这些周总量天然偏低，不是"业绩下滑"。
- **新客定义有起点效应**：新客 = 首次购买落在当周的客户，越靠近数据起点越可能把老客算成新客，所以 2009-W49 的 425 个"新客"和 2010-W01 之后的新客数不是同一性质，跨年比较时要留意。
- **缺客户 ID 的规模**：按 `data_quality_overview`，2,922 笔订单、£2,575,278.90 的 GMV（占总 GMV 13.1%）没有客户 ID；这些金额计入 GMV 但不进活跃客户数。GMV 是下单口径，含之后被取消的订单；取消单按取消发生时间入账，不回溯原单所在周。
- **极端大额订单需人工复核**：发票 581483，£168,469.60，2011-12-09（落在 2011-W49）；发票 541431，£77,183.60，2011-01-18。少数大额单被很快全额取消，会抬高当周 GMV，净销售额不受影响。
- 清洗规则里删掉了完全重复行（R07，11,812 行）和单价 ≤ 0 / 数量 ≤ 0 的行（R05/R06），所以 GMV 口径偏保守。
