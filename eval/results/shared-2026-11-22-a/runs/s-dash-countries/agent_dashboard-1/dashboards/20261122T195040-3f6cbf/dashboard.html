数据说明

  • 口径：GMV 为下单口径（含之后被取消的订单）；净销售额 = GMV − 取消金额；取消率 = 取消金额 ÷ GMV，分子分母不一定是同一批订单（取消按取消发生时间入账，可能对应 2010 年下单的订单）。逐月趋势图按 line_type 分组，分别看销售行与取消行金额。
  • 期间：2011-01-04 至 2011-12-09 有数据（2010-12-23 至 2011-01-03 停业）；2011-01 与 2011-12 是不完整月份，尤其 2011-12 的取消金额含少量大额订单取消，不能与完整月份直接比。
  • 样本不足：尾部小国 2011 年 GMV 不足 £1,000、订单数仅几单到几十单（如巴林、捷克、沙特），其取消率等比率波动大，样本不足不宜据此下结论；需重点跟进的应看西班牙、日本等分母较大的市场。
  • 少数金额极大、下单后很快全部取消的订单会抬高当月 GMV 与商品排名（净销售额不受影响）；荷兰、澳大利亚的高客单价同样受少量大单影响。
  • 英国占 GMV 84.7%，图中其余市场规模被压缩，可用顶部国家筛选器下钻具体市场。
  • 取消率、客单价为比率，不能跨国家相加；订单数为去重发票数，一张订单只计一次。

一家英国线上礼品批发零售商 2009-12 至 2011-12 的商品交易明细。清洗规则已经应用： 删除了重复、坏账调整、单价为 0 等记录，运费等非商品行不在表里。金额单位是英镑。表 order_lines：每行是订单里的一个商品（销售）或取消单里的一个商品（取消）。金额和数量都是正数，用 line_type 区分。这张表和查询数据的同事用的是同一份口径配置。 注意： - 周是 ISO 周；数据截止到 2011-12-09（周五），所以 2011-W49 不是完整的一周，和完整的周比总量会偏低。 - 2010-12-23 到 2011-01-03 停业，这期间没有数据。 - 约四分之一的行缺客户 ID：按客户统计（活跃客户、新老客）时这些行不计入，但它们的金额计入 GMV。 - 取消单按取消发生的时间入账，不回溯到原订单所在的周。 - 有少数金额极大、下单后很快又全部取消的订单（例如发票 541431、581483），会抬高当周的 GMV 和商品排名；净销售额不受影响。
