数据说明

  • 口径：取消金额＝当周 C 开头取消单的商品行金额（取正）；取消率＝取消金额÷当周 GMV（GMV 是下单口径，含之后被取消的订单）。取消单按取消发生时间入账、不回溯原订单所在周，所以分子分母不是同一批订单。
  • 期间固定为 2009-12-01 至 2011-12-04，即 ISO 周 2009-W49 至 2011-W48；2011-W49 不完整（数据只到 2011-12-09）未纳入，2009-W49 只含 12 月 1 日起的数据，不能和完整周直接比。
  • 2010-12-23 至 2011-01-03 停业，这几周没有数据，周度图上的空档即此原因。
  • 少数金额极大、下单后很快全额取消的订单（如发票 541431、581483）会抬高所在周和国家的取消金额与取消率，2011-W03 取消率明显偏高与此有关。
  • 英国一国占全部取消金额的 84.6%，其余国家的条形会被压得很小，可用页面上的国家筛选器单独查看某个国家。
  • “取消单数”按 C 开头发票号去重统计（取消行没有订单号），与公司固定报表里的订单数口径不同。

一家英国线上礼品批发零售商 2009-12 至 2011-12 的商品交易明细。清洗规则已经应用： 删除了重复、坏账调整、单价为 0 等记录，运费等非商品行不在表里。金额单位是英镑。表 order_lines：每行是订单里的一个商品（销售）或取消单里的一个商品（取消）。金额和数量都是正数，用 line_type 区分。这张表和查询数据的同事用的是同一份口径配置。 注意： - 周是 ISO 周；数据截止到 2011-12-09（周五），所以 2011-W49 不是完整的一周，和完整的周比总量会偏低。 - 2010-12-23 到 2011-01-03 停业，这期间没有数据。 - 约四分之一的行缺客户 ID：按客户统计（活跃客户、新老客）时这些行不计入，但它们的金额计入 GMV。 - 取消单按取消发生的时间入账，不回溯到原订单所在的周。 - 有少数金额极大、下单后很快又全部取消的订单（例如发票 541431、581483），会抬高当周的 GMV 和商品排名；净销售额不受影响。
