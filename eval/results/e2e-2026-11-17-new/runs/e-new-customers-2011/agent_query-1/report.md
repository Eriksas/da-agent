## 需要注意

- **2011 年不是完整自然年**：数据止于 2011-12-09 12:50，2011-W49 不完整，12 月只有 9 天，因此 12 月的新客数（28 人）和 GMV（£23,477.36）明显偏低，不能与整月直接比较；上述"全年"数字均未覆盖 12/10–12/31。
- **停业影响**：2010-12-23 至 2011-01-03 停业，1 月数据从 1 月 4 日才开始（data_quality_overview）。
- **老客判定回溯有限**：数据起点是 2009-12-01，无法识别此前（2009-12 之前）已购买过的客户，可能把一部分老客误记为 2011 新客；相应地 2,677 位老客是下限。
- **口径**：GMV 为下单口径、含之后被取消的订单（取消行计 0），未扣取消金额；极端大额行（如发票 581483，£168,469.60，2011-12-09）仍在 GMV 中且需人工复核（data_quality_overview 的 R09 清单）。
- **无 ID 订单不可归属**：2011 年约 13.72% 的 GMV（£1,299,552.88）来自没有客户 ID 的订单，既不算新客也不算老客，新客 GMV 不等于"新客贡献的全部收入"。
- 取数方另提示：若把取消行也当作"首单"判断，新客数会有小幅差异（该差异数字未经程序核对，此处不引用）。
- 以上均为同期对比与结构统计，**不含因果结论**——无法据此断言"哪项营销动作带来了新客"。

## 建议下一步

1. 用 metric_summary / drilldown 看 2011 年各周新客数与 GMV 的走势（尤其 2011-W36 至 2011-W48 与 2011-W49），定位 9–11 月获客高峰以及 12 月数据截断的影响。

3. 用 drilldown(dimension=product / country) 看新客集中在哪些商品和国家，判断新客质量是否低于老客（对比人均 £1,075.19 与老客人均水平）。
4. 把大额后取消订单（581483 等）单独做敏感性分析：新客 GMV 剔除这些行后的稳健性再复核。
5. 对 13.72% 无 ID 订单，评估是否能在下单流程中提高客户 ID 采集率，否则"新客/老客"的结构分析永远有盲区。
