# 2011-W22 GMV 环比分析

## 1. 结论

**这不是一次业务事故，而是"少了一个交易日"+"5 月末季节性淡季"叠加的结果。** 表面上看 GMV 从 159,463.82 跌到 115,065.00（-27.84%），但 W22 只有 **5 个交易日**，W21 有 6 个（tool: metric_summary）。按日均口径，跌幅只有 **-13.41%**（26,577.30 → 23,013.00），而且 2011-W23 已经反弹到 214,478.31（+86.40%）。

真正值得关注的不是总量，而是**人均下单频次**：日均活跃客户几乎持平（-2.15%），日均订单却掉了 -11.2%，说明问题出在老客"来得少了、买得更少了"，而不是客户大量流失。

## 2. 主要原因（按贡献排序）

**① 少一个交易日，贡献了降幅的 59.86%**
- 环比总降幅 -44,398.82（metric_summary）
- 基期日均 GMV 26,577.30，缺一天即约 26,577.30，占总降幅 **59.86%**（calculate）
- 若 W22 也有 6 个交易日、按当前日均 23,013.00 折算，整周应为 **138,078.00**，仍比 W21 低 13.41%（calculate + metric_summary）
- 该 5 天结构**每年都出现**：2010-W22 同样是 5 天 vs 2010-W21 的 6 天，当期也跌 -31.15%（metric_summary）——典型的月末假日/周末造成的自然节奏

**② 老客下滑是绝对主力（98.69% 的降幅）**
- 老客 GMV 137,421.07 → 93,603.39，**-43,817.68（-31.89%）**，占 GMV 总变化的 98.69%（drilldown）
- 老客数 243 → 191（-52）；而新客 17 → 21（+4）、新客 GMV 5,043.26 → 7,219.73（+43.16%）反而是涨的
- 拆解（decompose_gmv，Shapley）：活跃客户数 -24,548.60（55.29%）、人均订单数 -12,590.53（28.36%）、可识别客单价 -4,502.08（10.14%）、缺客户 ID 的 GMV -2,757.61（6.21%）
- **校正天数后的关键洞察**（calculate）：日均活跃客户 43.333333 → 42.4（**-2.15%**，基本持平），但日均订单变化为 **-11.2%**（订单总数 350 → 259，calculate）；人均订单数 1.2462 → 1.1226（-9.91%）。即**流量没掉，是购买频次掉了**

**③ 英国本土市场是主战场（93.79% 的降幅）**
- United Kingdom 137,820.66 → 96,176.99，**-41,643.67（-30.22%）**，占降幅 93.79%（drilldown）
- 其余国家样本都极小（Netherlands 2→5 单、EIRE 4→0 单等，均标注 small_sample），且前 8 名以外 8 个分组合计反而 +1,767.84 —— **不是国家结构问题，是本土大盘问题**

**④ 客单价小幅走低，不是主因**
- 客单价 455.61 → 444.27（-2.49%）；可识别客单价 439.70 → 423.63（decompose_gmv）
- 净销售额 157,659.72 → 113,356.54（-28.10%），与 GMV 同步；取消金额 1,804.10 → 1,708.46 反而下降，取消率 1.13% → 1.48%（+0.35pp）——**取消/退款不是本次下滑的原因**

**⑤ 商品端是分散的普跌，非单品塌方**
- 跌幅前列的 DOG BOWL CHASING BALL DESIGN（-3,148.83，1 单）、ILLUSTRATED CAT BOWL（-2,419.32，4 单）等均为 small_sample；前 8 名以外 2,019 个分组合计 -25,956.71，占 58.46%（drilldown）
- 唯一样本充足的 PARTY BUNTING（47→45 单）为 -2,325.39（-49.98%），属正常波动

## 3. 需要注意（口径与警告）

- **交易日差异是最大干扰项**（metric_summary / decompose_gmv / drilldown 三处均给出同一条 warning）：所有总量指标必须同时看日均，否则会高估严重程度
- **数据质量口径**（data_quality_overview）：数据区间 2009-12-01 至 2011-12-09，共 106 周；全量缺客户 ID 的 GMV 占比 13.11%，**W22 本身有 14,241.88 元的 GMV 缺客户 ID，占当周 GMV 的 12.38%**（calculate），因此"活跃客户数 212"本身低估了真实购买人数，老客/新客拆分也有盲区
- **R08 规则**：缺客户 ID 计入 GMV 和订单数，但不计入活跃客户/复购/人均订单 —— 所以人均订单数 1.1226 是"可识别客户口径"，与总订单数 259 不同源
- **极端大额订单不在 W22，而在 W23**：2011-W23 含发票 556444（PICNIC BASKET WICKER 60 PIECES）38,970.00，被人工调整冲销，GMV 和净销售额都含它、净销售额偏高 —— **因此 W23 的真实反弹幅度比 +86.40% 还大**（metric_summary warning）
- 历史闭店记录（圣诞、2011-04-21～04-26 等）中**未包含 2011 年 5 月末的闭店**，因此 W22 少掉的这一天具体是哪个日期、是否因假日，工具未提供，需人工核对
- **无对照实验，以上均为同期共现的拆解，不构成因果结论**

## 4. 建议下一步

1. **先确认那一天的缺口**：调取 W22 逐日 GMV/订单，确认缺失日期是否为国家法定假日（若是，环比应改为"按可比营业日"口径对比）
2. **用同比校准季节性**：W22 同比 **+7.94%**（106,601.91 → 115,065.00），两年同为 5 个交易日，说明 W22 本就是年度结构性低点，**不需要按事故级别处理**
3. **重点排查老客购买频次**：人均订单数 -9.91% 是唯一实质性走弱的指标。建议看老客分层（RFM）、邮件/推送触达与折扣投放、站内搜索与结账漏斗，验证是否存在流量承接或促销断档
4. **核对 W20 的高基数**：W19 204,717.07 → W20 210,335.39 → W21 159,463.82（-24.19%，两天数相同，是真实下跌）→ W22 115,065.00。W20 是否有一场大促/活动？若 W21 的跌幅主要来自 W20 的透支，则需把这波"两连降"合并复盘
5. **补齐客户 ID**：当周 12.38% 的 GMV 无客户 ID，建议排查埋点/线下订单导入链路，否则后续客户级归因会持续失真
