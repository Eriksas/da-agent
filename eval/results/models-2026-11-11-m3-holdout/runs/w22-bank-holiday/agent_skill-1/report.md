# 2011-W22 GMV 环比下降近三成 — 诊断结论

> 分析周：**2011-W22**，基期 **2011-W21**（数据来自 `metric_summary`，环比口径）。同比参考为 2010-W22。

## 1. 结论

GMV 从 W21 的 159,463.82 降到 W22 的 **115,065.00**，减少 44,398.82（**-27.84%**），但**两周交易天数不同（W22 只有 5 天，W21 有 6 天），总量不可直接比较**：日均 GMV 26,577.30 → 23,013.00，实际只跌 **-13.41%**（`metric_summary` 警告）。

按 W22 自身日均水平把缺失的那 1 个交易日补回来，可解释总降幅的 **51.83%**；剩下的缺口 **21,385.82**（占总降幅 **48.17%**，`calculate`）才是真实走弱的部分，来自**活跃客户数减少（-48 人）和人均订单数下降（-0.12 单）**，集中在**英国老客**，且**不是单一商品、也不是取消单造成的**。

补充背景：W21 本身日均已比 W20 下滑 **-24.19%**（35,055.90 → 26,577.30，`calculate`），W23 又回升到 214,478.31（日均 35,746.39）。所以 W22 更像一次**短两周回落 + 日历性少一天**，而不是业务持续崩塌；但回落原因（客户数、人均单量）需要业务侧确认。

**下钻（`drilldown`）**

- **国家**：**United Kingdom -41,643.67（-30.22%），占总变化 93.79%**，订单 315 → 232 单（样本充足）。其余国家全部为小样本（Netherlands 2→5 单、EIRE 4→0 单、Poland 2→1 单等），**不对其单独下结论**；前 10 名以外 6 个国家合计 **+498.75**（抵消项）。跌幅集中在主力市场英国。
- **新老客**：**老客 -43,817.68（-31.89%），占总变化 98.69%**，订单 303 → 216 单（样本充足）；**新客 +2,176.47（+43.16%）是唯一的正贡献抵消项**，但仅 21→22 单（样本不足，只作为方向参考）；"未知"（缺客户 ID）-2,757.61，26→21 单（样本不足）。
- **商品**：**没有单品主导**。前 8 名合计中 7 个订单数 < 30（样本不足），其中 DOG BOWL、ILLUSTRATED CAT BOWL 等近乎归零的商品贡献均在 5% 左右；样本充足的只有 PARTY BUNTING -2,325.39（-49.98%，占 5.24%）；前 8 名以外 2019 个分组合计 **-25,956.71（58.46%）**——**是普跌而非个别商品断货**。

## 3. 需要注意（口径与警告）

- **不可直接比较**：W22 5 天 vs W21 6 天，总量 -27.84% 中有相当一部分是日历差异，日均口径才是 -13.41%（`metric_summary`、`decompose_gmv`、`drilldown` 三处均返回同一警告）。
- **缺哪一天未确认**：`data_quality_overview` 未把 2011-W22 列入停业周或低交易周（停业记录为 2009-12-23、2010-04-01、2010-12-23、2011-04-21 四段），工具也未提供逐日明细。W22 少掉的这一天是不是节假日/周末营业安排，**待业务确认**。
- **取消不是原因**：取消金额 1,804.10 → 1,708.46（-5.30%），取消率 1.13% → 1.48%（+0.35 个百分点），净销售额 -44,303.18（-28.10%）与 GMV 同步下滑；且取消率的分子分母不一定是同一批订单。
- **左右邻周有干扰**：W23 含极端大额行发票 **556444（PICNIC BASKET WICKER 60 PIECES）38,970.00**（被人工调整冲销，GMV 与净销售额都含它），所以 W23 的回升被抬高；剔除该行后 W23 日均 GMV 为 **29,251.39**（`(214478.31 - 38970.00) / 6`），仍高于 W22 的 23,013.00。W22 本身**没有**极端大额行警告。
- **同比看并不差**：W22 vs 2010-W22（两周同为 5 天）GMV 115,065.00 vs 106,601.91，**+7.94%**，日均同幅度 +7.94%；订单数 -6.16%，客单价 +15.02%。
- **小样本与左删失**：所有订单数 < 30 的国家/新老客/商品分组均不下结论；新老客分组的"新客"数接近数据起点可能有左删失影响，新老客结论从严。
- **相关不等于因果**：以上均为同期变动的结构拆解，**没有对照实验，不能说"某因素导致"下降**，业务原因只能作为待验证假设。

## 4. 建议下一步

1. **先确认日历因素**：调 W21、W22、W23 的逐日 GMV/订单明细，定位 W22 缺失的具体日期，并核对是否有节假日、渠道停运或备货节奏调整。这决定"近三成"里有多少是真跌。
2. **查 W21 的先行走弱**（日均 -24.19%，活跃客户 347 → 260）：确认流量、投放、邮件触达、站外渠道是否在 W21 前后有调整——W21+W22 连续两周走弱，更像一次**持续两周的业务动作**而非随机波动。
3. **定位老客掉量**：老客 243 → 191 人（-52）、人均订单 1.2462 → 1.1226 单，是否有大客户流失、订单推迟到 W23，或复购触达没做；W22 活跃客户 212 → W23 333 的回升支持"部分需求后移"的可能（待验证）。
4. **核查极端值与缺失客户 ID**：W22 缺客户 ID 的 GMV 14,241.88，占当周 GMV 的 **12.38%**（`calculate`），确认这批订单的来源；并复核 38,970.00 的 556444 在报表口径上是否应计入。
5. **周报口径固化**：对外汇报"GMV 涨跌"时固定同时给出日均 GMV 与活跃客户数，避免把少一天说成"跌了三成"。

## 5. 可信度自评

**说明局限后分享**：数字与拆解结构（来自 `metric_summary`/`decompose_gmv`/`drilldown`）可靠且可复核，但"近三成"这一表述需要先标注少 1 个交易日；且缺少逐日明细、渠道与客户级数据，业务原因只能停留在假设层面，不能作为定性结论发出。
