**问题：** 2011-W41 的 GMV 为什么下降？

## 结论

分析的是 **2011-W41**（10/10–10/16）对比上一周 **2011-W40**：GMV 从 310,948.14 降到 **221,268.10**，减少 **89,680.04（-28.84%）**（metric_summary，wow）。

但这更像是 **W40 高基数之后的回落**，而不是生意塌陷：W39 GMV 为 206,510.83 → W40 跳到 310,948.14（+50.57%，其中客单价 +36.07%）→ W41 回落 221,268.10 → W42 又回升到 264,358.21（+19.47%，客单价 +20.01%）（metric_summary）。W41 仍高于 W39。

跌幅结构非常明确：**不是订单流失，是"大单/高客单订单"这一周没出现**——订单数只掉 40 单（-8.2%），而客单价从 637.19 掉到 493.90（-143.29，**-22.49%**）（metric_summary）。

## 主要原因

按 Shapley 分解（decompose_gmv，环比，合计 = -89,680.04）：

| 因子 | 贡献金额 | 占总变化 |
|---|---|---|
| 可识别客户客单价 | **-64,806.36** | **72.26%** |
| 活跃客户数 | -18,862.10 | 21.03% |
| 人均订单数 | -6,336.97 | 7.07% |
| 缺客户 ID 的 GMV | +325.39 | -0.36% |

1. **客单价是绝对主因（72.26%）**：可识别客户客单价 620.17 → 474.49（decompose_gmv base/current）。具体看是英国和老客：
   - 英国客单价 616.57 → 460.71（calculate，269,442.02/437 → 181,060.91/393）；英国 GMV 269,442.02 → 181,060.91（-88,381.11，**占总变化 98.55%**），英国占本周 GMV 的 81.83%（drilldown / calculate）。
   - 老客客单价 667.34 → 469.29（calculate，260,929.47/391 → 175,044.94/373）；老客 GMV -85,884.53（-32.91%），**占总变化 95.77%**，而老客订单只从 391 掉到 373（drilldown，customer_type）。
2. **客户数减少（21.03%）**：活跃客户 389 → 360（-29，-7.46%）；其中新客 67 → 49（-18，-26.87%），老客 322 → 311（-11）（metric_summary）。新客减少主要体现在订单数（新客订单 77 → 49，drilldown）。
3. **人均下单频次略降（7.07%）**：1.2031 → 1.1722（-2.57%）（metric_summary / decompose_gmv）。
4. **商品维度高度分散，不是单品断货**：跌幅前 8 名商品每个仅贡献 2.0%–4.5%（如 DOORMAT KEEP CALM AND COME IN -4,037.00，占 4.5%）；其余 2,490 个 SKU 合计 -71,127.17，占 79.31%（drilldown，product）——说明是"整体大单变少"，而非某个爆款断货。
5. **国家结构上只有英国是真跌**：澳洲从 17,150.53 归零（占 19.12%）但 W40 也只有 4 单，属小样本；德国 -3,750.43（16 单，小样本）；EIRE +5,906.03、法国 +3,283.04、西班牙 +3,161.54、塞浦路斯 +2,017.56 等逆势增长，14 个其他分组合计 +3,138.61（drilldown，country）。

## 需要注意

- **同比也在下降**，不是单纯环比基数问题：vs 2010-W41，GMV 221,268.10 vs 308,215.36（-86,947.26，**-28.21%**），订单 560 → 448（-112，-20%），客单价 -10.26%，活跃客户 -19.64%，新客 -46.74%（metric_summary，yoy）。同期 W40 是个异常高点，因此环比与同比同时为负。
- **净销售额降幅更大**：净销售额 204,251.49 vs 300,307.48（-96,055.99，-31.99%），因为取消金额从 10,640.66 升到 17,016.61（+6,375.95，+59.92%），取消率 3.42% → 7.69%（+4.27 个百分点）（metric_summary）。注意口径：取消金额是"当周 C 开头发票中的商品行金额，可能对应更早下的订单"，所以 W41 的取消里可能包含 W40 订单的退单——这只是同时出现的现象，需要核对明细后才能判断，不能据此下因果结论。
- **口径与数据质量警告**：
  - drilldown 明确警告：部分分组订单数少于 30（澳洲 4 单、EIRE 2 单、西班牙 1 单、塞浦路斯 1 单等），变化可能是偶然波动，不宜单独下结论。
  - metric_summary（yoy）警告：基期 2010-W41 距数据起点不足 52 周，部分老客会被算成新客。
  - GMV 为"下单口径"（含之后被取消的订单）；缺客户 ID 的订单计入 GMV/订单数但不计入活跃客户与复购，整体缺客户 ID GMV 占比 13.11%（data_quality_overview，R08）。
  - 清洗规则会影响绝对值：完全重复行删除 11,812 行、单价 ≤ 0 删除 6,207 行、非商品编码 5,913 行不计入 GMV 等（R01–R10）。
  - 交易天数两周都是 6 天，日均 GMV 同步下降 28.84%（51,824.69 → 36,878.02），**不存在少营业一天**的问题；数据中的不完整周（2009-W49、2011-W49）、停业（2009-12-23~2010-01-04、2010-12-23~2011-01-04、2011-04-21~04-26）均不落在 W40/W41。
  - 极端大额行清单中最近的记录为 2011-06-10 的 556444（38,970.00），不在 W40/W41；即 W41 未命中人工复核大单标记（但该清单仅 38 条，属阈值筛查）。
- 以上都是观测性对比，**没有对照实验，因此只能表述为"与……同时发生 / 可能的原因"，不能断定因果**。

## 建议下一步

1. **拉 W40 与 W41 的订单级明细**，定位英国客单价下降中贡献最大的若干笔大单（哪些客户、哪些 SKU、是否为大额批量采购），这是确认"大单未复现"的关键一步。
2. **核对 W41 的 17,016.61 取消金额对应的下单周**，若主要来自 W40，则 W40 的 GMV 存在"虚高"，复盘应改用净销售额口径，避免用 W40 做基期造成误判。
3. **确认 W40 是否有一次性事件**（促销、批量/团购订单、渠道活动）；结合 W39（206,510.83）与 W42（264,358.21）看是活动脉冲还是数据波动，再决定是否需要干预。
4. **新客单独立跟进**：新客 67 → 49、新客订单 77 → 49（含缺客户 ID 订单 26 单），需要查新客获取渠道与归因是否失效。
5. **把客单价拆成单价与件数**（目前工具只能给 GMV/订单口径客单价），判断是价格下行还是大件商品结构变化。
6. 若希望量化"客单价回补"的收益上限，可用 ab_sample_size / ab_proportion_test 在拿到真实实验分组数据后，评估提客单策略（提升 AOV 或凑单门槛）的效果——但注意这需要你提供实际的对照组/实验组转化数据。
