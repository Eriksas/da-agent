# 2011-W10 澳洲市场诊断（环比 2011-W09）

## 结论

**澳洲市场没有"出问题"——这是一个单笔订单造成的统计假象，不是趋势性下滑。** 澳洲在 W09 和 W10 **各只有 1 单**：W09 是 1 笔 16,726.84 的大单，W10 是 1 笔 210.90 的小单（`drilldown` 国家维度，两周均标记 `small_sample: true`）。跌掉的 16,515.94 全部来自"上一周那笔大单没有重复"，属于基数问题。

需要先纠正一个前提：**2011-W10 整体 GMV 是上涨的，不是下跌**——GMV 129,034.74，环比 +1,446.39（+1.13%），订单数 290（+2.47%），净销售额 127,570.42（+1.07%），两周交易天数均为 6 天，`metric_summary` 无任何 warnings。

## 主要驱动

**1. 澳洲：单笔订单的基数效应（数据事实 + 推断）**
- W08→W09→W10 澳洲 GMV：412.55（1 单）→ 16,726.84（1 单，+16,314.29）→ 210.90（1 单，-16,515.94，-98.74%）（`drilldown` 国家维度，2011-W09 与 2011-W10 两次环比）
- 澳洲占整体 GMV 比重：W09 **13.11%** → W10 **0.16%**（`calculate`）
- 剔除澳洲后，整体 GMV 变化为 **+17,962.33（+16.20%）**，而非 +1.13%（`calculate`）
- 推断依据：澳洲周订单量长期为 1 单，单笔金额在 210.90–16,726.84 之间大幅跳动；W10 的 210.90 反而与 W08 的 412.55 属同一量级，**W09 的大单才是异常值**。同比下钻中澳洲未进入前 10 名变化分组（末位为意大利 -580.08），据此反推澳洲 2010-W10 的 GMV 上限约 790.98，说明 W10 水平与去年相当（`drilldown` 同比口径 + `calculate`）。

**2. 英国：本周增长的真正来源（数据事实）**
- 英国 GMV 93,840.57 → 113,152.47，**+19,311.90（+20.58%）**，订单 250 → 268（`drilldown`），是唯一订单数超过 30 的分组，也是抵消澳洲跌幅的主要力量。

**3. 整体拆解：结构上是"客户数降、人均单数升"（数据事实，`decompose_gmv` Shapley）**
| 因子 | Shapley 贡献 | 说明 |
|---|---|---|
| 缺客户 ID 的 GMV | +8,323.00 | 未识别订单增长，对应部分大额单 |
| 人均订单数 | +7,148.75 | 1.095 → 1.1674 |
| 活跃客户数 | -7,144.05 | 242 → 227（-6.2%），主因是**老客减少 16 人（-7.96%）**，新客 42 人基本持平 |
| 可识别客户客单价 | -6,881.30 | 434.14 → 408.19 |

**4. 抵消项（不能只看最大一项）**
- 芬兰 -4,418.02（2 单→0）、法国 -2,126.04（9 单→2）、比利时 -984.07（3 单→0）均为低订单分组；工具 warnings 明确提示"订单数少于 30，变化可能是偶然波动，不宜单独下结论"。
- 同时 EIRE +2,435.38、Channel Islands +1,851.65、葡萄牙 +1,357.94、德国 +1,039.83 等正向贡献抵消了部分下滑——这正是各国变化贡献占比会为负或远超 100% 的原因：按工具口径（变化额 ÷ 总变化额），澳洲为 **-1,141.87%**（原始值 -11.4187）、英国为 **+1,335.18%**（原始值 13.3518），均由 `calculate` 换算。

## 需要注意

- **澳洲分组样本不足**：工具直接标注 `small_sample: true`，澳洲两周各 1 单，不足以支撑"市场出问题"的结论，也不应对其单独下业务结论。
- **取消金额口径**：澳洲 W09 取消金额 168.70、W10 为 0（`drilldown` 取消金额维度），说明 W09 那笔 16,726.84 并未被取消，是真实成交后未复购。
- **未命中极端大额行清单**：该单未出现在 `data_quality_overview` 的 extreme_lines 人工复核清单中（清单内含 581483 的 168,469.60、541431 的 77,183.60、556444 的 38,970.00、530715 的 15,818.40，均不属本周澳洲单）。但它仍属单笔占比极高的订单。
- **"缺客户 ID 的 GMV"占比**：全量数据缺客户 ID 订单占 13.11%（`data_quality_overview`），该部分 GMV 环比增加 8,323.00，share_of_total_change 为 5.7543，即 **+575.43%**（`calculate`），是整体正增长的主要来源，但无法归因到具体国家和客群，需人工核查。
- **2011-W10 无数据质量问题**：该周非部分周、不在停业窗口（2011-04-21 停业至 04-26 属 W17）、非节假日短周，两周交易天数一致（均为 6 天），可直接环比。

## 建议下一步

1. **查这 1 笔澳洲订单明细**：确认 16,726.84 的客户与商品，判断是常规批发/团购客户的一次性补货，还是该市场流失的真实信号——这决定后续是继续忽略还是启动客户挽回。
2. **看澳洲更长周期的月度趋势**（如连续 8–12 周 GMV 与订单数），判断澳洲是"稳定 1 单/周的小市场"还是"偶发大客户市场"；当前只有 3 周数据（412.55 / 16,726.84 / 210.90）。
3. **补齐澳洲订单数**：澳洲订单量长期为 1 单，任何单周 GMV 波动都会产生 98% 级别的假涨假跌，建议对订单数 < 30 的国家统一用"绝对金额 + 订单数"双口径看，或直接不作为结论依据。
4. **追查缺客户 ID 的 8,323.00 增量**（占本周总变化 +575.43%），确认是否有订单因客户 ID 缺失导致无法归因到国家和客群。
5. **老客流失值得单独跟**：活跃客户 -15 人中老客占 -16 人、新客仅 +1 人，这是唯一带有"经营性"信号的结构性变化，与澳洲无关，但更值得关注。
