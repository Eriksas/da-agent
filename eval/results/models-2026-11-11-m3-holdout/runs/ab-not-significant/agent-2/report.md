## 结论

**不能判定新版本更好。** 实验组转化率 6.5%、对照组 6.0%，相对提升 8.33%，但两比例 z 检验 **p = 0.191418，在 α = 0.05 下不显著**（ab_proportion_test）。当前样本量（每组 8000 人）不足以区分 0.5pp 的真实提升和随机波动。

## 主要原因（数字均来自 ab_proportion_test / calculate）

1. **差异本身很小，且置信区间跨零**
   - 绝对差 = 0.005（calculate：520/8000 − 480/8000），即 +0.5pp；相对提升 0.083333（+8.33%）
   - 95% 置信区间 **[−0.002501, 0.012501]**，即 −0.25pp ~ +1.25pp，区间包含 0
   - z = 1.3064，p = 0.191418，significant = false

2. **分流没问题，差异不是分流造成的**
   - SRM 检查：实际对照组占比 0.5、实验组 0.5，期望各 8000，chi2 = 0.0，p_value = 1.0，sample_ratio_mismatch = false → “样本比例与设计相符”
   - 即：实验设计（50/50、每组 8000）执行到位，结论不显著是**统计功效不足**，不是分流故障

3. **样本量不够（ab_sample_size，α=0.05、power=0.8）**
   - 基线 6% 想要检测 **0.5pp** 的提升：每组需 **36,791** 人（合计 73,582）→ 当前每组 8000 人远不够
   - 基线 6% 想要检测 **1pp** 的提升：每组需 **9,540** 人（合计 19,080）→ 当前每组 8000 人仍略少

## 需要注意

- 上面 8.33% 的相对提升是基于实验组比对照组多出的 **40** 个下单（calculate：520 − 480 = 40）这一很小的事件差异，请勿在汇报中当作已验证的收益使用。
- 转化率只衡量“是否下单”。新版详情页是否影响客单价、GMV/访客、退款率等，本次数据完全没有覆盖，不能由转化率外推。
