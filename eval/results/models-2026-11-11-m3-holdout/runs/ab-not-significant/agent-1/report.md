## 结论

**目前的数据还不足以说新版本更好。** 实验组下单率 0.065（520/8000），对照组 0.06（480/8000），点估计是 +0.5 个百分点（相对提升 8.33%），但两比例 z 检验 **p = 0.191418，不显著**（95% 置信区间 [-0.002501, 0.012501]，跨过 0），即这个提升与随机波动无法区分。

## 主要原因（按检验结果）

- **差异幅度与不确定度（来自 ab_proportion_test）**
  - 对照组下单率 0.06，实验组 0.065，difference = 0.005，relative_lift = 0.083333
  - z = 1.3064，p_value = 0.191418，significant = false
  - 95% 置信区间 [-0.002501, 0.012501]：真实效果可能是在 -0.25pp 到 +1.25pp 之间
  - 该工具 warnings 为空，即没有触发实验数据告警

- **分流是干净的（来自 ab_proportion_test 的 SRM 检查）**
  - 观测分流 50%/50%，期望 50%/50%，chi2 = 0.0，p_value = 1.0，sample_ratio_mismatch = false
  - 说明两组人数分配没问题，本次不显著不是因为分流偏差

- **样本量本身够用（来自 ab_sample_size）**
  - 以基线 6% 为起点，要以 80% 把握度检测 2pp 的绝对提升，每组需 2554 人（合计 5108），当前每组 8000 人已超出
  - 但若想检测 1pp 的绝对提升，每组需 9540 人（合计 19080），当前每组 8000 人不够
  - 也就是说：当前实验能确认「+2pp 级别」的效果，无法确认「+0.5pp~1pp 级别」的效果——而这次观测到的正是 +0.5pp

## 需要注意

- 用户提供的是「下单人数/总人数」，工具据此计算的是**下单转化率**；不显著结论只适用于这个指标，不等同于「新版本无价值」。
- 样本比例失衡（SRM）检查通过，alpha 取 0.05、power 取 0.8，与常规设置一致。
- 「下单」≠「成交」：如需评估业务价值，还应看净销售额/GMV、客单价、取消率等口径，避免下单涨了但被取消抵消。

## 建议下一步

1. **不要基于当前结果上线或全量推广**，继续跑到样本量足够：若以 1pp 为最小可检测效应，每组还需再加 1540 人（8000 → 9540，来自 ab_sample_size 与 calculate 的差值计算）。
2. **扩展指标口径**：对同一实验同时看 GMV / 净销售额 / 客单价 / 取消率，确认 +0.5pp 下单率是否带来实质成交增量。
3. **预先约定决策阈值**（例如「只有当 p < 0.05 且下单率提升 ≥ 1pp 才全量」），避免事后解读。
4. 若业务上 8.33% 的相对提升本身就有价值且成本极低，可以考虑分阶段小流量灰度，同时保留实验直到达到统计显著。
