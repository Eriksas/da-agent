**问题：** 我们做了一个满减实验，按 50/50 分流：对照组 5000 人中 400 人下单，实验组 5000 人中 460 人下单。效果显著吗？

# 满减实验结果分析

## 结论

**效果在统计上是显著的**：实验组转化率 9.2%（460/5000），对照组 8.0%（400/5000），绝对提升 1.2 个百分点，相对提升 15%，z = 2.1401，p = 0.032349 < 0.05，95% 置信区间为 [0.1012%, 2.2988%]，区间不包含 0，因此可以拒绝"两组无差异"的原假设。

样本比例检查（SRM）通过：对照组实际占比 0.5，与设计的 0.5 一致，卡方 = 0.0，p = 1.0，不存在分流异常。

## 主要结果

| 指标 | 对照组 | 实验组 | 差异 |
|---|---|---|---|
| 转化率 | 0.08 | 0.092 | +0.012（相对 +15%） |
| 转化人数 / 总人数 | 400 / 5000 | 460 / 5000 | +60 单 |

- 显著性与置信区间来自 `ab_proportion_test`：difference = 0.012，relative_lift = 0.15，z = 2.1401，p = 0.032349，CI = [0.001012, 0.022988]，significant = true，warnings 为空。
- 换算成业务量：按当前提升，实验组每 5000 人多产生 60 个下单（`calculate`：0.012 × 5000 = 60）。
- 相对提升的置信区间约为 +1.27% ~ +28.74%（`calculate`：0.001012 / 0.08 = 0.01265；0.022988 / 0.08 = 0.28735）。

## 需要注意

1. **样本量低于检验该效应的标准要求**。按基线转化率 8%、要检测 1.2pp 的绝对提升、α = 0.05、power = 0.8 计算，每组需要 8568 人、总计 17136 人（`ab_sample_size`）；实际每组只有 5000 人。这意味着本次是在样本不够的情况下达到了显著，属于"勉强踩线"，稳健性不足。
2. **p 值贴近显著性边界**（0.032349 接近 0.05），置信区间下界仅略高于 0（0.001012）。如果流量再少一些，或数据有轻微偏差，结论可能翻转。
3. **效应量区间很宽**：相对提升的置信区间从 +1.27% 到 +28.74%，不确定性极大，真实收益可能远低于 15%。
4. **样本量不足还有一个直接后果**：本次实验的功效（power）未达到 80%，存在 II 类错误风险——即使实验真实有效，也可能因为噪声而观测不到；反之，本次显著也可能部分来自随机波动。
5. 满减活动通常有**新奇效应**和**提前透支效应**（把后续自然下单挪到活动期），单周/短周期结果不一定能外推到长期，工具未提供实验持续时长信息。
6. 结论基于用户提供的转化人数，工具未提供实验的其它口径信息（是否同一时间窗口、是否同质流量等），需人工确认。

## 建议下一步

1. **继续跑量到每组至少 8568 人**（每组还差 3568 人，`calculate`：8568 - 5000 = 3568），重新检验，看显著性和置信区间是否稳定、区间是否收窄。
2. **看长期留存/复购指标**：满减容易带来一次性订单，检查活动后一段时间的复购率、LTV 是否被侵蚀，把"下单提升"和"利润"分开评估。
3. **核对收益是否覆盖成本**：把满减补贴金额算进去，计算增量订单的边际贡献是否为正——当前工具只提供转化率，未提供客单价与补贴成本。
4. **检查是否有交叉污染**（如对照组用户看到满减信息、优惠券被分享到对照组），这会低估真实效果。
5. 若要全量上线，建议先做小流量灰度验证金额与人群，而不是直接把本结论作为上线依据。
