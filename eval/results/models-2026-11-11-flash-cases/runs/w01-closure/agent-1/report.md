## 结论

**2011-W01 的“环比”在数据上算不出来**：基期 2010-W52 整周停业、GMV 为 0，工具返回的环比变化率为空（`change_pct: null`），因此系统口径的 +130,274.65 只是“从 0 变到有值”，不是真实增长。

换成有意义的两个参照口径：

## 主要原因

**1）相对 2010-W51 的回升，主要是可识别客户盘子在恢复，不是缺客户 ID 的“水分”**
- 可识别客户 GMV（GMV − 缺客户 ID 部分）：45,285.91 → 113,473.05，**+68,187.14（+250.57%）**（calculate）。
- 活跃客户数 86 → 207，**+140.70%**；订单数 158 → 242，**+53.16%**（metric_summary + calculate）。
- 反过来，缺客户 ID 的 GMV 占比从 2010-W51 的 **46.85%** 降到 2011-W01 的 **12.90%**（calculate）。也就是说上一周基线本身“含水分”很高，环比看起来的增幅里，有一部分其实是订单从无 ID 变回有 ID 的**归属修复**，而非纯新增生意。

**2）相对 2010-W01（同比）的下滑，主因是可识别客户客单价大幅走低**（decompose_gmv，Shapley 分解，总变化 −35,736.14）：
- 可识别客户客单价：**−77,797.41**（贡献占比 217.7%）
- 人均订单数：**−5,700.0**（15.95%）
- 活跃客户数：**+31,551.3**（−88.29%，反向贡献）
- 缺客户 ID 的 GMV：**+16,209.97**（−45.36%，反向贡献）

**3）新老客拆分（drilldown，同比）**：新客 GMV 34,620.97 → 6,133.72，**−28,487.25（−82.28%）**，占总变化 79.72%；老客 130,798.19 → 107,339.33，**−23,458.86（−17.94%）**，占总变化 65.64%；缺客户 ID 部分 +16,209.97，占总变化 −45.36%。同期订单数其实在涨（200 → 242，+21%）、活跃客户也涨（166 → 207，+24.7%），单均金额却从 830.05 降到 538.33。

## 需要注意

- **停业是这次环比失效的根本原因**（data_quality_overview）：停业区间 last_open 2010-12-23 → reopen 2011-01-04，gap 12 天，2010-W52（周一 2010-12-27）交易天数 0；2011-W01 也只有 5 个交易天（本周 7 天里少 1 天）。
- **交易天数不可比**：2011-W01 5 天 vs 2010-W51 4 天（环比）、5 天 vs 2010-W01 6 天（同比），总量变化里有天数因素，必须同时看日均。
- **小样本警告**：drilldown 标记“新客”（当期 14 单）和“未知/缺 ID”（当期 18 单）分组订单数少于 30，变化可能偶然，不宜单独下结论。
- **新客口径警告**：基期 2010-W01 距数据起点（2009-12-01）不足 52 周，起点前的购买不可见，部分老客会被算成新客——这会夸大 2010-W01 的新客基数（67 个新客 vs 2011-W01 的 14 个），所以“新客暴跌 82%”这个数字要谨慎解读。
- **指标口径**：GMV 为下单口径、含之后被取消的订单；2011-W01 取消金额 4,764.03、取消率 3.66%，且取消金额可能对应更早下的订单，与当周 GMV 不是同一批订单。
- GMV 环比变化率工具未提供（基期为 0），上文所有百分比均来自 calculate 对具体数值的运算。

## 建议下一步

1. **把 2010-W52 从环比基期里剔除**，运营周报对停业周应显式标注“无交易”，避免出现“从 0 涨到 130,274.65”的假增长；环比建议固定对比“上一个有交易的周”。
2. **优先核查可识别客户客单价的下滑**（884.59 → 506.58）：是低价订单占比上升、单品结构变化，还是大额订单（如 MEDIUM CERAMIC TOP STORAGE JAR 77,183.60）挪到了 2011-01-18 之后，确认是否只是大单时点问题。
