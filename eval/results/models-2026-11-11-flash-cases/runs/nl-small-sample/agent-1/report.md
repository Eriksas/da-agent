# 2011-W48 荷兰 GMV 异动分析

## 一、结论

分析的是 **2011-W48**（数据集中最后一个完整周，数据截至 2011-12-09；2011-W49 为不完整周）。

荷兰 W48 GMV 为 **104.00**，W47 为 **10,798.24**，减少 **10,694.24（-99.04%）**。但这不是全站大盘下滑：全站 GMV 从 **302,392.22 涨到 309,381.73（+6,989.51，+2.31%）**，荷兰的下跌吃掉了大部分增长——**剔除荷兰后全站环比为 +17,683.75（+6.06%）**。

荷兰的 "-99%" 是**分母极小造成的百分比放大**：荷兰在 W47 也仅占总 GMV 的 **3.57%**，W48 只剩 **0.03%**。从数据上看，跌的原因不是客单价下滑，也不是订单被取消，而是 **W47 那 5 笔订单在 W48 基本没有复现（订单数 5 → 1）**。

## 二、主要原因（按贡献大小）

1. **荷兰的可识别订单量从 5 笔降到 1 笔，单笔金额也从 2,159.65 降到 104.00**
   - 来源：`drilldown`（2011-W48，国家 × GMV，环比）：Netherlands base 10,798.24 / current 104.00 / change **-10,694.24** / change_pct **-99.04%**，base_orders **5**、current_orders **1**，`small_sample: true`；`calculate`：10,798.24 ÷ 5 = **2,159.648**，104.0 ÷ 1 = **104.0**。
   - 也就是说，跌幅来自"那笔约两千欧元量级的荷兰订单没有再次下单"，而不是同一批客户买得更少。

2. **不是取消单/退货造成的账面冲抵**
   - 来源：`drilldown`（国家 × **净销售额**，环比）：Netherlands base 10,798.24 / current 104.00 / change **-10,694.24**，与 GMV 口径完全一致。
   - 含义：荷兰这一周的 GMV 中**没有产生取消金额**，所以"跌"是下单口径上的真实缺失，而不是下单后又被 C 单冲回。

3. **荷兰属于"少数几笔、单笔金额大"的极小体量市场，一笔订单缺席就会砸出 -99%**
   - 来源：`drilldown`（国家 × GMV，**同比**）：2010-W48 荷兰为 **10,687.45（7 笔订单）** → 2011-W48 **104.00（1 笔）**，change **-10,583.45（-99.03%）**。
   - 含义：荷兰每周 GMV 稳定在 1 万量级但只由 5–7 笔订单构成（对比全站 W48 客单价 466.64，`metric_summary`），说明它更像少数固定客户的周期性大单，而非稳定零售盘；这类结构天然脆弱，一周缺席即呈现断崖式跌幅。

4. **它同时掩盖了全站的真实增长**
   - 来源：`drilldown`（国家 × GMV，环比）给出 Netherlands `share_of_total_change` = **-1.53**；`calculate`：(309,381.73 − 104.0) − (302,392.22 − 10,798.24) = **17,683.75**，对应 **+6.06%**。
   - 含义：若只看"全站 GMV 只涨了 2.31%"，会低估实际经营表现；荷兰单市场就拖累了 10,694.24 的增量。

5. **与新老客拆分的交叉对照（提示性线索，非因果结论）**
   - 来源：`drilldown`（新老客 × GMV，环比）：老客 224,386.57 → 236,766.93（**+12,380.36**，548 → 595 笔）；新客 19,446.50 → 10,050.46（**-9,396.04**，43 → 36 笔）；未知（缺客户 ID）58,559.15 → 62,564.34（+4,005.19）。
   - `calculate`：荷兰跌幅 -10,694.24 比新客整体净跌幅 -9,396.04 还多 **-1,298.2**。说明荷兰这 5 笔订单**不可能全部是新客**（否则新客组跌幅会更大），也不可能是老客组跌幅的来源（老客组为净增长）。但工具不提供"国家 × 客户类型"的交叉拆分，因此无法确认这 5 笔订单的归属，仅作提示。

## 三、需要注意（口径与警告）

- **样本不足警告（工具原文）**：`drilldown` 对 Netherlands 标记 `small_sample: true`，并警告"部分分组订单数少于 30，变化可能是偶然波动，**不宜单独下结论**"。荷兰 5 笔 → 1 笔正属此列，**不应据此判定荷兰市场崩塌**。
- **正负抵消警告（工具原文）**："有分组反向变化，相互抵消后总变化较小，所以单个分组的贡献占比会超过 100% 或为负。"澳大利亚（同比 -16,913.13，2 笔）、意大利（-2,453.8，4 笔）、西班牙（-3,313.22，3 笔）等均为个位数订单的分组。
- **指标口径**（`metric_summary` / `data_quality_overview`）：GMV 为下单口径（数量 × 单价，含之后被取消的订单）；净销售额 = GMV − 取消金额；活跃客户数不含缺失客户 ID；缺客户 ID 的 GMV 计入 GMV 与订单数。
- **周完整性**：2011-W48 交易天数 **6 天**，与 W47 的 6 天相同，无缺天；`data_quality_overview` 中不完整周为 2009-W49 与 2011-W49，不影响本周结论。
- **极端大额单人工复核清单**中列出的发票（581483、C581484、541431、C541433、556444、530715）日期分别在 2011-12-09、2011-01-18、2011-06-10、2010-11-04，**均不在 2011-W47/W48**，故荷兰此次下跌与已标记的极端大额行无关。
- **因果限制**：以上仅能说明"荷兰 W47 的几笔订单在 W48 未复现"这一现象；数据无法验证客户流失、暂停采购、账期/发货节奏或下单入口问题等原因，**不做因果归因**。

## 四、建议下一步

1. **拉取荷兰 W47 那 5 笔订单的明细**（发票号、下单日期、客户 ID、商品编码、金额），确认是否属于同一客户的周期性大单——这是判断"客户流失"还是"下单节奏/合并下单"的关键，当前工具无法覆盖订单明细级下钻。
2. **核对国家与客户 ID 的完整性**：清洗规则 R08（缺客户 ID，243,007 行，计入 GMV 但不计客户数）与 R10（国家不明确，817 行，仅标记）可能造成国家归属错位；可结合缺客户 ID 分组的 25 → 32 笔核查荷兰这 1 笔 104.00 是否是归属异常。
3. **观察 W49 是否恢复**：若该客户属于周期性采购，W49 出现大额荷兰订单可进一步支持"订单节奏"假设；但注意 2011-W49 为不完整周（数据止于 2011-12-09），不能直接与 W48 对比。
4. **建立"少数大客户市场"的监控口径**：对荷兰这类单周仅 5–7 笔、单均 2,159.65（全站客单价 466.64）的市场，建议按"单客户周贡献"而非"国家 GMV 环比百分比"设阈值告警，避免 -99% 的比例波动反复误导运营判断；同时把大额订单发货/账期节点纳入周度运营日历。
