**问题：** 上周 GMV 为什么变化？

## 分析对象

**2011-W48**（2011-11-28 至 2011-12-04，最近一个完整周），对比基期 **2011-W47**，环比口径。

## 1. 结论

上周 GMV **309,381.73**，环比 **+6,989.51（+2.31%）**（`metric_summary`）。这是一次**"量增价减"型的小幅增长**：订单数 +47 单（+7.63%）、活跃客户 +22 人（+4.47%）、人均订单数 +2.2% 共同推高，但可识别客户客单价从 412.58 降到 391.15（-21.42，-5.19%），把大部分增量抵消掉了（`decompose_gmv`）。净销售额 +10,881.75（+3.69%）高于 GMV，是因为当周取消金额几乎减半（7,158.91 → 3,266.67，-54.37%），不属于经营改善的同义信号。

## 3. 需要注意（口径与警告）

- **可比性没问题**：两周均为 6 个交易日（`metric_summary` trading_days），日均 GMV 51,563.62 vs 50,398.70（+2.31%），与总量同向；`metric_summary` 未返回警告。
- **取消率下降需谨慎解读**：取消率 2.37% → 1.06%（-1.31pp）。按 `data_quality_overview` 的定义，取消金额是"当周 C 开头发票中的商品行金额，可能对应更早下的订单"，分子分母不一定是同一批订单，所以**不能推断"本周订单被取消得更少"**，净销售额增速高于 GMV 增速也是该口径造成的。
- **缺客户 ID 数据占比高**：全量数据中缺客户 ID 的 GMV 占 13.11%（`data_quality_overview`），这部分本周贡献了总变化的 57.3%，但只有 32 单，无法归因到具体客户。
- **小样本陷阱**：`drilldown` 明确标记多个国家/商品分组订单数少于 30（荷兰、西班牙、意大利、法国、日本、芬兰、德国及多数商品），其"归零/翻倍"多为波动；单个分组贡献占比超过 100% 或为负，是因为各分组反向变化相互抵消。
- **极端大额行不在本周口径内**：581483（+168,469.60）与 C581484（-168,469.60）发生在 2011-12-09，属 2011-W49，未影响本周数据；但 W49 是不完整周（数据仅到 2011-12-09 12:50），下周比较前必须剔除这笔。
- **没有对照实验**，以上业务解释均为"与……同时发生的可能原因"，不是因果结论。

## 4. 建议下一步

1. **新客是本周最大业务疑点**：GMV -48.32% 主要由客单价 452.24 → 279.18 造成（新客数 37 → 31）。请业务确认 11 月底是否有优惠券/免邮/首单满减规则调整、促销到期或流量结构变化。
2. **客单价 -5.19% 的结构原因**：低价金属挂牌类商品占比上升可能拉低均价，建议补一张"价格带 GMV 分布"对比表（本周未覆盖）。
3. **修复缺客户 ID 的采集**（全量占比 13.11%）：这会直接提升归因准确度，也建议查是埋点/导出问题还是业务真实。
4. **核查 2011-W47 的取消是否集中在大额订单上**，以解释取消率从 2.37% 骤降到 1.06%。
5. **下周（W49）分析前**：先剔除 581483 / C581484 巨额订单，并用日均口径比较。
