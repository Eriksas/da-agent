# 上周 GMV 变化诊断（分析周：2011-W48，2011-11-28 ~ 12-04，对比 2011-W47）

## 1. 结论

GMV 从上周的 **302,392.22 元** 上升至 **309,381.73 元**，环比 **+6,989.51 元（+2.31%）**（`metric_summary` wow）；净销售额 **306,115.06 元，+10,881.75 元（+3.69%）**。

变化是典型的"**量增价减**"：增量全部来自**活跃客户数 +22**（492→514）和**人均订单数 +0.0264**（1.2012→1.2276），而**可识别客户客单价 412.58 → 391.15（-5.19%）** 是唯一且最大的拖累项；同时**新客 GMV 接近腰斩（-48.32%）**，增长完全靠老客和缺客户 ID 的部分支撑。同比看 GMV 仍低于去年同周 **-7,813.70 元（-2.46%）**，缺口同样落在新客。

## 3. 需要注意（口径与警告）

- **净销售额涨得比 GMV 多**：取消金额从 7,158.91 降至 3,266.67（-54.37%），取消率 2.37% → 1.06%（-1.31 个百分点，`metric_summary`）。取消口径为"当周 C 开头发票的商品行金额，可能对应更早下的订单"，分子分母不一定是同一批订单（`data_quality_overview` 定义），不能直接当作本周订单的取消率。
- **两周交易天数均为 6 天**，日均 GMV 51,563.62 vs 50,398.70（+2.31%）、日均订单 110.5 vs 102.6667，环比不含不完整周或停业造成的偏差；`metric_summary`（wow）本次**未返回任何 warnings**。
- **同比解读要打折**：工具对 yoy 给出警告——基期 2010-W48 距数据起点不足 52 周，起点前的购买看不到，部分老客会被算成新客，因此"新客同比 -23"这一条需谨慎（环比方向不受影响）。
- **总变化小、分组相互抵消**，所以单项贡献占比会超过 100% 或为负；`others` 是前 N 名以外的合计，不等于"剔除某一项后"的结果。
- **极端大额行不在本周**：人工复核清单中最大单（581483 / C581484，168,469.60，2011-12-09）落在 **2011-W49**，且数据在该周只到周五中午（W49 为不完整周），不影响 W48 的解读。
- 以上均为**同期共现的数据事实与结构描述**，不是因果结论；本周数据中没有任何对照实验可用于验证归因。

## 4. 建议下一步

1. **查客单价下滑的结构**：UK 单均金额 -2.78%、可识别客户客单价 -5.19%，建议按"折扣/运费/多件折价"或"低客单商品占比上升"拆解（`drilldown` 目前只能按国家/新老客/商品，未覆盖折扣维度）。
2. **核实新客获取与质量**：新客数 37 → 31、同比 54 → 31，且新客人均 GMV 525.58 → 324.21，建议与市场/投放侧核对渠道投放量、落地页与新客优惠力度是否同期调整。
3. **补客户 ID 的治理**：缺客户 ID 的 GMV 占本周 **20.22%**，且贡献了总变化的 57.3%，其口径直接影响新老客结论，建议排查下单流程的 ID 缺失原因。
4. **跟进 W49**：数据截止 2011-12-09 12:50，W49 为不完整周且含 168,469.60 的极端大额单与全额取消单，做周报时应使用日均并单独剔除该单后复算，避免把 W48 与 W49 直接对比。
5. **业务确认**上述新客与客单价假设；如需验证促销/推荐改版的因果效果，建议做 AB 实验（用 `ab_proportion_test` 判定转化差异）。
