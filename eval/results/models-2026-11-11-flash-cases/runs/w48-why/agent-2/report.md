## 1. 结论

上周 GMV **没有下降，而是小幅上升**：309,381.73，环比 2011-W47 的 302,392.22 **增加 6,989.51（+2.31%）**；两周交易天数都是 6 天，日均 GMV 从 50,398.70 升至 51,563.62（+2.31%）。

但这个净增是**几股方向相反的力量相互抵消后的结果**：订单数 +47（+7.63%）、活跃客户 +22（+4.47%）带来的是正向拉动，而**可识别客户客单价下降（贡献 -13,088.20）是最大的负向因素**，最终只剩 +6,989.51 的净增。

如果看**净销售额**（GMV − 取消金额），表现更好：306,115.06，环比 **+10,881.75（+3.69%）**——因为取消金额同时从 7,158.91 降到 3,266.67（-54.37%），取消率从 2.37% 降到 1.06%（`metric_summary`；6,989.51 + 3,892.24 = 10,881.75，`calculate`）。

**② 拉动项：人均订单数上升 → 贡献 +5,336.81（`decompose_gmv`）**
人均订单数 1.2012 → 1.2276（+2.20%），总订单 616 → 663（`metric_summary`）。

**③ 拖累项：可识别客户客单价下滑 → 贡献 −13,088.20（`decompose_gmv`）**
可识别客户客单价从 412.58 降到 391.15，整体客单价 AOV 从 490.90 降到 466.64（-4.94%）。这与增长集中在**低单价、订单数多的小件商品**一致（见下）。

**⑤ 国家结构：英国单市场主导，个别小市场大单消失形成反向抵消（`drilldown` country）**

## 3. 需要注意（口径与警告）

- **本周 GMV 增长是"薄增长"**：订单和客户都在涨，但客单价跌 4.94%，说明增量靠更便宜、更碎的订单堆出来。
- **小样本分组不可单独下结论**：荷兰、日本、法国、西班牙以及多个商品分组的订单数 < 30（`drilldown` warnings），其中荷兰的 −10,694.24 尤其可能只是 1–2 笔大单缺失，属于波动而非趋势。
- **占比会超 100% 或为负**：各分组方向相反、相互抵消，导致单项贡献占比（如英国 +204.56%、新客 −134.43%）不能当作"净增构成比"来读。
- **缺客户 ID 的部分占当周 GMV 的 20.22%**（62,564.34 / 309,381.73，`calculate`），这部分的 +4,005.19 增量不带客户信息，**不能等同于真实客户增长**，解读客户数/新老客时应把它剔除看。
- **同比仍是负的**：2011-W48 GMV 317,195.43 → 309,381.73，**−7,813.70（−2.46%）**；净销售额 309,029.05 → 306,115.06，−2,913.99（−0.94%）。即本周的小幅回升尚未收复去年同期水平。
- **同比基期口径提示**：2010-W48 距数据起点不足 52 周，起点前的购买看不到，部分老客会被误算为新客（`metric_summary` yoy warnings），所以"新客同比 −42.59%"这个数要谨慎解读。
- **取消额分子分母不同批**：取消金额取当周 C 开头发票的商品行，可能对应更早下的订单，取消率不宜当作订单级取消率。
- **数据清洗影响**：存在重复行删除（R07）、缺客户 ID（R08）、国家不明确（R10，817 行）等规则；极端大额行（如 581483 / C581484）均在 2011-12-09 的 2011-W49，不在 W48 区间内。

## 4. 建议下一步

1. **查英国客单价下滑的来源**：拉取 W47/W48 英国订单明细，看是"高单价 SKU 断货/未下单"还是"低价 SKU 占比提升"，这是把 +2.31% 转成更健康增长的关键。
2. **盯新客获取**：新客人数与新客 GMV 同比、环比双双走弱，建议核对新客引流渠道（来源站/落地页/优惠）当周是否有变动或中断。
3. **剔除波动项看真实增速**：把荷兰这类小样本大单单独标记后重算一次环比，判断剔除后 GMV 增幅是否仍为正。
4. **复盘新增放量 SKU**：COOK WITH WINE METAL SIGN（2 → 39 单）与 N0 SINGING METAL SIGN（5 → 25 单）订单量激增，确认是正常销售还是单次批量/团购订单，并评估能否复刻。
5. **查英国取消骤降的原因**：取消额从 6,424.77 降到 2,168.51，是流程变化还是发货/回访环节变动；同时注意这抬高了净销售额但对 GMV 无影响。
