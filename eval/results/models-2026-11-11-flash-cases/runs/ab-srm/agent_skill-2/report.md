**问题：** 我们做了一个满减实验，按 50/50 分流：对照组 5000 人中 400 人下单，实验组 5600 人中 480 人下单。实验组赢了吗？

## 结论

**不能判定实验组赢。** 两组转化率差异（对照组 8.00% vs 实验组 8.57%，绝对差 0.57pp、相对提升 7.14%）**统计上不显著**（z = 1.0644，p = 0.287131，95% 置信区间 [-0.48pp, +1.62pp]）；更关键的是**样本比例失衡（SRM）检查未通过**，实验结论在排查分流与埋点之前不成立。

## 主要原因

1. **差异落在随机波动范围内**（来源：ab_proportion_test）
   - 对照组转化率 0.08，实验组转化率 0.085714，difference = 0.005714，relative_lift = 0.071429
   - z = 1.0644，p_value = 0.287131，confidence_interval = [-0.004788, 0.016217]，significant = false
   - 置信区间同时包含 0 和小幅负向，说明现有数据既不能证明实验组更好，也不能排除"实验组更差"

2. **分流比例与 50/50 设计不符（SRM 告警）**（来源：ab_proportion_test）
   - 实际对照组占比 0.471698、实验组占比 0.528302（总样本 10600）
   - 设计期望对照组 5300 人，实际 5000 人，偏差 -300 人；实验组比对照组多 600 人
   - 卡方拟合优度检验 chi2 = 33.9623，p_value = 0.0，sample_ratio_mismatch = true
   - 工具建议：先排查分流和埋点，暂不解读实验效果

3. **差异幅度本身低于本实验的设计检出能力**（来源：ab_sample_size）
   - 以基线 8% 转化率、检出 2pp 绝对提升、α=0.05、power=0.8 计算，每组需 3213 人、合计 6426 人；本次每组 5000 / 5600 人，样本量对 2pp 效应是够的
   - 但实测差异只有 0.57pp，远小于 2pp 的设计 MDE，属于"样本量够、但效应太小"的情况，再跑下去也大概率还是这个结论
