**问题：** 2010-W10 的新客多不多？和上周比有什么变化？

## 分析范围

分析的是 **2010-W10**（与上一周 **2010-W09** 环比），数据来源：metric_summary、drilldown、decompose_gmv、data_quality_overview。

## 1. 结论

2010-W10 的新客**不算多，而且比上周明显减少**：新客 83 个，上周（2010-W09）为 116 个，减少 33 个（-28.45%）；新客占活跃客户的比例从 39.06% 降到 34.16%（-4.90 个百分点）。新客同时也是本周 GMV 下滑的最大来源：新客 GMV 减少 22,918.14（-42.95%），贡献了本周 GMV 总变化的 96.79%。

## 2. 主要原因（新客相关数字，按贡献排序）

| 指标 | 2010-W10 | 2010-W09 | 变化 |
|---|---|---|---|
| 新客数 | 83 | 116 | -33（-28.45%） |
| 老客数 | 160 | 181 | -21（-11.6%） |
| 活跃客户数 | 243 | 297 | -54（-18.18%） |
| 新客 GMV | 30,441.58 | 53,359.72 | -22,918.14（-42.95%），占总变化 96.79% |
| 老客 GMV | 87,482.12 | 96,648.70 | -9,166.58（-9.48%） |
| 缺客户 ID 的 GMV | 20,219.44 | 11,812.67 | +8,406.77（+71.17%） |
| 总 GMV | 138,143.14 | 161,821.09 | -23,677.95（-14.63%） |

其他要点：
- **新客降幅大于整体降幅**：新客 -28.45% vs 活跃客户整体 -18.18%（metric_summary），说明流失主要来自新增一端，而非老客复购。
- **新客质量同步走低**：新客人均 GMV 从 459.997586 降到 366.766024（-20.27%），新客 GMV 占总 GMV 比重从 32.97% 降到 22.04%（drilldown + calculate）。
- **GMV 三因子拆解**（decompose_gmv，Shapley 值）：活跃客户数贡献 -26,738.05（占总变化 112.92%），人均订单数 -2,146.01（9.06%），可识别客户客单价 -3,200.66（13.52%），缺客户 ID 的 GMV +8,406.77（-35.5%）。即：总量下滑主要由客户数（其中主要是新客）驱动，客单价环节的拖累反而被整体客单价上升部分抵消。
- **横向参照**（metric_summary 邻周）：新客数 2010-W08 为 88 → 2010-W09 为 116 → 2010-W10 为 83 → 2010-W11 为 83（与 W10 持平）。所以 83 是这一段周的低位，且到下一周没有回升。周末与节后（2010-04-01 至 2010-04-06 停业 5 天）并未落在 2010-W10，2010-W10 与 2010-W09 交易天数均为 6 天，不存在交易天数差异。

## 3. 需要注意（口径与警告）

- **新客数可能被高估**（metric_summary 与 drilldown 均给出该警告）：数据起点为 2009-12-01，2010-W10 与 2010-W09 距起点均不足 52 周，起点之前的购买记录看不到，部分老客会被误判为新客。因此"83 这个数偏大"，环比降幅也可能被压缩（老客被算成新客的基数在两周都存在）。
- **"未知"分组样本不足**：缺客户 ID 的分组当期仅 19 单（上周 36 单），drilldown 标记为 small_sample，其 +8,406.77 的增长不宜单独下结论。
- **口径提醒**（data_quality_overview）：GMV 为下单口径、含之后被取消的订单；缺客户 ID 的订单计入 GMV 和订单数，但不计入活跃客户、复购和人均订单（全量数据中缺客户 ID 的 GMV 占比 13.11%）。活跃客户数 = 新客数 + 老客数。
- **没有对照实验**，以上都是同期相关关系，不能断言"新客减少导致了 GMV 下降"；只能说两者同时发生，且在拆解中客户数项的贡献最大。

## 4. 建议下一步

1. **确认新客流失是拉新投放问题还是留存问题**：查看 2010-W09/W10 的流量与渠道来源结构（可用 drilldown 按 country / product 维度看新客和老客各自的变化来源），判断新客是"来得少"还是"买得少"。
2. **排查新客质量下降原因**：新客人均 GMV -20.27%，可下钻到商品维度，看是否集中在低单价商品或折扣/促销结束。
3. **警惕缺客户 ID 的订单激增**：本周未知分组 +71.17%，虽样本不足，但占比上升本身会推高总 GMV 并压低"可识别客户"口径的指标，建议核查是否有渠道未传客户 ID。
4. **观测下周是否延续**：2010-W11 新客仍为 83，若 2010-W12 仍无回升，需按渠道/国家维度进一步排查拉新链路。
