## 三、需要注意

- **看板无法真正拆新老客**：看板所用数据表没有 customer_type 字段，客服/运营 Agent 已确认只能以活跃客户数、人均订单数、人均 GMV 作代理指标。我上面表格里的真新老客拆分来自 `order_lines` 表的 `customer_type` 列（取数 Agent 已校验：customer_type='新客' 的客户首购周等于该周，'老客' 严格早于该周，同周无双标）。
- **人均订单数两个口径不同**：看板的 1.29 单 = 全部订单 663 ÷ 活跃客户 514（含游客订单）；metric_summary 的 1.2276 单只算可识别客户的订单。前者偏高，与看板 Agent 说明一致。
- **不完整周与停业**：2011-W49 只到 12-09；2011-W01 因 2010-12-23～2011-01-03 停业只从 1/4 起算（data_quality_overview）；2011-04-21～04-25 也停业 5 天。
- **缺客户 ID 的订单**：全表占 GMV 13.11%（data_quality_overview），2011 年内约两成（本周 20.22%）；这部分钱在 GMV 里但不进任何客户数，所以"金额类"和"人数类"指标的分母不对齐。
- **新客样本小**：每周新客仅 14–67 人（query_data），单周新客 GMV 易被个单影响，不宜对单周下强结论；drilldown 也提示有分组订单数少于 30。
- **极端大额订单待人工复核**：581483 / C581484（168,469.60，2011-12-09，落在不完整的 W49）、541431 / C541433（77,183.60，2011-01-18，落在 W03）——属于先取消/对冲的大单，对单周 GMV 有放大作用（data_quality_overview）。
