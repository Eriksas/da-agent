**2011-W48 GMV 小幅上涨：309,381.73 英镑，环比 +6,989.51 英镑（+2.31%）**；日均 GMV 同为 +2.31%（50,398.70 → 51,563.62）。增长来自"人变多、买得更勤"，被"可识别客户客单价下降"抵消掉大半。净销售额环比 +3.69%（295,233.31 → 306,115.06），因为取消金额从 7,158.91 降到 3,266.67（取消率 2.37% → 1.06%）。

## 3. 需要注意

- **净增量小、正负互相抵消**：英国的 +14,297.73 与荷兰的 −10,694.24 等相互抵消，所以单个分组的贡献占比会出现超过 100% 或为负（工具已提示），不要把"占比"直接读成"贡献率"。
- **样本不足的分组不下单独结论**：荷兰 5→1 单、日本 0→1 单、西班牙 3→1 单、法国 10→18 单、新客 43/36 单、"未知"32 单。
- **缺客户 ID 占比高**：W48 缺客户 ID 的 GMV 为 62,564.34，占当周 GMV 的 20.2%；这部分计入 GMV 和订单数，但不计入活跃客户数与客单价，因此"客单价下降"只对可识别客户成立。
- **口径提醒**：取消金额按当周 C 开头发票入账，可能对应更早的订单，故取消率分子分母不一定是同一批订单；新老客口径重叠（W47 的新客在 W48 已算老客），两周新老客不能简单相加得总量。
- **周完整性**：W48/W47 均为完整周、交易天数相同；数据末端 2011-W49 是不完整周（截止 2011-12-09 12:50），且质量清单中最大极端单（发票 581483，168,469.60，2011-12-09）落在 W49，不影响本次读数，但不要拿 W49 与 W48 比。
- 以上为"同时发生"与结构事实，业务归因（渠道、投放、库存）尚无对照支持。

## 4. 建议下一步

1. **查英国新客获取链路**：新客人数 34→27、新客客单价 453.68→280.51 同时下滑，与渠道结构变化/落地页改动/促销力度是否有关，需向业务确认（待业务确认）。
2. **查可识别客单价下降的商品结构**：CHILLI LIGHTS 订单由 31 降到 21 单；是否有高单价商品缺货或促销结构变化（待确认）。
3. **荷兰 1 单先不下结论**：样本过小，需业务确认是否为当地库存/物流中断，必要时看更长周期。
4. **若要判断"取消率下降"是否真实改善**：需按原始下单周重新归集取消单（当前口径混入了历史订单的取消）。
