**问题：** 我们测试了新版商品详情页，按 50/50 分流：对照组 8000 人中 480 人下单，实验组 8000 人中 520 人下单。新版本更好吗？

## 结论

**不能下结论说新版本更好。** 实验组下单率 6.5%（520/8000）高于对照组 6.0%（480/8000），但差异 0.5 个百分点在统计上不显著（p = 0.191418，95% 置信区间 -0.2501pp ~ +1.2501pp，跨越 0）。目前的数据既不能证明新版更好，也不能排除它更差。

## 主要原因

**1. 方向为正，但样本量不足以判定（来自 `ab_proportion_test`）**

| 项目 | 数值 |
|---|---|
| 对照组转化率 | 0.06（480/8000） |
| 实验组转化率 | 0.065（520/8000） |
| 绝对差 | 0.005（+0.5 个百分点） |
| 相对提升 | 8.33% |
| z 值 | 1.3064 |
| p 值 | 0.191418 |
| 95% 置信区间 | [-0.002501, 0.012501]（-0.25pp ~ +1.25pp） |
| 是否显著 | false |

**2. 分流正常，不是分流失衡造成的假象（来自 `ab_proportion_test` 的 SRM 检查）**

卡方拟合优度检验 chi2 = 0.0，p = 1.0，实测对照组占比 0.5，与设计值 0.5 完全一致，`sample_ratio_mismatch = false`。因此结论不成立的原因不是分流出错，而是效应本身被噪声淹没了。

**3. 本次样本量对 0.5pp 的效应来说太小（来自 `ab_sample_size`）**

- 基线 6%、要检出 0.5pp 的绝对提升、α=0.05、power=0.8：需要每组 36,791 人（合计 73,582 人），本次每组只有 8,000 人。
- 反过来看每组 8,000 人能做到什么：要达到 80% 把握度，只能检出约 1.1pp 的提升（每组需 7,940 人）或 1.2pp（每组需 6,719 人）。也就是说，即使新版真能带来 0.5pp 的提升，当前实验规模也有较大概率检测不出来。

## 需要注意

- 上述结论仅基于你提供的“下单人数/总人数”四组数字，工具未提供实验的其他护栏指标（GMV、客单价、客单、退款率、加购率），单一转化率不能代表新版详情页的整体价值。
- 置信区间上界 +1.25pp、下界 -0.25pp，说明当前数据对效应大小的不确定性很大，不能把 +8.33% 的相对提升当成真实效果去做收益测算。
- 实验流的 p = 0.191418 不显著属于“未拒绝原假设”，不等于“证明两组相同”。

## 建议下一步

1. **不要基于本次结果上线或回滚决策。** 继续跑量至每组约 36,791 人（合计约 73,582 人），或先与业务确认一个可接受的最小有意义提升（MDE）。
2. **如果只关心较大的效应**（比如 ≥1.1pp 的下单率提升），每组 8,000 人已接近足够，可以按更大 MDE 重新解读。
3. **补充护栏指标**：用同一分流数据看 GMV/客单价是否同步提升——新版详情页常见“转化率升但客单价降”的情况，只看下单率可能选错方案。
4. **上线后用本店的周度指标做验证**：新版全量后的 2011-W48（最近完整周）GMV、客单价、取消率等变化，可作为方向性佐证（与实验结果同时发生，非实验因果结论）。
