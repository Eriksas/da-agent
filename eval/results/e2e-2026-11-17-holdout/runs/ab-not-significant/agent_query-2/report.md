**问题：** 我们测试了新版商品详情页，按 50/50 分流：对照组 8000 人中 480 人下单，实验组 8000 人中 520 人下单。新版本更好吗？

# 结论

**目前不能判定新版本更好——差异未达到统计显著。** 实验组转化率 6.5%，对照组 6.0%，绝对差 +0.5 个百分点、相对提升 8.33%，但 p = 0.1914 > 0.05，95% 置信区间为 [-0.25pp, +1.25pp]，跨过 0（来自 `ab_proportion_test`）。这属于「数据不足以判断」，不是「新版本无效」。

# 主要原因（逐项说明）

**1. 分流是干净的，可以排除流量配比问题**
- 观测对照组占比 0.5，期望 0.5，卡方 = 0.0，p = 1.0，SRM 检验未发现样本比例失衡（来自 `ab_proportion_test`）。
- 结论：两组各 8000 人，实际转化 480 vs 520，实验组多 40 单（来自 `calculate`），差异方向为正。

**2. 不显著的原因是样本量不足，而不是观察不到效应**
- 在基线转化率 6%、要检测 0.5pp 绝对提升的设定下，80% 把握度需要**每组 36,791 人**（合计 73,582 人）；当前每组只有 8,000 人（来自 `ab_sample_size`）。
- 所需样本量是当前每组样本量的 4.598875 倍（来自 `calculate`）。
- 换算到当前样本量，真实效果可能落在：每 8,000 人少 20.008 单到多 100.008 单之间（来自 `calculate`）。也就是说，即使新版本实际是负效应，当前数据也几乎发现不了。

**3. 差异还可能来自噪声**
- p = 0.1914 意味着在「两组无差异」的假设下，出现当前或更大差异的概率约为 19%，属于随机波动范围内（来自 `ab_proportion_test`）。

# 需要注意

- 本次检验只覆盖「是否下单」这一个转化指标，未提供客单价、GMV、退款/取消率等护栏指标；若新版本提升了转化但拉低了客单价或退款率，结论会完全不同。
- 转化率数字（480/8000、520/8000）全部来自你的输入，工具未对其做二次核对。
- 结果来自 `ab_proportion_test`（两比例 z 检验，检验用合并比例、置信区间用非合并标准误），该工具本身未返回额外警告。

# 建议下一步

1. **延长实验至每组约 36,791 人**（当前量的 4.598875 倍），或至少继续跑到预定的样本量，再判断 8.33% 的相对提升是否真实。
2. **不要基于当前结果上线或回滚**，如果业务上有强需求做决策，建议以「方向为正 + 未显著 + 欠功效」的形式记录结论，避免把噪声当效果。
3. **补齐护栏指标**：客单价、GMV、退货率、页面性能（新版详情页常伴随加载变慢），用同样的显著性方法一起看。
4. 如果延长实验成本高，可考虑把 MDE 放宽到业务可接受的幅度（如 1pp）重新计算所需样本量，用更少样本换取对「有实际意义的提升」的判断能力。
