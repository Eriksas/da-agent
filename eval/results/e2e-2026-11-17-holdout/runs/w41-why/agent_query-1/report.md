**问题：** 2011-W41 的 GMV 为什么下降？

# 2011-W41 GMV 环比下降诊断

**分析口径**：2011-W41（2011-10-10 ~ 10-16）对比 2011-W40（2011-10-03 ~ 10-09），环比。

## 1. 结论

2011-W41 GMV 为 **221,268.10 英镑**，比上一周（310,948.14 英镑）**减少 89,680.04 英镑，降幅 28.84%**（来源：`metric_summary`）。两周交易天数都是 6 天、均为完整周、无极端大额行，数据可直接比较。

下降的实质是**大额批发型订单（单笔 ≥500 件）在 W41 大幅减少**：订单数只降了 8.2%（488 → 448），但客单价降了 22.49%（637.19 → 493.90），因为这些订单带走的件数（170,875 → 117,536，-31.22%）远多于订单数的减少幅度（来源：`metric_summary`、`query_data` 订单规模分档）。

## 2. 主要驱动

**按 Shapley 分解排序（`decompose_gmv`，口径：GMV = 活跃客户数 × 人均订单数 × 可识别客户客单价 + 缺客户 ID 的 GMV，总变化 -89,680.04，各因子贡献之和等于总变化）**

| 因子 | W40 → W41 | Shapley 贡献 | 占总变化 |
|---|---|---|---|
| 可识别客户客单价 | 620.17 → 474.49 | **-64,806.36** | 72.26% |
| 活跃客户数 | 389 → 360 | **-18,862.10** | 21.03% |
| 人均订单数 | 1.2031 → 1.1722 | **-6,336.97** | 7.07% |
| 缺客户 ID 的 GMV（抵消项） | 20,706.71 → 21,032.10 | **+325.39** | -0.36% |

**拆解 1：客单价下降 = 每单件数下降，不是价格下降（`query_data`）**
- 平均每单件数 350.15 → 262.36（-25.07%，`calculate`）；平均件单价 1.82 → 1.88（略升）；均价 <2 英镑的订单占比 53.07% → 53.35%（基本不变）。
- 推断：客单价下滑来自**单笔订单买得更少**，而非折扣或单价走低。

**拆解 2：降幅集中在 500 件以上的大单档（`query_data` 订单规模分档）**
- ≥500 件档：订单数 81 → 55，件数 100,241 → 53,969，GMV 175,815.05 → 98,289.29，**该档贡献了总降幅的 86.45%**（`calculate`：(98,289.29-175,815.05)/(-89,680.04)）。
- 100-499 件档：订单数 270 → 240，件数 64,600 → 56,667，GMV 117,571.20 → 104,062.16（第二大降幅来源）。
- 10-99 件档为正贡献（GMV 17,078.26 → 18,529.43，订单数 109 → 129），部分抵消了大单档的下滑；1-9 件档 GMV 483.63 → 387.22。
- 单笔最大订单也在变小：W40 第一大单 13,760.02 英镑 / 7,020 件（发票 569570），W41 第一大单 8,132.31 英镑 / 1,624 件（发票 571281）；W40 前三笔订单件数分别为 7,020 / 6,016 / 4,176，W41 前十笔中最多仅 4,176 件。

**拆解 3：结构上集中在英国和老客（`drilldown`）**
- 国家：United Kingdom GMV 269,442.02 → 181,060.91（-88,381.11，-32.8%），占总变化 **98.55%**；该国订单数 437 → 393，说明同样是"单均变小"而非客户数崩塌。
- 新老客：老客 260,929.47 → 175,044.94（-85,884.53，占总变化 95.77%）；新客 29,311.96 → 25,191.06（-4,120.90，占 4.6%）；缺客户 ID 的"未知"客群 20,706.71 → 21,032.10（+325.39，为正抵消项）。
- 商品：没有任何单一商品贡献超过总变化的 4.5%（最高为 23284 DOORMAT，-4,037.00，占 4.5%），前 10 名以外 2,488 个分组合计 -67,831.87（占 75.64%）→ 属广泛性下滑，非某个爆品断货。

**拆解 4：客户层面高度集中（`query_data` 前 10 大客户）**
W40 GMV 前 10 客户中有 8 位在 W41 完全无下单（W41 GMV 记 0），例如：
- 18102：W40 GMV 22,987.45，8 单，7,156 件 → W41 为 0
- 16684：W40 GMV 18,047.42，3 单，14,808 件 → W41 为 0
- 12415：W40 GMV 16,471.77，2 单，7,135 件 → W41 为 0
- 15838：W40 GMV 10,992.96，1 单，6,016 件 → W41 为 0
- 仍在下单的：16029（W40 14,156.64 → W41 10,244.56）、17509（4,302.36 → 1,781.28）

## 3. 需要注意

- **可比性 OK**：两周均 6 个交易日、均完整周（`data_quality_overview` 中不完整周只有 2009-W49 和 2011-W49；停业期在 2009-12、2010-12、2011-04，不涉及本两周）；人工复核的极端大额行分别落在 2011-12-09、2011-01-18、2011-06-10、2010-11-04，均不在 W40/W41。
- **取消率同时上升**：3.42% → 7.69%（+4.27 个百分点），因此净销售额降幅（-31.99%，300,307.48 → 204,251.49）大于 GMV 降幅（-28.84%）。GMV 为下单口径、含之后被取消的订单；且取消金额的分子与当周 GMV 分母不一定是同一批订单，该比率只能作参考。
- **GMV 为下单口径**：含之后被取消的订单金额，所以"W41 大单消失"部分可能被后续取消放大，需要用净销售额口径复核。
- **小样本分组不下结论**：Australia 从 4 单降到 0（GMV -17,150.53，占总变化 19.12%）但订单数仅 4 单，属样本不足波动；EIRE、France、Spain、Belgium、Cyprus 等各国订单数均少于 30（`drilldown` warnings），"未知"客群 26 单同样不足 30，结论中只作为抵消项列示。
- **商品维度 top-N 口径**：`others` 是前 10 名以外 2,488 个分组的合计，不等于剔除某一款后的结果。
- **相关不等于因果**：本分析无对照实验，以上均为同期结构事实；"大单减少的原因"属待验证假设。

## 4. 建议下一步

1. 查上述 8 位沉默客户（18102、16684、12415、15838、15769、17511、16333、14031）的复购间隔与流失原因：是否有账号失效、授信/账期到期、地址或联系人变更、转向竞品，还是仅采购周期错位。
2. 用净销售额口径重算 W40/W41 的 ≥500 件大单档，剔除后续取消单的影响，判断"大单消失"中有多少其实是"下完就取消"。
3. 看 W41 大单档订单数从 81 降到 55 的同时，10-99 件档订单数从 109 升到 129：确认是否为大客户"拆单"改走小额多单；可对比这些大客户 W42 是否重新出现大额订单（若 W42 回升，则更像采购周期波动而非客户流失）。
4. 向业务确认 W41 是否有批发渠道的大客户促销、账期政策或流程变更；若无，则该假设不成立。
5. 补充同比：对比 2010-W41，确认 W41 的大单收缩是季节性还是今年新增趋势（需另取同比数据）。

## 5. 可信度自评

**说明局限后可直接分享**：GMV、订单、分解与分档数据均来自工具计算且口径一致（W40/W41 可比）；但"大单为何消失"目前只有同期结构证据，属待业务确认的假设；且澳大利亚等小样本国家的波动不宜解读。
