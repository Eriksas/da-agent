**问题：** 2025 财年拼多多和京东，谁的盈利能力更强？

## 结论

**拼多多 FY2025（2025-01-01 至 2025-12-31）的盈利能力明显强于京东 FY2025（同一自然年期间，财年完全对齐，均为人民币）。** 拼多多归母净利率 22.66%、经营利润率 21.56%、ROE 26.93%，京东分别为 1.50%、0.21%、8.45%。但两家 FY2025 盈利都在下滑，京东下滑更陡。

## 主要发现

**数据事实（financial_summary / peer_compare，FY2025）**

| 指标 | 拼多多 | 京东 |
|---|---|---|
| 营业收入 | 4,318.46 亿元，同比 +9.65% | 13,090.85 亿元，同比 +12.97% |
| 毛利率 | 56.28%（上年 60.92%） | 16.04%（上年 15.87%） |
| 经营利润率 | 21.56%（上年 27.53%） | 0.21%（上年 3.34%） |
| 归母净利率 | 22.66%（上年 28.55%） | 1.50%（上年 3.57%） |
| ROE | 26.93%（上年 44.92%） | 8.45%（上年 17.55%） |
| ROA | 17.24% | 2.82% |
| 资产负债率 | 34.39% | 57.74% |
| 流动比率 | 2.43 | 1.22 |
| 经营现金流 ÷ 归母净利润 | 1.093 | 0.967 |

**推断：**
- 规模上京东远大于拼多多（收入约 3 倍），但**利润效率完全不在一个量级**：拼多多经营利润 931.02 亿元，京东仅 27.74 亿元。拼多多归母净利润 978.43 亿元，是京东 196.31 亿元的数倍（金额见 financial_summary）。
- 京东的弱项在费用端：销售及市场费用从 479.53 亿元增至 839.53 亿元（+75.07%），费用率从 4.14% 升至 6.41%；拼多多研发费用率 3.82%、销售及市场费用率 29.01%（均为 financial_summary 口径）。
- 回报结构上，拼多多是“低杠杆 + 高利润率”：权益乘数 1.562、资产负债率 34.39%；京东权益乘数 3.0006、资产负债率 57.74%，且权益乘数在上升。京东 ROE 8.45% 主要靠资产周转率 1.8789 撑起来，利润率极薄。
- 现金流质量：拼多多 1,069.39 亿元经营现金流覆盖 978.43 亿元归母净利润（1.093）；京东 189.91 亿元经营现金流对 196.31 亿元归母净利润（0.967，略低于 1），自由现金流 111.68 亿元、上年 527.42 亿元（-78.83%）。

## 风险提示（数据信号，非结论）

- **拼多多**：收入增速从 59.04% 骤降至 9.65%；毛利率下降 4.64 个百分点，经营利润率下降 5.97 个百分点；ROE 从 44.92% 降到 26.93%。总资产和权益大幅扩张（总资产 +24.75%，权益 +31.94%），总资产周转率从 0.9233 降到 0.7609，摊薄了回报。
- **京东**：经营利润几乎被费用吃光（经营利润同比 -92.84%），经营现金流同比 -67.31%，自由现金流同比 -78.83%，流动比率 1.22 且在下降，归母股东权益同比 -5.98%。OCF/净利润已低于 1。
- 京东净利润含少数股东与归母口径相差 17.9%（231.42 亿元 vs 196.31 亿元），引用时需注明口径。

## 需要注意

- 财年对齐：两家 FY2025 均为 2025-01-01 至 2025-12-31，币种同为人民币，因此可直接比。
- 毛利率跨公司比较要谨慎：各公司计入营业成本的项目不同（京东为自营商品为主的零售口径），比较时应优先看经营利润率。
- 拼多多未披露购建固定资产支出与自由现金流，相关结论不下。
- 费用投入上升与竞争格局、补贴政策相关属**待验证假设**，需结合公司公告和业务信息核实；本数据只含标准分类科目，看不到业务原因。
