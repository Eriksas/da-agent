# 拼多多（PDD Holdings）FY2025 ROE 下降归因

分析对象：**拼多多（PDD Holdings）**，FY2025 = 2025-01-01 至 2025-12-31（对比 FY2024 = 2024-01-01 至 2024-12-31），币种人民币（来自 `company_overview`、`financial_summary`）。

## 1. 结论

ROE 从 **44.92%** 降到 **26.93%**，下降 **18.00 个百分点**（`financial_summary`、`dupont`）。杜邦拆解显示三个因子**同时下行**：归母净利率贡献约 **-8.11 个百分点**（Shapley，占 45.09%），总资产周转率贡献约 **-6.80 个百分点**（占 37.79%），权益乘数贡献约 **-3.08 个百分点**（占 17.12%）。也就是说，**主要是盈利能力和资产使用效率下降，其次是权益增厚带来的"分母稀释"（杠杆下降）**，而不是某一项单独原因。

## 2. 主要发现

**① 盈利端：净利率下滑是最大来源（`dupont`）**
- 归母净利率 28.55% → 22.66%（-5.89 个百分点，`financial_summary`）
- 驱动链条清晰（`financial_summary`）：
  - 毛利率 60.92% → 56.28%（-4.64 个百分点）；毛利仅增 31.08 亿元（+1.30%），而收入增 380.10 亿元、营业成本增 349.01 亿元（+22.68%）
  - 经营利润率 27.53% → 21.56%（-5.97 个百分点）；经营利润 1,084.23 亿元 → 931.02 亿元（-14.13%）
  - 费用率上行：研发费用率 3.21% → 3.82%（研发费用 164.96 亿元，+30.31%）；销售及市场费用率 28.26% → 29.01%（费用 1,252.88 亿元，+12.57%）；两项合计费用率上升 **1.36 个百分点**（calculate）
- 归母净利润 1,124.35 亿元 → 978.43 亿元（-12.98%）（`financial_summary`）

**② 资产端：收入增速远低于资产增速，周转率被稀释（`financial_summary`、`calculate`）**
- 总资产周转率 0.9233 → 0.7609（`dupont`）
- 总资产 5,050.34 亿元 → 6,300.44 亿元（+24.75%），而收入仅 +9.65%，两者增速差 **15.10 个百分点**（calculate）
- 资产扩张主要在现金：现金及现金等价物 577.68 亿元 → 1,089.01 亿元（+88.51%），增加了 511.33 亿元。同期经营现金流 1,069.39 亿元，比归母净利润高 **90.96 亿元**（calculate）——利润留存转化为大量现金类资产，但这些资产当年未带来对应收入，拉低了周转率。

**③ 权益端：权益快速累积，权益乘数（杠杆）反而下降（`financial_summary`、`dupont`）**
- 归母股东权益 3,133.13 亿元 → 4,133.85 亿元（+31.94%），增速高于总资产（+24.75%）
- 权益乘数 1.7043 → 1.5620；资产负债率 37.96% → 34.39%（`financial_summary`）
- 推断：净资产积累（来自留存利润和经营现金流）使权益分母变大，在 ROE 公式里起"稀释"作用。这是"分母效应"，不是加杠杆推高或压低 ROE 的主因。

**④ 补充：净利率中约 1.10 个百分点来自经营利润以外的项目（calculate）**
- 归母净利率 22.66% 高于经营利润率 21.56%，差额 1.10 个百分点；工具未提供投资收益/减值等明细，因此净利润口径波动中非经营项目的影响无法进一步拆分（`financial_summary` warnings）。
