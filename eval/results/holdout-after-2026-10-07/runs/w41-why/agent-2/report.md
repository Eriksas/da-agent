# 2011-W41 GMV 下降分析

> 分析对象：**2011-W41**（ISO 周，约 10/10–10/16），对比基期 **2011-W40**（环比）。两周交易天数均为 6 天，metric_summary 无警告，属完整可比周。

## 1. 结论

2011-W41 GMV 为 **221,268.10**，较 W40 的 310,948.14 减少 **89,680.04，降幅 28.84%**。这不是"单量崩了"，而是**单均金额（客单价）大幅缩水**：订单只降 8.2%，客单价却降 22.49%（637.19 → 493.90）。降幅几乎全部来自**英国老客的单均消费额下降**，而非新客或小语种市场。

## 2. 主要原因（按贡献大小）

**① 可识别客户客单价下降 —— 贡献 72.26%（Shapley，decompose_gmv）**
- 可识别客户客单价 620.17 → 474.49，贡献 **-64,806.36**，占总降幅 72.26%（连环替代法 -61,477.43）。
- 这是本周第一大因素。

**② 活跃客户数下降 —— 贡献 21.03%**
- 389 → 360（-7.46%），贡献 **-18,862.10**；其中新客 67 → 49（-26.87%），老客 322 → 311（-3.42%）。人均订单数 1.2031 → 1.1722，仅贡献 **-6,336.97（7.07%）**——即"来的人少了"比"每人少买"影响更大，但客单价仍是第一。

**③ 英国市场是全部降幅的来源 —— 占总变化 98.55%（drilldown / country）**
- UK：269,442.02 → 181,060.91，**-88,381.11（-32.8%）**。
- 拆分看：UK 订单 437 → 393（-10.07%），但 **UK 客单价 616.57 → 460.71，环比 -25.28%**（calculate）。单量小降、单均腰斩，是 UK 拖累的核心。
- 澳大利亚 -17,150.53（占比 19.12%），但**基期仅 4 单**，样本不足；EIRE +5,906.03、Germany -3,750.43、France +3,283.04 对应订单数分别为 2/16/10 单，**均标记 small_sample，不宜单独下结论**。前 5 名以外 17 个分组合计 +10,412.96。

**④ 老客贡献了 95.77% 的降幅（drilldown / customer_type）**
- 老客：260,929.47 → 175,044.94，**-85,884.53（-32.91%）**，订单仅 391 → 373，**老客客单价环比 -29.68%**（calculate）。
- 新客：-4,120.90（-14.06%），占比仅 4.6%。缺客户 ID 部分 +325.39，可忽略。

**⑤ 商品层面是"长尾普跌"，不是某个爆款断货（drilldown / product）**
- 降幅前 5 的商品合计只占总变化的 **14.82%**（calculate，由 others 的 85.18% 反推）；**未列入前 5 的 2,493 个分组从 289,965.16 降到 213,577.21，-26.34%，占总变化 85.18%**。

**⑥ 同期取消率跳升，净销售额比 GMV 掉得更多**
- 取消金额 10,640.66 → 17,016.61（+59.92%），取消率 3.42% → 7.69%（+4.27 个百分点）。
- 因此净销售额 300,307.48 → 204,251.49，**-31.99%**，降幅大于 GMV 的 -28.84%。
- 取消增量同样集中在 UK（10,298.71 → 14,368.14，+4,069.43，占 63.82%）；USA +1,579.51、EIRE +830.30 为 1 单/小样本。

**⑦ 同比看，W41 是一个持续走低的节点（compare=yoy）**
- vs 2010-W41：GMV -28.21%（308,215.36 → 221,268.10）、订单 -20%（560 → 448）、活跃客户 -19.64%（448 → 360）、客单价 -10.26%。
- **注意结构差异**：同比降幅主要来自**单量与客户数**（订单 -20%），而环比降幅主要来自**客单价**（-22.49%）。这提示 W41 更像是"消费降档"叠加在全年下行趋势上。

## 3. 需要注意（口径与警告）

- **不能下因果结论**：以上都是同期共现的拆解，没有对照实验。只能说"与……同时发生"，不能说客单价下降"导致"GMV 下滑。
- **GMV 是下单口径**，含之后被取消的订单（R04：取消/退货单不计入 GMV，单独计为取消金额）。取消率上升说明本周下单质量同步变差。
- **取消金额口径不对称**："当周 C 开头发票中的商品行金额，可能对应更早下的订单"，分子分母不一定是同一批订单，不能直接当作 W41 订单的取消率。
- **分母口径差异**：客单价 493.90 是 GMV÷订单数（含缺客户 ID 的 26 单），decompose 中的"可识别客户客单价"474.49 已剔除缺客户 ID 部分，两者不可混用。
- **样本不足警告**：drilldown 三次均返回"部分分组订单数少于 30，变化可能是偶然波动"——澳大利亚（4 单）、EIRE（2 单）、德国（16 单）、法国（10 单）、USA 取消（1 单）、WALL ART VILLAGE SHOW（9 单）、JUMBO BAG PINK POLKADOT（22 单）均属此类，不宜单独下结论。
- **无极端大额订单干扰**：data_quality_overview 列出的 6 条极端大额行分别在 2011-12-09、2011-01-18、2011-06-10、2010-11-04，**均不在 W41**，本周无需人工复核项。
- **缺客户 ID 的 GMV** 全量占 13.11%，本周为 20,706.71 → 21,032.10，微增，对结论无影响。
- 两周交易天数同为 6 天，日均 GMV 同步下降 28.84%（51,824.69 → 36,878.02），**不是假期/停业造成的口径差异**（2011 年 4 月那次停业在 W17，不在本周）。

## 4. 建议下一步

1. **查 UK 老客客单价 -29.68% 的构成**：拉 W39–W42 的 UK 订单金额分布，确认 W40 的高客单价是否由个别高金额批量订单支撑、而这些订单在 W41 未复购。
2. **核对商品价格与促销日历**：W41 是否有折扣活动、免运费门槛调整或高价 SKU 缺货，工具未提供价格/库存/促销字段，需从业务侧确认。
3. **跟进取消率 3.42% → 7.69%**：按发票追踪 C 单与原单的对应关系，确认是 W41 新单被取消，还是历史订单在本周集中退单——两者含义完全不同。
4. **看后续周是否回补**：若 W42–W43 客单价回到 W40 的 637.19 附近，说明是订单结构偶发波动；若继续停留在 W41 的 493.90、可识别客单价 474.49 附近，则属于消费降档，需要经营动作。
5. **用 ab_proportion_test 验证干预效果**：如果打算对 UK 老客做复购/升单活动，先算基线转化率，再用 ab_sample_size 算每组所需样本量，不要只看单周环比就下结论。
