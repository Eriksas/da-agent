**问题：** 2011-W10 澳大利亚的 GMV 跌了这么多，澳洲市场出问题了吗？

分析的是 **2011-W10（对比基期 2011-W09）** 的国家维度数据。

## 1. 结论

澳洲市场没有"出问题"——**澳洲 GMV 从 16,726.84 跌到 210.90（-98.74%）是因为基期 2011-W09 那一周只有 1 张订单、且金额高达整体客单价的 37.1 倍，这个一次性尖峰在 W10 没有重复出现**（drilldown-国家，2011-W10 环比；calculate 折算倍数）。同期整体 GMV 实际是**上涨**的：129,034.74 vs 127,588.35，+1,446.39（+1.13%，metric_summary）。

## 2. 主要驱动（按贡献排序）

1. **澳洲单笔尖峰订单不再重复（数据事实）**：澳洲 W09 = 16,726.84（1 单）、W10 = 210.90（1 单），变化 **-16,515.94**，share_of_total_change 为 **-11.4187**（drilldown 国家维度原值；该值为负是因为其他市场在同周反向抵消）。往前一周看，澳洲 W08 = 412.55（也是 1 单，drilldown 2011-W09 环比）——W10 的 210.90 与 W08 的 412.55 属同一量级，即**回落而非塌陷**。
2. **英国正向抵消（数据事实）**：英国 W09 = 93,840.57 → W10 = 113,152.47，**+19,311.90（+20.58%）**，订单 250 → 268，量级足够大，非小样本。它的正向贡献盖过了澳洲的负向贡献，所以整体仍是涨的。
3. **其他小市场同属噪声，不构成"澳洲独有"的问题（数据事实）**：芬兰 -4,418.02（-100%，2 单 → 0 单）、法国 -2,126.04（-68.36%，9 单 → 2 单），这两个分组工具同样标记 small_sample。
4. **剔除澳洲后整体增长更明显（推断，依据 calculate）**：剔除澳洲两周，GMV 从 110,861.51 升到 128,823.84，**+17,962.33（+16.2%）**（两个剔除后的总额与变化额、变化率均来自 calculate）。说明真实经营盘子在 W10 是明显向好的。
5. **与澳洲无关但同周存在的结构变化（数据事实，metric_summary / drilldown 新老客）**：活跃客户数 242 → 227（-15，-6.2%）、老客数 201 → 185（-16，-7.96%），老客 GMV -6,006.25（-6.13%）；同期缺客户 ID 的 GMV 从 12,542.28 升到 20,865.28（+8,323.0，+66.36%）。这属于需要单独看的另一件事。

## 3. 需要注意

- **样本不足警告**：drilldown 明确标记澳洲 W09/W10 均为 small_sample（各 1 单），"不宜对样本不足的分组单独下结论"。上面关于澳洲的所有结论只能表述为"尖峰订单未重复"，不能表述为"澳洲用户流失"。
- **口径**：GMV 是下单口径（含之后被取消的订单）。查看 W10 取消金额的国家下钻，澳洲 W09 取消金额仅 168.70（1 单）、W10 为 0，说明那笔 16,726.84 的大单在这两周**没有对应的全额取消记录**（取消口径按 C 开头发票的日期归周，分子分母也可能不是同一批订单）。净销售额 127,570.42，取消率 1.13%，与 W09 基本持平（metric_summary）。
- **总量可比性没问题**：两周交易天数都是 6 天，日均 GMV 21,505.79 vs 21,264.73（+1.13%），metric_summary 本周无 warnings；2011-W10 也不在 data_quality_overview 列出的不完整周/停业周中。
- **人工复核**：那笔 16,726.84 的澳洲发票未出现在 data_quality_overview 返回的极端大额清单（清单里金额最接近的是 2010-11-04 的 15,818.40，另一周），但它已达整体客单价的 37.1 倍，建议按 R09（极端大额行，共标记 38 行）人工核查是否为大额批发/一次性订单、是否有重复或归属错误。
- 澳洲 GMV 仅占 W10 整体 129,034.74 的 **0.16%**（calculate），对整体盘子影响可以忽略。

## 4. 建议下一步

- 让业务确认澳洲 W09 那笔约 1.67 万的单据性质（大客户集中采购？一次性订单？测试单？），据此决定是否把它从澳洲的基线判断中剔除。
- 若要评估澳洲是否真有趋势性下滑，建议看更长区间（如 2011-W06 至 2011-W14 逐周澳洲订单数与 GMV），因为单周、单订单的环比无法支撑结论。
- 把"活跃客户 -6.2%、老客 -7.96%、缺客户 ID 的 GMV +66.36%"作为独立议题查一轮（drilldown 新老客 + 缺客户 ID 部分），这比澳洲的单点波动更值得投入。

## 5. 可信度自评

**说明局限后可分享**：澳洲"跌 98.74%"是事实，但澳洲两周各只有 1 张订单且工具明确标记样本不足，结论只能定性为"基期单笔尖峰未重复"；不能据此判断澳洲市场本身出了问题。
