# 新版商品详情页 A/B 实验结论：**证据不足，不能判定新版本更好**

## 1. 结论
实验组转化率 6.5%，对照组 6%，绝对差 +0.5pp、相对提升 8.33%（多 40 人下单）。但 p = 0.1914 > 0.05，95% 置信区间为 [-0.25pp, +1.25pp]，**不显著**。目前只能说"实验组转化率更高，与新版详情页上线同时发生"，不能说新版带来了提升——同样的数据也完全可能来自随机波动。

## 2. 关键数字（均来自 ab_proportion_test / ab_sample_size / calculate）

| 指标 | 数值 |
|---|---|
| 对照组转化率 | 480 / 8000 = 6% |
| 实验组转化率 | 520 / 8000 = 6.5% |
| 绝对差 | +0.5pp |
| 相对提升 | +8.33% |
| z 值 | 1.3064 |
| p 值 | 0.191418 |
| 95% 置信区间 | -0.25pp ~ +1.25pp |
| 是否显著 | 否 |

**分流质量检查通过**：SRM 检验实际分流 50% / 50%，与设计的 50/50 一致，chi2 = 0，p = 1.0，无样本比例失衡。也就是说问题不在分流，而在样本量。

## 3. 为什么没跑出显著性：样本量不够
以基线 6% 计算（ab_sample_size，alpha = 0.05，把握度 0.8）：
- 要稳定检测 **+0.5pp** 的提升：需每组 **36,791** 人（合计 73,582），当前每组只有 8,000，**还差 28,791 人/组**。
- 要稳定检测 **+1pp** 的提升：需每组 **9,540** 人（合计 19,080），当前量级刚好处在临界线下方。

换句话说：如果真实提升只有 0.5pp，8,000/组 基本注定测不出来；如果真实提升其实有 1pp 左右，当前样本也可能只是差一点。

## 4. 需要注意
- ab_proportion_test 无 warnings；但置信区间下界为 -0.25pp，意味着**小幅负向影响目前也无法排除**。
- 置信区间上界 +1.25pp 说明真实效果有较大概率落在 0 ~ 1.25pp 的模糊区间，不宜据此定收益预期。
- 检验基于单指标（是否下单），未考虑 GMV / 客单价 / 退款等下游指标——详情页改动可能影响客单和退货率，仅看转化率不完整。
- 该工具做的是两比例 z 检验，未做多重比较校正；若你们同时看多个指标看显著性，需要相应调整 alpha。

## 5. 建议下一步
1. **先定 MDE 再决定跑多久**：和团队确认这次实验要检测的最小效果（0.5pp 还是 1pp）。若认 1pp，每组再扩约 1,540 人即可；只认 0.5pp，则需再扩 28,791 人/组——这个成本是否值得，是决策问题。
2. **加看 GMV / 人均 GMV、客单价**：详情页优化常见收益在客单而非转化，补上金额指标再判断（需要同期对照组数据）。
3. **不要基于本次结果上线决策**，也不建议反复看 p 值直到显著；若要继续，按预先设定好的样本量跑满再看一次。
4. **留存护栏指标**：确认新版没有拉低退款率、加购到下单转化、页面加载性能等。
