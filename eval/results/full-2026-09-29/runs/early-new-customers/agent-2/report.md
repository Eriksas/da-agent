## 分析的是 2010-W10（对比基期：2010-W09，环比）

### 1. 结论
2010-W10 新客数 **83 人**，比上周（2010-W09）的 **116 人**减少 **33 人，环比 -28.45%**。同期活跃客户数从 297 降到 243（-54 人，-18.18%），GMV 从 161,821.09 降到 138,143.14（-23,677.95，-14.63%）。**新客减少是这周整体下滑的主要来源**：GMV 的环比下降中，新客段贡献了 96.79%（-22,918.14，-42.95%），老客段贡献 38.71%（-9,166.58，-9.48%），"未知"（缺客户 ID）段为正向 +8,406.77。

### 2. 主要原因（数字均来自工具）
- **新客数下降**：83 人 vs 116 人，-33 人（-28.45%），来自 `metric_summary`。
- **新客是 GMV 下滑的主要来源**：新客段 GMV 30,441.58 vs 53,359.72，-22,918.14（-42.95%），占总变化 96.79%，来自 `drilldown`（维度：customer_type）。
- **老客也在跌，但跌幅小**：老客数 160 vs 181（-21 人，-11.6%），老客段 GMV -9.48%，占比 38.71%，来自 `metric_summary` / `drilldown`。
- **结构因子拆解**（`decompose_gmv`，Shapley 值）：活跃客户数 -26,738.05（占总变化 1.1292）、人均订单数 -2,146.01（0.0906）、可识别客户客单价 -3,200.66（0.1352）、缺客户 ID 的 GMV +8,406.77（-0.355）。即**下滑主要来自"来的人少了"（活跃客户数），不是"买得少了"或"客单价变低"**。客单价 419.66 vs 429.82、人均订单数 1.1564 vs 1.1751。
- **不是少开门**：两周交易天数都是 6 天（变化 0），来自 `metric_summary`。

### 3. 需要注意（口径与警告）
- 工具 warnings 明确提示：**当期 2010-W10 与基期 2010-W09 都距数据起点（2009-12-01）不足 52 周**，起点之前的购买看不到，**部分老客会被误算成新客**。这周离数据起点只有约 14 周，新客数很可能被高估，"新客减少"的真实幅度可能与口径有关。
- `drilldown` 提示：**"未知"（缺客户 ID）分组本周仅 19 单，样本不足 30**，其 +8,406.77 的变化可能是偶然波动，不宜单独下结论。该组在 W09 是 36 单/W10 是 19 单，与 `decompose_gmv` 中缺客户 ID GMV 上升存在口径上的一致性但需人工核对。
- 新客/老客定义：**新客 = 首次购买落在当周的客户；老客 = 活跃客户数 − 新客数**；活跃客户数不含缺失客户 ID 的订单（清洗规则 R08，该规则影响 243,007 行；全量缺客户 ID 的 GMV 占比 13.11%）。
- GMV 为**下单口径**，含之后被取消的订单；若要看真实到手金额需用净销售额（GMV − 取消金额）。
- 全量数据中有 38 行"极端大额行"列入人工复核清单（含 2010-11-04 的 15,818.4 等），不直接落在 2010-W10，但说明金额类指标存在极端值干扰的可能。
- 以上都是**同时发生的变化，不是因果结论**；没有对照实验，不能说"新客减少导致 GMV 下滑"。

### 4. 建议下一步
1. **补"多不多"的基准**：拉取更早若干周（数据起点附近）的新客数，看 83 人是处于高位还是低位；由于起点后 52 周内新客口径不可靠，横向比较最好用 2011 年同期的周做同比（yoy），避免"老客被算成新客"的偏差。

3. **看商品结构**：`drilldown` 按 product 维度拆 2010-W10 的 GMV，确认是否有主推品售罄或断货。
4. **核对缺客户 ID 的异常**：本周"未知"组只有 19 单但金额上升，工具已标样本不足，建议人工核查这 19 单是否为渠道未采集客户 ID。
