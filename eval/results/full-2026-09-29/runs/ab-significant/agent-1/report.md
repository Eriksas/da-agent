# 满减实验结果：转化率提升**统计显著**

## 1. 结论
实验组转化率 9.2%，对照组 8.0%，绝对差异 +1.2pp，相对提升 15%，**在 95% 置信水平下显著**（p = 0.032）。

## 2. 主要结果
以下数字均来自 `ab_proportion_test`：

| 指标 | 数值 |
|---|---|
| 对照组转化率 | 400 / 5000 = 0.08 |
| 实验组转化率 | 460 / 5000 = 0.092 |
| 绝对差异 | 0.012 |
| 相对提升 | 0.15 |
| z 值 | 2.1401 |
| p 值 | 0.032349 |
| 95% 置信区间 | [0.001012, 0.022988] |
| 是否显著 | 是 |

- **分流校验（SRM）先行通过**：卡方拟合优度检验 p = 1.0，实际对照组占比 0.5，与设计的 0.5 完全一致，无样本比例失衡。
- 检验方法：两比例 z 检验（检验用合并比例，置信区间用非合并标准误）。

## 3. 需要注意
1. **样本量偏小、结论处于临界区间**。按 `ab_sample_size` 计算，要在基线 8% 的情况下以 80% 把握度检测到 1.2pp 的提升，**每组需要 8568 人**；实际每组只有 5000 人。也就是说本次实验的统计功效低于 80%，p = 0.032 距离 0.05 的显著性阈值很近，属于"擦线通过"。
2. **置信区间下限仅 0.001012（0.1pp）**，已非常接近 0，意味着真实效果有较大概率是"几乎无提升"到"小幅提升"之间。直接上线前建议扩量复核。
3. **本次检验无 warnings**；但该工具只校验分流比例，不校验是否中途修改过分流比例、是否只跑了一个时间窗口、是否存在多重比较（若你们同时跑了多组满减门槛，需要做多重检验校正，本结果可能不成立）。
4. 该工具只支持转化率（比例）指标，**未涉及 GMV / 客单价 / 毛利**。满减通常会拉低客单价，转化率显著不等于利润显著。

## 4. 建议下一步
- **扩量复跑**：每组跑到 8500+ 人（或把实验延长），确认 1.2pp 的提升是否稳定。
- **看收入侧指标**：把订单数、GMV、客单价一起看，评估"满减 − 让利成本 + 增量订单"后的净收益；重点看实验组客单价是否被满减吃掉。
- **看新老客结构**：如果提升主要来自本来就会下单的高频老客，实验对拉新价值有限。
- **检查实验纪律**：确认实验期间未改分流比例、观察窗口覆盖完整周（避免工作日/周末结构偏差），并确认是否有多实验并行需要校正。
