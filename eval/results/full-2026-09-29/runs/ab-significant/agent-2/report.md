# 满减实验结果：显著，但幅度贴近显著性边界

## 1. 结论
实验组转化率 9.2%，对照组 8.0%，绝对提升 1.2pp、相对提升 15%，z = 2.14，p = 0.032 < 0.05，**在 α=0.05 下效果显著**（来自 `ab_proportion_test`）。但 95% 置信区间下界仅 0.10pp，几乎贴着 0，且当前样本量（约 8568/组）低于本次实验实际达到的检验精度需求（见下文），结论偏脆弱。

## 2. 主要结果（全部来自 `ab_proportion_test`）
| 指标 | 数值 |
|---|---|
| 对照组转化率 | 0.08（400/5000） |
| 实验组转化率 | 0.092（460/5000） |
| 绝对差 | 0.012 |
| 相对提升 | 0.15 |

| p 值 | 0.032349 |
| 95% 置信区间 | [0.001012, 0.022988] |
| 是否显著 | 是 |

**SRM 检查（先做的失衡检验）**：观测对照组占比 0.5，期望 0.5，卡方 0.0，p = 1.0，`sample_ratio_mismatch: false` —— 分流比例与设计一致，可以正常解读。

## 3. 需要注意
- **样本量与把握度不匹配**：按基线 8%、想稳定检出 1.2pp 的绝对提升，α=0.05、power=0.8，`ab_sample_size` 返回**每组需 8568 人**；本次每组只有 5000 人。也就是说这次是在"样本不够"的情况下勉强打到显著线，p = 0.032 离 0.05 只有一点余量，**再跑一周或换一批流量结果可能就翻转成不显著**。
- **置信区间下界 0.001012 极接近 0**：真实提升的区间从"几乎没提升"到"2.3pp"，区间很宽，不宜对外承诺具体数字。
- 相对提升 15% 听起来不小，但绝对值只有 1.2pp；下单成本、客单价、是否挤占原有自然转化都未纳入本次检验。工具只检验了转化人数，不含金额指标。
- 本次为单次检验，无多重比较校正；若你们同时看了多组优惠力度或多指标，实际显著性需相应调整（工具未提供该检验）。

## 4. 建议下一步
1. **延长实验或扩流量**：按 `ab_sample_size` 的结果把每组加到 8500+ 人（或延长实验周期），让 p 值有稳定余量，再决定是否全量。
2. **补金额维度**：除转化率外，再看实验组的 GMV / 客单价是否同步提升 —— 满减常出现"转化率涨、客单价掉"的情况，可用 `metric_summary` 口径的对应周数据核对。
3. **评估长期效应**：检验满减是否把本来会下单的人提前转化（ cannibalization），建议加长观察期再看留存与复购。
4. **如果必须现在决策**：可以按"大概率正向、但幅度不确定"做小流量灰度，同时准备回滚开关，而不是直接全量。
