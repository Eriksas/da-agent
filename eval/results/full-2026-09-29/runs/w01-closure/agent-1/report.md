# 2011-W01 GMV 环比怎么看

**分析周期：2011-W01（2011-01-03 至 2011-01-09 所在周），基期 2010-W52。**

## 1. 结论

**2011-W01 的 GMV 环比（对比 2010-W52）没有分析意义**：基期整周停业、零交易，环比数值只是"从 0 到 130,274.65"，工具未给出变化百分比，GMV 结构拆解也因基期无可识别客户而无法执行。

真正可用的口径是**同比（vs 2010-W01）**：GMV 从 166,010.79 降到 130,274.65，减少 35,736.14（-21.53%）。这个下降与**客单价大幅下滑**同时发生，而订单数和活跃客户数其实是增长的。

## 2. 主要原因（同比口径，来自 decompose_gmv / metric_summary / drilldown）

GMV 恒等式：`GMV = 活跃客户数 × 人均订单数 × 可识别客户客单价 + 缺客户 ID 的 GMV`，总变化 -35,736.14，各因子 Shapley 贡献：

| 因子 | Shapley 贡献 | 说明 |
|---|---|---|
| 可识别客户客单价 | **-77,797.41**（占总变化 217.7%） | 可识别客户客单价从 884.59 降至 506.58（-291.73，-35.15%），是唯一显著为负的驱动因子 |
| 缺客户 ID 的 GMV | +16,209.97（-45.4%） | 从 591.63 增至 16,801.6，对冲了部分下滑 |
| 活跃客户数 | +31,551.30（-88.3%） | 从 166 增至 207（+41，+24.7%），是正贡献 |
| 人均订单数 | -5,700.00（+16.0%） | 从 1.1265 降至 1.0821，小幅下降 |

新老客拆解（drilldown，customer_type）：
- **新客 GMV：-28,487.25（-82.28%），占总变化 79.7%**；新客数从 67 降到 14（-79.1%）
- 老客 GMV：-23,458.86（-17.94%），占总变化 65.6%；老客数从 99 增至 193（+94.9%）
- 未知（缺客户 ID）：+16,209.97（+2739.9%）

商品拆解（drilldown，product）：变化最大 5 个单品合计占比都不高，其余 **2,457 个分组合计 -34,046.42，占总变化 95.3%**——即下降是全局性的，没有单一商品驱动。

**注意：以上都是"同时发生"的统计关联，本数据无对照实验，不能断言客单价下滑"导致"了 GMV 下降。**

## 3. 需要注意（数据口径与警告）

- **环比不可用（最重要）**：metric_summary 明确 warning「基期 2010-W52 整周没有交易（停业），各项指标为 0」；decompose_gmv 直接报错「基期 2010-W52 没有可识别客户的订单，无法拆解」。data_quality_overview 记录该周 trading_days=0，属于 2010-12-24 至 2011-01-04 的 12 天假期停业。
- **同比基期也有缺陷**：warning「基期 2010-W01 距数据起点不足 52 周：起点之前的购买看不到，部分老客会被算成新客」——2010-W01 的新客 67 有可能被高估，这会让"新客 -82%"的降幅看起来比实际更大。
- **交易天数不对等**：2011-W01 为 5 个交易日，2010-W01 为 6 个（-16.7%），总量对比天然吃亏。
- **取消率上升**：3.66% vs 0.78%，上升 2.88 个百分点。注意口径：取消金额是"当周 C 开头发票"的金额，可能对应更早下的订单，不一定是同一批订单。
- **样本不足**：新老客和商品拆解中多个分组订单数少于 30（工具已标记 small_sample）。
- **缺客户 ID 的订单**（清洗规则 R08）计入 GMV 和订单数，但不计入活跃客户/复购/人均订单；本周 unidentified_gmv 达 16,801.6，是拆分中不可忽视的一块。
- 环比口径下 aov、cancel_rate 的 base 为 null，无法比较。

## 4. 建议下一步

1. **换个基期看环比**：把 2011-W01 与 2010-W48/2010-W49 这类正常的相邻周（或 2011-W02 做次周对比）比较，才能看真实的周环比走势。
2. **验证客单价下滑的来源**：用 drilldown 按国家（dimension=country）拆 net_sales 或 aov，看是否集中在某几个市场；并核对人均订单数/人均件数的明细。
3. **查"缺客户 ID 的 GMV"突然放大**的原因（16,801.6 vs 上年同期 591.63）：可能是某批发/游客订单缺 ID，也可能是下单流程或数据采集变更，建议抽样核对。
4. **核对取消率上升**是否集中在某些客户或商品（drilldown，metric=cancelled_amount，dimension=product）。
5. **人工复核大额订单清单**：data_quality_overview 列出了 38 行极端大额行，其中 2011-01-18 的 "MEDIUM CERAMIC TOP STORAGE JAR" 存在 77,183.6 的下单与取消对冲，虽不在 W01，但会影响后续周的分析结论。
6. 本次共调用 6 次工具，其中 1 次失败（环比拆解因基期停业不可用）。
