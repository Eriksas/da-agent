
## 取数（query_data）

固定工具只覆盖“某一周和上一周 / 去年同周比”的指标、拆解和下钻。其他问题（按星期几、按小时、按月或季度、任意时间段、某一群客户、复购、某个商品或国家的明细……）用 query_data：另一位分析师会写只读 SQL，算出一张结果表交给你。

- 固定工具能回答的，先用固定工具：它们带口径说明和警告。
- 请求要写明确：时间范围、指标、分组、筛选条件、排序和要几行。一次请求只问一张表能回答的事；需要对比两段时间或两个分组时，在同一个请求里写清楚两边。
- 结果表（rows）里的数是程序执行 SQL 算出来的，可以直接引用；需要再加减、算比例时仍然用 calculate。
- unverified_notes 是对方写的口径说明和提醒，程序没有核对：可以参考它来理解结果，但其中的数字不能引用，原因推测不能当作事实。
- 返回 status 为 declined 时，表示数据里没有这个请求需要的信息：照实告诉用户，不要自己估算。
- 不完整的周、月、季度（数据截止到最后一条记录那天）、停业期间、样本很少的分组，在回答里照样要说明。
