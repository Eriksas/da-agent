#### 1. 结论

GMV 从 **161,821.09 降至 138,143.14，环比 -23,677.95（-14.63%）**；订单 **385 → 300（-85，-22.08%）**；活跃客户 **297 → 243（-54，-18.18%）**。本周下滑是"人少了"而不是"单变小了"：贡献最大的是活跃客户数（Shapley -26,738.05），可识别客户客单价仅小幅走低（Shapley -3,200.66），人均订单数基本持平（Shapley -2,146.01）。同时**缺客户 ID 的 GMV 反而 +8,406.77**，抵消了约 35.5% 的降幅，使总量降幅看起来比可识别客户侧的下滑温和；整体客单价上升 9.56%（420.31 → 460.48）主要来自这块结构变化，而非普遍提价。

#### 3. 需要注意

- **缺客户 ID 部分占比从 7.30% 升到 14.64%**（`calculate`），每单均值从 **328.13 升到 1,064.18**，且订单数从 36 降到 19。可能是少数访客大额单，也可能是客户 ID 采集/回填异常（待核实）；它同时影响 AOV 和全部拆解结论，是本周最需要先确认的一块。
- **左删失**：数据起点为 2009-12-01，本周与基期距起点均不足 52 周，部分老客会被算成新客 → 新客数 83、老客数 160 这类结构数字应从严解读（`metric_summary`、`drilldown` 均有此警告）。
- **客单价口径**：整体 AOV = GMV ÷ 订单数（含缺客户 ID 部分），所以 AOV +9.56% 与可识别客单价下降（429.82 → 419.66）并不矛盾，两者不要混用。
- **取消不是主因**：取消率 1.13% → 1.40%（变化 0.0027，即 +0.27 个百分点），取消金额 +111.88 至 1,933.46；净销售额 -23,789.83（-14.87%），与 GMV 降幅基本一致。
- **可比性良好**：两周交易天数均为 6 天，日均 GMV 23,023.86 vs 26,970.18、日均订单 50 vs 64.1667（降幅同为 -14.63% / -22.08%）；本周不在停业周或不完整周列表内，`data_quality_overview` 中被标记的极端大额行也都不在本周（最近一笔为 2010-11-04 的发票 530715）。
- **同比不可用**：2009-W10 不在数据范围（2009-W49 至 2011-W49），无法做同比参照。
- 本文只描述相关与结构事实，未做因果判断。
