## 3. 需要注意

1. **净变化被两笔大额反向摆动掩盖。** EIRE（−45,988.38）与缺 ID 销售额（+32,563.29）合计 78,551.67，远超实际净变化 10,567.00。**不要用"GMV 只跌了 6.4%，问题不大"这种结论。**

2. **"缺客户 ID 的 GMV"数据质量异常。** 该项从 591.63 跳到 33,154.92（+55.04 倍，工具给出的百分比），订单从 13 → 27。按清洗规则 R08，缺客户 ID 的记录**计入 GMV 和订单数，但不计入活跃客户/复购/人均订单**。全量数据该比例为 13.11%（`data_quality_overview`），而本周明显偏高。后果是：本周的"订单数 +31%"里有一部分来自这些无法归因的订单，同时它们无法参与新老客分析。

3. **EIRE 的大额集中未被极端值清单捕获。** `data_quality_overview` 的极端大额行复核清单（R09，共 38 行）中，最近的几笔集中在 2010-11、2011-01、2011-06、2011-12，**没有 2010-W01 的记录**。也就是说 EIRE 在 W01 的 47,630.88（仅 3 单）不是被系统标记出来的极端行，需要人工拉订单明细确认是真实大客户还是少数几笔大单。

4. **基期处于"长假后重开"状态，天然偏高。** `data_quality_overview` 显示门店 2009-12-23 停业、2010-01-04 重开，停业 12 天；2009-W52 仅 3 个交易日、2009-W53 为 0。**2010-W01 是重开后的第一周**，节前积压需求很可能集中释放到该周。这与"EIRE 和老客在 W01 基数异常高"的现象同时出现。*（可能的原因，待业务确认：需要节前/节后对比数据验证。）*

5. **左删失，新老客拆分不可靠。** 当期与基期均触发警告：距数据起点（2009-12-01）不足 52 周，起点前的购买不可见，部分老客会被算成新客。因此"新客 +25.37%"应从严解读，老客数又是"活跃客户数 − 新客数"的残差，**新老客的绝对数与占比都带误差**。

6. **拆解结果对顺序敏感。** 活跃客户数的 chain 值 28,898.53 与 Shapley 值 23,680.94 相差约 5,200；可识别客单价 chain −85,590.82 与 Shapley −76,711.23 相差约 8,900。方向一致、量级有别，建议以 Shapley 为准并注意此敏感性。

7. **商品维度无单一主因。** 前 5 名商品全部下滑，但合计仅约 20%–25% 的贡献/项，且 4 项为小样本；`others`（2248 个分组合计）为 +1,154.74。**不要从商品层面下结论。**

8. **取消率小幅上升**（0.78% → 1.02%，+0.25 个百分点，取消金额 1,288.94 → 1,591.17），净销售额降幅（−6.60%）略大于 GMV 降幅（−6.37%）。量级小，不是本周主因。另注意口径：取消率的分子分母不一定是同一批订单。

9. **不下因果结论。** 以上全部为同期共现的结构性事实，任何"为什么"（如促销、库存、投放变化）都需要业务侧确认或实验验证。
