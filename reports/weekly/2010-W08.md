#### 3. 需要注意

1. **可比性 OK**：两周交易天数均为 **6 天**，日均 GMV **26,726.23 vs 28,432.62（-6.00%）**、日均订单 **52.3333 vs 51.8333**，总量与日均结论一致，不存在不完整周期或停业干扰（停业窗口在 2010-04-01→04-06 与年末，不在本周）。
2. **小样本分组**：丹麦、荷兰、瑞典、法国、比利时、UAE、塞浦路斯及多数商品分组订单数 <30，其变化可能是偶然波动，本报告只用于解释总量，不单独下结论；`others`（6 国合计 / 2233 个商品合计）是“前 N 名以外”的合计，**不等于剔除某一组后的结果**。
3. **占比符号**：存在反向变化的分组相互抵消，单个分组贡献占比可能 >100% 或为负（如老客 +280.81%、新客 -207.70%），不要按占比字面解读。
4. **口径**：GMV 为下单口径、含之后被取消的订单；取消率（1.70% vs 4.22%，-2.52pp）的分子（当周 C 开头发票）与分母（当周 GMV）不一定是同一批订单。
5. **左删失**：当期与基期均距数据起点不足 52 周，起始前的购买不可见，部分老客会被算成新客，新客规模可能被高估，新老客结论从严。
6. **无极端大额行落在本周**：人工复核清单中与 2010 年相关的单据为 530715（2010-11-04），其余为 2011 年，不在 2010-W08；但丹麦/荷兰的少量高额订单是本周波动的实际来源。
7. **口径外因素**：缺客户 ID 的 GMV 占全站 13.11%（data_quality_overview），本周该部分 -2,753.44 且订单数由 33 降到 14，对活跃客户、复购、人均订单口径有影响。
8. **不下因果结论**：以上均为相关性与结构描述，未做对照实验，缺少“为什么丹麦/荷兰客户没下单”的业务证据。

#### 4. 建议下一步

1. **向业务确认**：丹麦 2 单、荷兰 3 单对应的具体客户/商品与场景（是否为大额团购、批量补货或一次性采购），以及本周英国单均提升、新客单均上升是否与某次活动/投放同步发生。
2. **补数据**：拉取丹麦、荷兰在 2010-W05~W10 的逐周明细，判断是“一次性大单结束后回落”还是“客群流失”，避免用两周数据下结论。
3. **补维度**：按客户 ID 核对老客 GMV -28,750.35 的来源客户，看是否集中于少数高价值老客；并对缺客户 ID 部分（14 单）追查可识别性。
4. **口径复核**：确认取消金额骤降 62.07% 是真实订单质量改善，还是取消单日期与下单日期错位造成的口径现象。
5. **如需验证因果**（如“英国单均提升由新客券驱动”），应设计 A/B 实验，用 `ab_sample_size` / `ab_proportion_test` 检验，而不是继续用环比推断。
6. **监控口径**：建议后续周报固定使用日均指标（交易天数不同才可比），并对新客/老客结论加左删失保留。
