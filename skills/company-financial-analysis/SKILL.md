# 上市公司财报分析

## 1. 先判断问题属于哪一档

- **查一个数**（如“京东 2024 年营业收入多少”）：调用 `financial_summary`，直接回答，不走下面的完整流程。
- **单公司分析**（默认）：按第 2 节全部步骤执行。
- **同行对比**：按第 2 节执行，并调用 `peer_compare`。
- **估值、评级、股价、买卖建议**：拒绝，说明这里只做财务分析，可以提供哪些财务指标。

## 2. 步骤（按顺序执行）

1. **明确范围**：哪家公司、哪个财年、和什么比（上一财年或同行）。调用 `company_overview`，确认财年截止日、币种、可用财年、哪些科目没有标准数据。用户没说财年时，用最近一个财年。
2. **取数**：调用 `financial_summary`，逐条阅读 warnings（财年不对齐、未披露、口径切换、净利润口径）。
3. **分析**：按第 3 节的维度逐项看，每个维度至少引用一个比率。ROE 有明显变化时调用 `dupont`，看变化来自净利率、周转率还是权益乘数。
4. **写结论前**：对照第 4 节的陷阱清单逐条检查。
5. **风险提示**：列出第 3 节里命中的风险信号，写明这是“数据显示的信号”，不是判断。

## 3. 分析维度

| 维度 | 看什么 | 工具里的指标 |
|---|---|---|
| 业务：规模与增长 | 收入规模、收入同比 | 营业收入、revenue_growth |
| 业务：盈利能力 | 毛利率、经营利润率、归母净利率、费用率 | gross_margin、operating_margin、net_margin、rd_ratio、marketing_ratio |
| 财务：回报 | ROE、ROA、杜邦拆解 | roe、roa、`dupont` |
| 财务：资本结构 | 资产负债率、权益乘数 | debt_ratio、equity_multiplier |
| 财务：偿债与流动性 | 流动比率、现金 | current_ratio、现金及现金等价物 |
| 财务：现金流质量 | 经营现金流 ÷ 归母净利润、自由现金流 | ocf_to_net_income、自由现金流 |

**风险信号**（数据显示的信号，需要结合业务判断）：
- 收入下降，或增速比上一财年明显放缓；
- 经营利润率大幅下降，或某项费用率大幅上升；
- 经营现金流 ÷ 归母净利润低于 1：利润没有足够的现金支撑；
- 资产负债率上升，或流动比率低于 1；
- ROE 的提升主要来自权益乘数（加杠杆），而不是净利率或周转率。

## 4. 陷阱清单（写结论前逐条对照）

| 陷阱 | 在这份数据里的样子 | 怎么避免 |
|---|---|---|
| 财年不对齐 | 阿里财年截至 3 月 31 日，FY2026 = 2025-04-01 至 2026-03-31；其他三家是自然年 | 写明各自的期间；同行对比时说明不是同一段时间 |
| 币种不同 | 阿里、京东、拼多多用人民币，亚马逊用美元 | 跨公司只比比率和增速，不比金额，不自行换算汇率 |
| 未披露不等于 0 | 部分公司近年的购建固定资产支出、亚马逊的研发费用没有标准数据 | 写“未披露”，相关指标（如自由现金流）不下结论 |
| 口径切换 | 工具提示某个科目两年用了不同的标注写法 | 引用 warnings 里的说明，同比结论加保留 |
| 净利润口径 | “归母净利润”和“含少数股东的净利润”可能相差较大 | 写明用的是归母净利润 |
| 毛利口径 | 毛利是“营业收入 − 营业成本”算出来的，各公司计入营业成本的项目不同 | 毛利率跨公司比较要加保留，优先比较经营利润率 |
| 杠杆推高 ROE | ROE 上升可能只是权益乘数变大 | 用 `dupont` 的 Shapley 贡献说明来源 |
| 非经营项目 | 投资收益、减值等会让净利润大幅波动，经营利润更能反映主业 | 净利润和经营利润一起看；数据里没有这些项目的明细，不要猜具体是什么 |
| 相关当因果 | 数据里只有财务数字，没有业务原因 | 业务原因写成“待验证假设” |

## 5. 结论写法

每条发现标明类别：

- **数据事实**：工具直接给出的数字，注明来自哪个工具。
- **推断**：由数据推出的判断，必须写出依据。
- **待验证假设**：业务原因，注明“需要结合公司公告或业务信息核实”。

## 6. 输出格式

1. **结论**：一两句话，写明公司、财年和期间。
2. **主要发现**：按第 3 节的维度，每条带数字和出处。
3. **风险提示**：命中的风险信号。
4. **需要注意**：口径、未披露项、财年和币种。
5. **可信度自评**：可直接分享 / 说明局限后分享 / 需修改后再分享，并写一句理由。

## 7. 边界

- 所有数字来自工具返回的结果；需要计算时调用 `calculate`，不心算。
- 不做估值（市盈率、目标价等）、不做评级、不预测股价、不给买卖建议。
- 不下因果结论；数据是 SEC 公开年报里标准分类的科目，公司自定义的科目看不到。
