**问题：** 2011-W49 的 GMV 大涨，是好消息吗？

分析的是 **2011-W49**（数据截止 2011-12-09 12:50，周五中午）对比 **2011-W48**。

## 1. 结论

**不是好消息，这是"假涨"。** GMV 环比 +56.35% 几乎全部来自一张当天被全额取消的极端大额订单；剔除这一单的直接影响后，真正反映经营结果的**净销售额只 +1.58%**，而**订单数 -23.23%、活跃客户数 -19.26% 是在下降的**。而且 W49 还是一个不完整周，不能与整周直接比。

## 2. 主要原因（按贡献排序）

| 因子 | 数值 | 来源 |
|---|---|---|
| 单个极端大额订单 | 发票 581483，商品 23843「PAPER CRAFT , LITTLE BIRDIE」，金额 **168,469.60**，占 GMV 总变化的 **96.63%**（仅 1 单，工具标记 small_sample） | `drilldown`(product/gmv) |
| 这张单被等额取消 | 取消金额 3,266.67 → **172,781.77**（+169,515.10），其中该商品占取消增量的 **99.38%** | `drilldown`(cancelled_amount/product) |
| 取消率飙升 | **1.06% → 35.72%**，变化 **+34.66 个百分点** | `metric_summary` |
| 客单价虚高 | AOV 466.64 → **950.34（+103.66%）**；可识别客户客单价 391.15 → **838.31（+114.32%）**，几乎全由这张单撑起 | `metric_summary`、`decompose_gmv` |
| 客单价是唯一"正贡献"因子 | 贡献：**+248,355.67（占总变化 142.45%）**；活跃客户数 **-72,453.52（-41.56%）**，人均订单数 **-18,653.29（-10.70%）**，缺客户 ID 的 GMV **+17,094.54（+9.81%）** | `decompose_gmv`（Shapley 值） |
| 大盘并未变好 | 其余 2,593 个商品的 GMV **305,017.11 → 302,127.80（-2,889.31）** | `drilldown`(product/gmv) |
| 量在萎缩 | 订单 663 → **509**，活跃客户 514 → **415**，新客 31 → **17**，老客 483 → **398** | `metric_summary` |

新老客拆分（`drilldown` customer_type）也印证同一件事：老客 GMV 贡献了总变化的 84.12%，而这张单正落在老客里；新客、新老客订单均减少。

## 3. 需要注意（口径与警告，工具原话）

- **当期 2011-W49 是不完整周：数据截止到 2011-12-09 12:50（周五）**；交易天数 5 天 vs W48 的 6 天。环比并非同口径。
- **当期含极端大额行**：发票 581483 金额 168,469.60，**24 小时内被等量取消**（GMV 含它，净销售额已扣除）；另有发票 C581484 金额 -168,469.60。
- 该极端行在 `data_quality_overview` 中属 R09「极端大额行：仅标记，列入人工复核清单」，**尚未被人工确认**；同类还有 2011-01-18 的 77,183.60（同样 24 小时内取消）。是否真实成交、是否录入错误，工具没有给出结论。
- 取消率口径提醒：分子（当周 C 开头发票）分母（当周 GMV）不一定是同一批订单。
- 拆分工具提示：部分商品/分组订单数少于 30，变化可能只是偶然波动。
- 工具**未提供**"剔除该极端订单后的 GMV / 订单数"这一口径，也未提供逐日曲线，所以"W49 真实增速是多少"我没有数据可给。
- 上述均为同期**同时发生**的关联与算术分解，不构成因果结论。

## 4. 建议下一步

1. **先做人工复核**：把发票 581483 / C581484 提交业务确认（是否真实大客户单、是否录入错误、是否为刷单），并把它加入监控名单——本次大涨能否成立完全取决于这一单。
2. **对外汇报改用净销售额口径**（310,943.36 vs 306,115.06，+1.58%），或用剔除极端行的 GMV，避免用 +56% 做结论/做业绩。
3. **真正要关注的是量的下滑**：订单 -23%、活跃客户 -19%、新客 31→17。W49 数据只有 5 天，暂不能定性，建议等 W50 完整周（2011-W50）出来后再用 `metric_summary`/`decompose_gmv` 复核是否延续。
4. 若要判断"是不是季节性"，可用 compare=yoy 看 2011-W49 对 2010-W49；W49 本身不完整，同比也会受限。
5. 查一下该商品 23843 的正常销量与历史单均金额，判断这单是常规大客户还是异常值（工具未提供该商品的长期分布）。
