# 真实运行样例

2026-09-29 用真实模型（MiniMax-M3.1-Flash-Preview）回答的两个问题，完整保留了从 AI 初稿到人工复核的全过程。每个目录包含：

| 文件 | 内容 |
|---|---|
| `answer.md` | 模型的原始回答 |
| `report.md` | 标注“AI 初稿”的报告，附自动核查结果、工具调用记录和警告汇总 |
| `checks.json` | 自动核查的结构化结果 |
| `run.json` | 完整运行记录：和模型的全部对话、每次工具调用的参数和返回值、token 用量 |
| `review.md` | 人工复核记录：自动核查查不出来的推理问题 |

| 问题 | 自动核查 | 人工复核发现 |
|---|---|---|
| [上周 GMV 为什么变化？](20260929T144747-a7db30/review.md) | 85/85 个数字有出处；标记 3 处表述 | 过度概括、无证据的推测、解释逻辑不成立 |
| [2011-W49 的 GMV 大涨，是好消息吗？](20260929T145037-386bcf/review.md) | 59/59 个数字有出处；标记 1 处表述 | 口径误读导致结论方向相反；结论与自己的警告矛盾 |

结论：**数字可以自动核查，推理必须由人复核。** 这两次运行中模型没有编造数字，但出现了“数字全对、推理有误”的情况，其中最严重的一处自动核查无法发现。
