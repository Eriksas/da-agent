# 2011-W48 GMV 环比变化分析

> 分析周期：**2011-W48**（对比基期 2011-W47，环比 wow）。数据范围 2009-12-01 至 2011-12-09，W48 是最近的完整周。

## 1. 结论

上周 GMV **微涨**：309,381.73，环比 +6,989.51（**+2.31%**），订单数 663 单（+47，+7.63%）。但这是"量增价减"的拉锯结果——**活跃客户数增长和人均订单数增长是正贡献，客单价下滑是负贡献**，三者相互抵消后才只剩 2.31% 的净增长。净销售额表现更好：306,115.06，环比 **+10,881.75（+3.69%）**，因为取消金额同时大幅下降。

## 2. 主要原因（按贡献大小）

来自 `decompose_gmv`（Shapley 值，与分解顺序无关）：

| 因子 | Shapley 贡献 | 占总变化 | 说明 |
|---|---|---|---|
| 可识别客户客单价 | **-13,088.20** | -187.25% | 412.58 → 391.15，最大拖累项 |
| 活跃客户数 | **+10,735.71** | +153.60% | 492 → 514 人（+22） |
| 人均订单数 | **+5,336.81** | +76.35% | 1.2012 → 1.2276 |
| 缺客户 ID 的 GMV | **+4,005.19** | +57.30% | 58,559.15 → 62,564.34（+6.84%） |

四条贡献相加等于总变化 +6,989.51（工具校验通过）。

**分维度看（drilldown）：**

- **新老客**（GMV）：老客 +12,380.36（+5.52%，订单 548→595），新客 **-9,396.04（-48.32%，订单 43→36）**。增长全靠老客，新客接近腰斩。
- **客户数结构**：老客 455→483（+28，+6.15%），新客 37→31（-6，-16.22%）。
- **国家**：英国 +14,297.73（+5.38%，订单 560→607）；荷兰 -10,694.24（订单 5→1）、意大利 -2,453.80（订单 4→0）、西班牙 -3,313.22（订单 3→1）三个小市场订单几乎归零。
- **商品**：RABBIT NIGHT LIGHT +4,145.47、COOK WITH WINE METAL SIGN +2,392.15、VINTAGE DOILY JUMBO BAG RED +2,762.02 为正；CHILLI LIGHTS -3,242.33 为负。
- **净销售额与取消**：取消金额 7,158.91 → 3,266.67（**-54.37%**），取消率 2.37% → 1.06%（-1.31 个百分点），其中英国取消额 6,424.77 → 2,168.51（-66.25%）。这解释了为什么 GMV 只涨 2.31%、净销售额却涨 3.69%。

## 3. 需要注意（口径与警告）

- **样本不足警告**（工具原文）：荷兰（5→1 单）、日本（0→1 单）、西班牙（3→1 单）、意大利（4→0 单）、法国（10→18 单），以及"未知"客群（25→32 单），分组订单数均少于 30，**变化可能是偶然波动，不宜单独下结论**。
- **反向抵消警告**（工具原文）：有分组反向变化，相互抵消后总变化较小，所以单个分组的贡献占比会超过 100% 或为负——上表中 -187.25%、+153.60% 这类占比就是这个原因，不能按字面理解为"贡献了一倍多"。
- **GMV 为下单口径**，含之后被取消的订单；取消金额按"当周 C 开头发票"统计，**分子分母不一定是同一批订单**，所以"取消率下降"可能部分来自前几周订单本周才被取消。
- **缺客户 ID 的 GMV** 全量占比 13.11%，本周该部分 +6.84%，不计入活跃客户/复购/人均订单，会使客单价等指标的解读偏差。
- **客单价口径差异**：整体 AOV 466.64（-4.94%），可识别客户 AOV 391.15，差异来自缺客户 ID 部分金额占比上升。
- **无对照实验**：以上均为同期对比，未控制流量、促销、节假日等因素，只能说"与……同时发生"，不能判定因果。
- 本周与上周交易天数均为 6 天，无停业差异影响。

## 4. 建议下一步

1. **优先排查新客腰斩**：新客 GMV -48.32%、新客数 -16.22%，但新客基数仅 36-43 单，波动天然大。需确认是否有渠道/投放/落地页变更，或新客首单门槛（运费、满减）调整。
2. **排查客单价下滑的构成**：可看是否集中在某几个高价商品或某类目（英国是主市场且客单价未拆），以及是否有低价促销/折扣码活动。
3. **核对 W47 的取消高峰**：W47 取消率 2.37% 明显高于 W48 的 1.06%，查 W47 是否有集中退货批次，避免把"取消回落"当成经营性改善。
4. **核对荷兰/意大利/西班牙的订单归零**：这几国订单量本就在 1-5 单区间，更可能是数据记录习惯或客户归属变化，而非真实市场流失。
5. **补做同比（yoy）对照**：本周 vs 2010-W48，排除季节性（12 月圣诞备货周期）后再判断趋势。
6. 若需验证"某项改动是否提升客单价/新客转化"，需先跑样本量估算再设计 AB 实验，当前数据不足以支持因果结论。
